# Java 基础语法学习

## 编译运行方式

```bash
# 编译
javac 文件名.java

# 运行
java 类名
```

### 示例
```bash
javac VariablesAndTypes.java
java VariablesAndTypes
```

## 前置要求
- JDK 8 或更高版本
- 配置好 JAVA_HOME 环境变量

## 目录结构

### 01_基础语法
- `VariablesAndTypes.java` - 变量、数据类型、字符串

### 02_流程控制
- `ControlFlow.java` - 条件、循环、switch 表达式

### 03_函数
- `Methods.java` - 方法、重载、递归、重写

### 04_数据结构
- `CollectionsDemo.java` - List、Map、Set、集合工具

### 05_面向对象
- `OOPDemo.java` - 类、继承、多态、接口、抽象类

### 06_常用操作
- `FileAndException.java` - 文件IO、异常处理、NIO

## 推荐学习顺序
1. 基础语法 → 2. 流程控制 → 3. 方法 → 4. 集合 → 5. 面向对象 → 6. 文件操作
