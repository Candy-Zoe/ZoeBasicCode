# JavaScript 基础语法学习

## 运行方式

### Node.js 环境
```bash
node 文件名.js
```

### 浏览器环境
1. 创建 HTML 文件，通过 `<script src="文件名.js"></script>` 引入
2. 直接在浏览器开发者工具控制台中运行

## 前置要求
- Node.js 14+ (推荐 18+)
- 或现代浏览器 (Chrome / Firefox / Edge / Safari)

## 目录结构

### 01_基础语法
- `01_变量和数据类型.js` - 变量、数据类型、字符串、解构

### 02_流程控制和函数
- `01_流程控制和函数.js` - 条件、循环、函数、数组方法

### 03_面向对象和常用操作
- `01_面向对象和常用操作.js` - 类、Promise、Set/Map、Proxy

## 推荐学习顺序
1. 基础语法 → 2. 流程控制和函数 → 3. 面向对象和常用操作
