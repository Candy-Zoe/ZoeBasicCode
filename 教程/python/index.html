Python 教程

从零开始系统学习 Python 编程语言，涵盖语法基础、面向对象、进阶特性和实战最佳实践。Python 是一种解释型、面向对象、动态类型的高级编程语言，以其简洁优雅的语法和强大的生态系统著称。

1. Python 简介

原理讲解：为什么选择 Python

Python 由 Guido van Rossum 于 1991 年发布，设计哲学强调代码可读性和简洁性。Python 采用"一种方式，最好只有一种方式"的哲学，使得不同开发者写出的代码风格高度一致。

Python 是动态类型语言，变量不需要声明类型，解释器会在运行时自动推断。同时它是强类型语言，不会自动进行类型隐式转换（比如字符串和数字不能直接相加）。

Python 的应用领域极为广泛：Web 开发（Django、Flask）、数据科学（NumPy、Pandas）、人工智能（PyTorch、TensorFlow）、自动化运维（Ansible）、桌面应用（PyQt）、游戏开发（Pygame）等。

Python

# Simple is better than complex.        简单胜于复杂

3. 基本语法

原理讲解：Python 的缩进机制

Python 使用缩进（通常是 4 个空格）来定义代码块，而不是像 C/Java 那样使用花括号。这是 Python 最显著的特征之一。缩进不是装饰性的——它是语法的一部分，缩进错误会导致 IndentationError。

4. 变量与数据类型

原理讲解：Python 的对象模型

在 Python 中，一切皆对象。变量本质上是对象的引用（标签），而不是存储值的容器。当你写 x = 42 时，Python 在内存中创建一个整数对象 42，然后让变量 x 指向它。

Python 的变量是动态类型的——同一个变量可以指向不同类型的对象。但变量本身有类型检查：x = 5 后 x 指向 int 对象，x = "hello" 后 x 指向 str 对象。

可变对象（list、dict、set）和不可变对象（int、str、tuple）的行为不同。不可变对象的"修改"实际上是创建新对象，而可变对象可以在原地修改。

5. 运算符

原理讲解：Python 运算符的特殊性

Python 的运算符有几个显著特点：(1) 整数除法使用 //，不是 /（Python 3 中 / 始终返回浮点数）；(2) 幂运算使用 **，比 math.pow() 更高效；(3) Python 支持链式比较（1 < x < 10），这是 C/Java 不支持的。

Python 的 is 和 == 有本质区别：== 比较值是否相等，is 比较身份（是否是同一个对象）。对于小整数（-5 到 256），Python 会缓存复用，所以 a is b 可能为 True，但这不是可靠的做法。

Python
# 算术运算符
print(10 / 3)      # 3.3333... (真除法)
print(10 // 3)     # 3  (整除，向下取整)
print(10 % 3)      # 1  (取余)
print(2 ** 10)     # 1024 (幂运算)
print(-7 // 2)     # -4  (向下取整，不是截断！)

# 链式比较 —— Python 独有的语法
x = 5
print(1 < x < 10)       # True
print(1 < x < 3 or 8 < x < 10)  # True

# is 与 == 的区别
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)     # True  (值相同)
print(a is b)     # False (不是同一个对象)

# 短路求值
# and: 第一个为假则返回第一个，否则返回第二个
# or:  第一个为真则返回第一个，否则返回第二个
result = None or "默认值"  # "默认值"
name = "Alice" or "Bob"   # "Alice" (短路)

6. 字符串

原理讲解：Python 字符串的不可变性

Python 字符串是不可变序列（immutable sequence）。这意味着一旦创建，字符串的内容不能被修改。每次对字符串的"修改"（如拼接、替换）实际上都会创建一个新的字符串对象。

这个设计有重要影响：频繁拼接字符串应该使用 list + join()，而不是 +=。因为每次 += 都会创建新字符串并复制已有内容，导致 O(n²) 的时间复杂度。

Python 字符串默认使用 UTF-8 编码，原生支持 Unicode 字符。字符串中的每个字符都是一个 Unicode 码点，可以用 ord() 获取码点，chr() 从码点创建字符。

# f-string 中可以嵌入表达式

print(f"{3.14159:.2f}")              # 3.14

7. 列表与元组

原理讲解：可变与不可变序列

列表（list）是 Python 中最常用的数据结构，它是可变序列，可以存储任意类型的对象。列表底层是一个动态数组（指针数组），当元素增加时会自动扩容。Python 的列表扩容策略是：新容量 = 旧容量 + (旧容量 >> 3) + 6，即约 12.5% 的增长。

元组（tuple）是不可变序列。一旦创建，不能添加、删除或修改元素。元组的主要优势：(1) 更省内存；(2) 可以作为字典的键；(3) 线程安全；(4) 语义上表示"不可变的数据集合"。

Python 3.12+ 中元组支持 x | y 语法进行连接，进一步提升了元组的易用性。

Python
# 列表操作
fruits = ["苹果", "香蕉", "橙子"]

# 增
fruits.append("葡萄")         # 末尾追加
fruits.insert(1, "芒果")      # 指定位置插入
fruits.extend(["西瓜", "樱桃"]) # 扩展列表

# 删
fruits.remove("香蕉")          # 按值删除（第一个匹配项）
popped = fruits.pop()         # 弹出末尾元素
del fruits[0]                 # 按索引删除

# 查
print("苹果" in fruits)        # True（成员检查）
print(fruits.index("橙子"))     # 返回索引
print(fruits.count("苹果"))     # 出现次数

# 列表切片（非常强大的特性）

nums[3:6] = [30, 40, 50]  # 切片赋值（可以改变长度）

# 列表排序
nums.sort()                     # 原地排序
nums.sort(reverse=True)          # 降序排序

8. 字典与集合

原理讲解：哈希表的魔法

Python 字典底层是哈希表（hash table），这是 Python 中查找速度最快的数据结构。字典的键必须是可哈希的（hashable），即实现了 __hash__() 方法且不可变。这就是为什么列表不能作为字典的键，但元组可以（如果元组中的所有元素也是可哈希的）。

Python 3.7+ 中，字典保持插入顺序（ordered by insertion）。Python 3.6 中 CPython 实现也保持顺序，但官方保证是从 3.7 开始的。

集合（set）也是基于哈希表实现的，它不存储重复元素，支持高效的成员测试（O(1)）和集合运算（交集、并集、差集）。

9. 条件判断

原理讲解：Python 的真值判断

Python 中以下值被视为 False：False、None、0（整数）、0.0（浮点数）、""（空字符串）、[]（空列表）、{}（空字典）、()（空元组）、set()（空集合）。其他所有值都为 True，包括非零数字、非空字符串、所有容器对象。

这个特性使得 Python 代码可以非常简洁：if items: 比 if len(items) > 0: 更 Pythonic。但要注意：数字 0 和空序列都为 False，所以在数字判断时要小心。

Python
# if-elif-else 结构

if score >= 90:
    grade = "优秀"
elif score >= 80:
    grade = "良好"
elif score >= 70:
    grade = "中等"
elif score >= 60:
    grade = "及格"
else:
    grade = "不及格"

# 三元表达式（条件表达式）

# match-case 模式匹配（Python 3.10+）

match command:
    case "start" | "go":      # 多个模式用 | 分隔
        print("启动程序")
    case "stop" | "quit":
        print("退出程序")
    case f"login {user}":       # 捕获模式

11. 推导式

原理讲解：推导式的本质与性能

推导式（comprehension）是 Python 中创建可迭代对象的语法糖。列表推导式在底层会被编译为一个专门的字节码指令 LIST_COMP，比等价的 for 循环 + append() 快约 20-30%，因为减少了函数调用的开销。

15. 作用域

原理讲解：LEGB 规则与闭包

Python 使用 LEGB 规则来查找变量：Local（局部作用域）→ Enclosing（闭包作用域）→ Global（模块全局作用域）→ Built-in（内置作用域）。当在当前作用域找不到变量时，会依次向外层查找。

闭包（closure）是函数和其引用的外部变量的组合。当内部函数引用了外部函数的变量，且外部函数已经返回后，这些变量仍然被内部函数"记住"。闭包是装饰器和函数式编程的核心机制。

nonlocal 关键字用于在内部函数中修改闭包作用域中的变量（Python 3+），global 用于修改模块全局变量。滥用这些关键字会破坏封装性，应该尽量避免。

Python
# LEGB 作用域
x = "全局变量"         # Global

def outer():
    x = "外层变量"     # Enclosing

    def inner():
        x = "局部变量" # Local
        print(x)        # 局部变量

    inner()
    print(x)            # 外层变量

outer()
print(x)               # 全局变量

# 闭包 —— 函数记住外部变量
def make_counter():
    count = 0
    def counter():
        nonlocal count    # 声明使用闭包作用域的变量
        count += 1
        return count
    return counter

print(my_counter())   # 1
print(my_counter())   # 2
print(my_counter())   # 3

16. 类与对象

原理讲解：Python 的对象模型

Python 的类是对象的蓝图。当你定义一个类时，Python 会创建一个类对象（type 类的实例）。当实例化时，Python 调用类的 __new__() 方法创建实例对象，然后调用 __init__() 方法初始化实例。

17. 继承与多态

原理讲解：MRO 与多继承

Python 支持多继承，一个类可以同时继承多个父类。这带来了菱形继承问题（Diamond Problem）：如果 A 继承 B 和 C，B 和 C 都继承 D，那么调用 A 的方法时应该走哪条路径？

Python 使用C3 线性化算法（C3 Linearization）来确定方法解析顺序（MRO，Method Resolution Order）。通过 ClassName.__mro__ 可以查看 MRO 顺序。C3 算法确保：(1) 子类在父类之前；(2) 多个父类保持声明顺序；(3) 不违反继承关系。

super() 在多继承中不是调用"父类"，而是调用 MRO 中的下一个类。理解这一点对于正确使用多继承至关重要。

Python
# 继承

    def __init__(self, name):
        self.name = name

    def speak(self):
        raise NotImplementedError("子类必须实现 speak 方法")

class Dog(Animal):
    def speak(self):
        return f"{self.name}说：汪汪！"

    def speak(self):
        return f"{self.name}说：喵喵！"

    print(animal.speak())   # 不需要知道具体类型，只要能 speak 就行

animal_sound(Cat("咪咪"))

# super() 在多继承中的使用
class A:
    def method(self):
        print("A.method")

class B(A):
    def method(self):
        print("B.method")
        super().method()   # 调用 MRO 中的下一个类

class C(A):
    def method(self):
        print("C.method")
        super().method()

class D(B, C):
    def method(self):
        print("D.method")
        super().method()

print(D.__mro__)
# (<class 'D'>, <class 'B'>, <class 'C'>, <class 'A'>, <class 'object'>)

d = D()
d.method()
# D.method → B.method → C.method → A.method

18. 魔术方法

原理讲解：魔术方法的运行机制

魔术方法（dunder methods）是 Python 的运算符重载和协议机制。当你写 a + b 时，Python 会调用 a.__add__(b)；当你用 len(obj) 时，Python 会调用 obj.__len__()。

这种机制使得自定义类可以像内置类型一样使用。比如实现 __iter__() 和 __next__() 就能让自定义类支持 for 循环，实现 __getitem__() 就能让类支持下标访问。

Python
# 常用魔术方法
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    # 字符串表示
    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

    def __str__(self):
        return f"({self.x}, {self.y})"

    # 运算符重载
    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

    def __mul__(self, scalar):
        return Vector(self.x * scalar, self.y * scalar)

    def __abs__(self):
        return (self.x**2 + self.y**2) ** 0.5

    # 比较运算
    def __eq__(self, other):
        return self.x == other.x and self.y == other.y

    # 可调用（函数式风格）
    def __len__(self):
        return 2

    # 支持下标访问
    def __getitem__(self, index):
        if index == 0: return self.x
        if index == 1: return self.y
        raise IndexError("Index out of range")

v2 = Vector(3, 4)

print(v1 * 3)       # (3, 6)

print(v1[0])        # 1

22. 装饰器

原理讲解：装饰器的运行时机制

装饰器本质上是一个高阶函数，它接受一个函数作为参数，返回一个新函数。@decorator 语法只是 func = decorator(func) 的语法糖。装饰器在模块加载时执行（函数定义时），不是在函数调用时执行。

带参数的装饰器是三层嵌套：@decorator(args) 等价于 func = decorator(args)(func)。最外层接收装饰器参数，中间层接收被装饰的函数，最内层是实际的包装函数。

functools.wraps 装饰器保留被装饰函数的 __name__、__doc__ 等元数据，是编写装饰器的必备工具。

Python
import functools
import time

# 基本装饰器
def timer(func):
    @functools.wraps(func)  # 保留原函数的元数据
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        elapsed = time.perf_counter() - start
        print(f"{func.__name__} 执行耗时: {elapsed:.4f}秒")
        return result
    return wrapper

@timer
def slow_function(n):
    time.sleep(n)
    return n

# 带参数的装饰器
def retry(max_attempts=3, delay=1):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(max_attempts):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    if attempt == max_attempts - 1:
                        raise
                    print(f"重试 {attempt+1}/{max_attempts}: {e}")
                    time.sleep(delay)
        return wrapper
    return decorator

@retry(max_attempts=3, delay=0.5)
def fetch_data(url):
    import requests
    return requests.get(url).json()

# 类装饰器
class CountCalls:
    def __init__(self, func):
        functools.update_wrapper(self, func)
        self.func = func
        self.count = 0

    def __call__(self, *args, **kwargs):
        self.count += 1
        print(f"{self.func.__name__} 被调用了 {self.count} 次")
        return self.func(*args, **kwargs)

@CountCalls
def say_hello():
    print("Hello!")

23. 生成器与迭代器

原理讲解：惰性求值的力量

迭代器是实现了 __iter__() 和 __next__() 方法的对象。每次调用 next() 返回下一个值，直到 StopIteration 异常。迭代器是一次性的——遍历完后不能重新开始。

生成器是使用 yield 关键字的特殊迭代器。当函数包含 yield 时，调用函数不会执行代码，而是返回一个生成器对象。每次调用 next()，函数执行到下一个 yield，返回 yield 的值，然后暂停执行，保留所有局部变量的状态。

生成器的核心优势：惰性求值——只在需要时才生成值，非常适合处理大数据流。生成器表达式 (x**2 for x in range(1000000)) 不会创建百万元素的列表，而是按需生成。

Python
# 生成器函数
def countdown(n):
    """倒计时生成器"""
    while n > 0:
        yield n         # 暂停并返回值
        n -= 1

# 使用生成器
for num in countdown(5):
    print(num)         # 5, 4, 3, 2, 1

# 生成器表达式（惰性求值）
# 列表推导式：一次性创建所有元素
squares_list = [x**2 for x in range(1000000)]  # 占用大量内存

# 生成器表达式：按需生成
squares_gen = (x**2 for x in range(1000000))  # 几乎不占内存

# yield from —— 委托生成器
def chain(*iterables):
    for it in iterables:
        yield from it     # 等价于 for item in it: yield item

list(chain([1, 2], [3, 4], [5, 6]))
# [1, 2, 3, 4, 5, 6]

24. 多线程与异步

原理讲解：GIL 的影响与选择

GIL（Global Interpreter Lock，全局解释器锁）是 CPython 解释器中的一个互斥锁，它确保同一时刻只有一个线程执行 Python 字节码。这意味着 Python 多线程无法利用多核 CPU 进行并行计算。

但 GIL 并不影响所有场景：I/O 密集型任务（网络请求、文件读写、数据库操作）在等待 I/O 时会释放 GIL，所以多线程仍然有效。CPU 密集型任务应该使用 multiprocessing 模块（多进程）来利用多核。

asyncio 是 Python 的异步 I/O 框架，使用协程（coroutine）实现单线程并发。协程比线程更轻量（没有上下文切换开销），适合高并发的网络应用。async/await 语法让异步代码看起来像同步代码。

Python
# 多线程 —— 适合 I/O 密集型任务

import time

    print(f"开始下载: {url}")
    time.sleep(2)  # 模拟 I/O 操作
    print(f"完成下载: {url}")

urls = ["url1", "url2", "url3"]

for t in threads:
    t.start()
for t in threads:
    t.join()

with ThreadPoolExecutor(max_workers=5) as executor:
    results = list(executor.map(download, urls))

# multiprocessing —— 适合 CPU 密集型任务
from multiprocessing import Pool

def cpu_heavy(n):
    return sum(i * i for i in range(n))

with Pool(processes=4) as pool:
    results = pool.map(cpu_heavy, [10**6] * 4])

25. 最佳实践与常见陷阱

原理讲解：Pythonic 代码的本质

"Pythonic"代码是指符合 Python 设计哲学和社区惯例的代码。PEP 8 是 Python 的代码风格指南，几乎所有 Python 项目都遵循它。但 Pythonic 不仅仅是格式——它是一种思维方式：用简洁、清晰、地道的方式解决问题。

Python 的核心原则：Simple is better than complex。当你的代码变得复杂时，先问问是否可以用更简单的方式实现。Python 的标准库提供了大量"开箱即用"的工具，很多情况下不需要自己造轮子。
