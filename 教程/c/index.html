C 语言教程

系统化学习 C 语言 —— 从环境搭建到指针与内存管理，深入底层原理，掌握系统编程的基石。

1. C 语言简介

C 语言由 Dennis Ritchie 于 1972 年在贝尔实验室开发，是一种通用的、过程式的编程语言。它是 Unix 操作系统的母语，也是 C++、Java、Python 等众多现代语言的祖先。

C 语言的核心特点

贴近硬件：C 提供对内存地址的直接操作能力，能高效访问底层硬件资源。

可移植性：C 编译器几乎覆盖所有平台，同一份代码稍作修改即可跨平台编译。

高效执行：编译型语言，生成机器码直接运行，性能接近汇编语言。

简洁语法：关键字仅 32 个（C89 标准），语法结构清晰紧凑。

C 语言的应用领域极其广泛：

  • 操作系统：Linux 内核、Windows 底层模块均用 C 编写
  • 嵌入式系统：单片机、DSP、物联网设备的首选语言
  • 数据库引擎：MySQL、PostgreSQL 等核心引擎
  • 编译器与解释器：Python、Ruby、PHP 的解释器均为 C 实现
  • 游戏引擎底层：图形渲染、物理引擎的性能关键路径

3. 基本语法

第一个程序

C 
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}
程序结构解析

#include <stdio.h>：预处理指令，将标准输入输出头文件的内容插入到当前位置。stdio.h 定义了 printf、scanf 等函数的声明。

int main(void)：程序入口函数。int 是返回类型，void 表示不接受任何参数。操作系统通过调用 main 函数来执行程序。

return 0;：向操作系统返回退出码。0 表示正常退出，非零值表示异常。

注释

C 
// 单行注释（C99 标准引入）

/*
 * 多行注释
 * 可以跨越多行
 * 但不能嵌套！
 */

/* 多行注释不能嵌套: /* 这会导致编译错误 */ */

语句与分号

C 语言中每条语句都以分号 ; 结尾。分号是语句终止符，不是分隔符。

C 
int x = 10;          // 声明并初始化
x = x + 5;            // 赋值语句
printf("%d\n", x);  // 函数调用语句

// 空语句（什么都不做）
;

花括号与代码块

花括号 { } 定义一个代码块（也叫复合语句），用于组织多条语句为一个逻辑单元。

C 
if (x > 0) {          // 代码块开始
    printf("正数\n");
    x = x - 1;
}                      // 代码块结束
代码块与变量作用域

在 C 语言中，变量的作用域由其所在的代码块决定。在代码块内部声明的变量，只能在该代码块内访问。这被称为块作用域（block scope）。理解作用域是理解变量生命周期和内存布局的基础。

内存对齐（Memory Alignment）

C 编译器会对结构体成员进行内存对齐，以提高 CPU 访问效率。例如，一个 int（4 字节）的地址通常是 4 的倍数。这意味着结构体的实际大小可能大于各成员大小之和。

示例：struct { char a; int b; } 占 8 字节而非 5 字节——a 后面有 3 字节的填充（padding），以确保 b 在 4 字节对齐的地址上。

了解内存对齐有助于理解结构体大小、网络协议解析和跨平台序列化。

extern声明变量/函数定义在其他文件中

5. 变量

变量是内存中一块有名字的存储区域，用于保存程序运行中的数据。

声明与初始化

C 
int age;                // 声明（未初始化，值不确定）
age = 25;               // 赋值

float salary = 8500.50;  // 声明并初始化

char grade = 'A';       // 字符用单引号

// C99+: 可以在代码块中的任意位置声明
for (int i = 0; i < 10; i++) {
    int temp = i * 2;  // 在 for 循环内声明
}
栈内存与变量生命周期

在函数内部声明的局部变量存储在栈（Stack）上。当函数被调用时，栈帧（stack frame）被创建，局部变量获得内存；当函数返回时，栈帧被弹出，这些变量的内存被自动释放。

关键特性：栈上未初始化的变量值是不确定的（垃圾值），使用未初始化的变量是 C 语言中最常见的 bug 来源之一。

栈内存的特点：分配/释放速度极快（仅移动栈指针），但容量有限（通常 1~8 MB），且函数返回后不可访问。

命名规则

  • 以字母或下划线开头，后跟字母、数字或下划线
  • 区分大小写：age 和 Age 是不同的变量
  • 不能使用关键字（如 int、return、if）
  • 建议使用有意义的名称：student_count 优于 sc

变量的作用域

C 
int global_var = 100;   // 全局变量（所有函数可见）

void foo(void) {
    int local_var = 20;  // 局部变量（仅 foo 可见）
    printf("%d\n", global_var);  // ✓ 可以访问全局变量
}

void bar(void) {
    printf("%d\n", global_var);  // ✓ 可以访问
    // printf("%d\n", local_var);  // ✗ 编译错误！
}

6. 运算符

算术运算符

C 
int a = 17, b = 5;

a + b   // 22   加法
a - b   // 12   减法
a * b   // 85   乘法
a / b   // 3    整数除法（截断小数）
a % b   // 2    取余（模运算）

// 浮点除法保留小数
double x = 17.0 / 5;   // x = 3.4
整数除法会截断小数部分（向零取整），而不是四舍五入。17 / 5 的结果是 3 而不是 3.4。

关系与逻辑运算符

运算符含义示例
==等于5 == 5 → 1
!=不等于5 != 3 → 1

>= / <=大于等于 / 小于等于5 >= 5 → 1
&&逻辑与1 && 0 → 0

自增自减

C 
int i = 5;

i++;    // 后置自增：先使用 i 的值(5)，再 i = 6
++i;    // 前置自增：先 i = 7，再使用 i 的值(7)
i--;    // 后置自减
--i;    // 前置自减

int a = 5;
int b = a++;  // b = 5, a = 6（先赋值后自增）
int c = ++a;  // c = 7, a = 7（先自增后赋值）

位运算符

C 
unsigned int a = 0b1100;  // 12
unsigned int b = 0b1010;  // 10

a & b   // 0b1000 = 8    按位与
a | b   // 0b1110 = 14   按位或
a ^ b   // 0b0110 = 6    按位异或
~a      // 按位取反
a << 2  // 0b110000 = 48 左移2位（×4）
a >> 1  // 0b0110 = 6    右移1位（÷2）

赋值运算符

C 
int x = 10;
x += 5;    // 等价于 x = x + 5   → 15
x -= 3;    // 等价于 x = x - 3   → 12
x *= 2;    // 等价于 x = x * 2   → 24
x /= 4;    // 等价于 x = x / 4   → 6

运算符优先级

优先级口诀

单目 > 算术 > 移位 > 关系 > 位运算 > 逻辑 > 赋值

单目运算符（! ++ -- & * sizeof）优先级最高，赋值运算符优先级最低。当不确定时，用括号明确优先级——这不会影响性能，但能让代码更清晰。

10. 函数定义与调用

函数是代码复用的基本单位，将一段逻辑封装为独立的模块。

函数定义

C 
// 返回类型 函数名(参数列表) { 函数体 }

int add(int a, int b) {
    return a + b;
}

void greet(const char *name) {
    printf("你好，%s!\n", name);
}

double circle_area(double radius) {
    return 3.14159 * radius * radius;
}

int main(void) {
    printf("%d\n", add(3, 5));         // 8
    greet("世界");
    printf("面积: %.2f\n", circle_area(5.0));
    return 0;
}
值传递（Pass by Value）

C 语言函数参数全部按值传递。调用函数时，实参的值被复制到形参中，函数内部对形参的修改不会影响实参。

如果需要在函数内修改外部变量，必须传递指针（地址）。这是 C 语言的一个重要设计决策——安全但需要显式操作。

C 
// 错误示例：无法通过值传递修改外部变量
void swap_wrong(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
    // 交换成功，但只交换了形参副本
}

// 正确示例：通过指针传递
void swap_right(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void) {
    int x = 10, y = 20;
    swap_wrong(x, y);   // x=10, y=20（未交换）
    swap_right(&x, &y); // x=20, y=10（交换成功）
    return 0;
}

11. 递归

递归是函数调用自身来解决问题的编程技巧。每个递归函数必须有基准情况（base case）来终止递归。

C 
// 阶乘：n! = n × (n-1)!
long long factorial(int n) {
    if (n <= 1) return 1;     // 基准情况
    return n * factorial(n - 1); // 递归调用
}

// 斐波那契数列
int fibonacci(int n) {
    if (n <= 1) return n;
    return fibonacci(n - 1) + fibonacci(n - 2);
}

// 递归求和：1 + 2 + ... + n
int sum(int n) {
    if (n == 0) return 0;
    return n + sum(n - 1);
}
递归的栈内存开销

每次递归调用都会在栈上创建一个新的栈帧，存储参数、局部变量和返回地址。如果递归过深（如没有正确设置基准情况），会导致栈溢出（stack overflow）。

优化策略：对于尾递归（递归调用是函数的最后一个操作），一些编译器（如 GCC 使用 -O2）会自动将递归优化为循环，避免栈溢出。

C 语言的默认栈大小通常为 1~8 MB。深层递归（如计算斐波那契数列的 fib(50)）会消耗大量栈空间。对于深度超过几千层的递归，应改用迭代实现。

12. 一维数组

数组是相同类型元素的有序集合，存储在连续的内存空间中。

C 
// 声明与初始化
int arr[5] = {10, 20, 30, 40, 50};
int zeros[10] = {0};          // 全部初始化为 0
int partial[5] = {1, 2};      // {1, 2, 0, 0, 0}
int auto_size[] = {1, 2, 3};  // 编译器自动推断大小为 3

// 访问元素（下标从 0 开始）
printf("第一个元素: %d\n", arr[0]);   // 10
printf("最后一个: %d\n", arr[4]);     // 50
printf("数组长度: %zu\n", sizeof(arr) / sizeof(arr[0]));
数组的内存布局

数组在内存中是连续存储的。对于 int arr[5]，如果 arr 的首地址是 0x1000，那么：

arr[0] 在 0x1000，arr[1] 在 0x1004（假设 int 占 4 字节），arr[2] 在 0x1008，以此类推。

这种连续性使得数组可以通过指针算术高效访问，也是数组和指针关系密切的根本原因。

C 语言不检查数组边界！访问 arr[5]（对于大小为 5 的数组）是未定义行为（undefined behavior），可能导致程序崩溃或数据损坏。程序员必须自己确保索引在有效范围内。

13. 二维数组

C 
// 二维数组：3 行 4 列
int matrix[3][4] = {
    {1,  2,  3,  4},   // 第 0 行
    {5,  6,  7,  8},   // 第 1 行
    {9,  10, 11, 12}   // 第 2 行
};

// 访问元素
printf("%d\n", matrix[1][2]);  // 7（第 1 行第 2 列）

// 遍历二维数组
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 4; j++) {
        printf("%3d ", matrix[i][j]);
    }
    printf("\n");
}
二维数组的内存本质

C 语言中二维数组实际上是一维数组的数组。matrix[3][4] 在内存中仍然是一块连续的空间，共 3 × 4 × sizeof(int) = 48 字节。

matrix[i] 本身是一个指向第 i 行首元素的指针。matrix[i][j] 等价于 *(*(matrix + i) + j)。这种理解对掌握指针与二维数组的关系至关重要。

14. 字符数组与字符串

C 语言没有原生的字符串类型，字符串本质上是以 '\0'（空字符）结尾的字符数组。

C 
// 字符串声明方式

char str2[10] = "Hello";       // 剩余元素初始化为 '\0'
char str3[] = {'H', 'i', '!', '\0'}; // 手动添加终止符

// 常用字符串函数
#include <string.h>

char dst[20];

strcpy(dst, src);      // 安全复制：dst = "Hello"
strncpy(dst, src, 3); // 只复制前 3 个字符
strcmp("abc", "abd"); // 返回负值（'c' < 'd'）
strcat(dst, " World"); // 拼接字符串
字符串在内存中的布局

对于 char str[] = "Hello";，内存中存储的是：

H(0x48) → e(0x65) → l(0x6C) → l(0x6C) → o(0x6F) → \0(0x00)

共占用 6 字节。字符串函数（如 strlen、strcpy）依赖 '\0' 来判断字符串结尾。如果忘记添加终止符，函数会继续读取越界内存，导致不可预测的行为。

使用 strcpy 时，目标缓冲区必须足够大。推荐使用 strncpy 或 snprintf 来防止缓冲区溢出。

15. 指针基础

指针是 C 语言最强大也最危险的特性。它存储的是变量的内存地址，而非变量的值。

C 
int x = 42;
int *p = &x;       // p 存储 x 的地址

printf("x 的值: %d\n", x);       // 42
printf("x 的地址: %p\n", (void *)&x); // 0x7fff5c... 之类
printf("p 的值: %p\n", (void *)p);  // 与 &x 相同
printf("p 指向的值: %d\n", *p);   // 42（解引用）

*p = 100;            // 通过指针修改 x 的值
printf("x = %d\n", x);         // 100
指针的内存布局

假设在 64 位系统上：

变量 x：地址 0x7FFE0000，存储值 42（0x2A），占 4 字节。

指针 p：地址 0x7FFF0000，存储值 0x7FFE0000（x 的地址），占 8 字节（64 位指针）。

指针本身也是一个变量，也占用内存空间。解引用（*p）就是通过指针中存储的地址，找到并操作那个内存位置。

指针运算

C 
int arr[] = {10, 20, 30, 40, 50};
int *p = arr;         // p 指向 arr[0]

*p          // 10   *(p + 0)
*(p + 1)    // 20   指针加 1，移动 sizeof(int) 字节
*(p + 2)    // 30

p + 3       // 地址值 = arr 的地址 + 3 × 4 = arr + 12 字节

// 指针相减得到元素个数
int *end = &arr[4];
ptrdiff_t len = end - p;  // len = 4
指针算术的原理

指针加 1 移动的字节数取决于指针指向的类型大小。p + 1 实际移动的是 sizeof(*p) 字节。

对于 int *p，p + 1 移动 4 字节（一个 int 的大小）。对于 double *p，p + 1 移动 8 字节。这就是 C 语言指针算术的类型感知特性。

void 指针（通用指针）

C 
// void* 可以指向任意类型，但不能直接解引用
int n = 42;
double d = 3.14;
void *vp;

vp = &n;                    // ✓ void* 可以接受任何类型指针
printf("%d\n", *(int *)vp);     // 必须强制转换后解引用: 42

vp = &d;
printf("%f\n", *(double *)vp);  // 3.140000

// malloc 返回 void*，这就是为什么需要强制转换
int *arr = (int *)malloc(10 * sizeof(int));

// 通用打印函数
void print_bytes(const void *data, size_t len) {
    const unsigned char *p = (const unsigned char *)data;
    for (size_t i = 0; i < len; i++) {
        printf("%02x ", p[i]);
    }
    printf("\n");
}

const 指针

C 
int x = 10, y = 20;

// 指向 const 的指针：不能通过指针修改值，但指针本身可改

// *p1 = 30;    // ✗ 编译错误
p1 = &y;       // ✓ 可以指向其他地址

// const 指针：指针不能改，但可以修改值
int *const p2 = &x;
*p2 = 30;       // ✓ 可以修改值
// p2 = &y;    // ✗ 编译错误

// 指向 const 的 const 指针：都不能改

// *p3 = 30;    // ✗
// p3 = &y;    // ✗

// 记忆技巧：const 在 * 左边 → 值不可改；const 在 * 右边 → 指针不可改

16. 指针与数组

在 C 语言中，数组名在大多数表达式中会隐式转换为指向首元素的指针。

C 
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;     // 等价于 int *p = &arr[0];

// 以下表达式等价
arr[2]  ≡  *(arr + 2)  ≡  *(p + 2)  ≡  p[2]

// 用指针遍历数组
for (int *p = arr; p < arr + 5; p++) {
    printf("%d ", *p);
}

// 数组名不是指针变量！
// arr = p;   // ✗ 编译错误：arr 是常量指针（地址不可修改）
p = arr;     // ✓ p 是变量，可以重新赋值
数组名与指针的区别

虽然数组名在大多数上下文中等同于指向首元素的指针，但它们不是同一个东西：

sizeof：sizeof(arr) 返回整个数组的大小（5 × 4 = 20），而 sizeof(p) 返回指针的大小（8 字节，64 位系统）。

赋值：数组名是地址常量，不能被赋值；指针是变量，可以被赋值。

&运算符：&arr 的类型是 int (*)[5]（指向数组的指针），与 arr 的值相同但类型不同。

17. 指针与函数

指针作为函数参数

C 
// 通过指针修改外部变量
void increment(int *p) {
    (*p)++;
}

// 返回多个值
void min_max(const int arr[], int n, int *min, int *max) {
    *min = arr[0];
    *max = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] < *min) *min = arr[i];
        if (arr[i] > *max) *max = arr[i];
    }
}

int main(void) {
    int x = 10;
    increment(&x);
    printf("x = %d\n", x);  // 11

    int arr[] = {3, 1, 4, 1, 5, 9};
    int min, max;
    min_max(arr, 6, &min, &max);
    printf("min=%d, max=%d\n", min, max);
    return 0;
}

函数返回指针

C 
// ⚠️ 危险：返回局部变量的指针

    int local = 42;
    return &local;  // ✗ 错误！local 在函数返回后被销毁
}

// ✓ 正确：返回 static 变量的指针

    static int counter = 0;
    counter++;
    return &counter;  // static 变量在函数返回后仍然存在
}

}
返回局部变量的地址是 C 语言中最危险的错误之一。局部变量存储在栈上，函数返回后栈帧被弹出，该地址的内存可能被其他函数覆盖，导致悬垂指针（dangling pointer）。

18. 多级指针

指针可以指向另一个指针，形成多级指针。

C 
int x = 100;
int *p = &x;       // 一级指针：指向 int
int **pp = &p;      // 二级指针：指向 int*
int ***ppp = &pp;   // 三级指针：指向 int**

printf("%d\n", x);       // 100
printf("%d\n", *p);      // 100
printf("%d\n", **pp);    // 100
printf("%d\n", ***ppp);  // 100

**pp = 200;            // 通过二级指针修改 x
printf("x = %d\n", x);  // 200
多级指针的内存布局

以二级指针为例：

int x = 100; → 地址 0x1000，值 100

int *p = &x; → 地址 0x2000，值 0x1000

int **pp = &p; → 地址 0x3000，值 0x2000

*pp 访问 0x2000，得到 0x1000。**pp 先解引用得到 0x1000，再解引用得到 100。

二级指针的实际用途

C 
// 在函数内修改指针本身（指向不同的地址）
void allocate(int **pp, int size) {
    *pp = malloc(size * sizeof(int));
    if (*pp == NULL) {
        perror("malloc");
    }
}

int main(void) {
    int *arr = NULL;
    allocate(&arr, 100);  // arr 现在指向动态分配的内存
    free(arr);
    return 0;
}

void bubble_sort(int arr[], int n, int (*cmp)(int, int)) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (cmp(arr[j], arr[j + 1]) > 0) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

20. 内存管理

理解 C 程序的内存布局是掌握内存管理的基础。

C 程序的内存布局

一个 C 程序在内存中的布局从低地址到高地址依次为：

1. 代码段（Text Segment）：存储编译后的机器指令，只读。所有函数的代码都在这里。

2. 只读数据段（Read-only Data / .rodata）：存储字符串字面量和 const 全局变量。

3. 已初始化数据段（Data Segment）：存储已初始化的全局变量和 static 变量。如 int global = 42;

4. 未初始化数据段（BSS Segment）：存储未初始化或初始化为 0 的全局变量和 static 变量。程序启动时由操作系统自动清零。

5. 堆（Heap）：动态内存分配区域，由程序员手动管理（malloc/free）。向高地址增长。

6. 栈（Stack）：存储局部变量、函数参数和返回地址。向低地址增长。由编译器自动管理。

C 
#include <stdio.h>
#include <stdlib.h>

int global_init = 42;           // 数据段（.data）
int global_uninit;               // BSS 段（.bss）
const char *str = "Hello";    // str 在 .data，"Hello" 在 .rodata

int main(void) {
    int local;                    // 栈（Stack）
    static int stat = 10;      // 数据段（.data）
    int *heap = malloc(sizeof(int)); // 堆（Heap）

    printf("代码段地址: %p\n", (void *)main);
    printf("数据段地址: %p\n", (void *)&global_init);
    printf("BSS段地址:  %p\n", (void *)&global_uninit);
    printf("栈地址:     %p\n", (void *)&local);
    printf("堆地址:     %p\n", (void *)heap);

    free(heap);
    return 0;
}
栈与堆的对比

栈（Stack）：由编译器自动管理，分配/释放仅需移动栈指针（极快）。容量有限（通常 1~8 MB）。函数返回后自动释放。适合存储局部变量和小型数组。

堆（Heap）：由程序员手动管理（malloc/free）。分配/释放需要搜索空闲块（相对较慢）。容量几乎无限制（受限于物理内存）。生命周期由程序员控制。适合存储大型数据和生命周期跨越多个函数的数据。

21. 动态内存分配

C 
#include <stdlib.h>

// malloc：分配指定字节数的内存，不初始化
int *arr = (int *)malloc(10 * sizeof(int));
if (arr == NULL) {
    perror("malloc");
    return 1;
}

// calloc：分配并初始化为零
int *arr2 = (int *)calloc(10, sizeof(int));  // 所有元素为 0

// realloc：重新分配内存（调整大小）
int *temp = (int *)realloc(arr, 20 * sizeof(int));
if (temp != NULL) {
    arr = temp;
}

// 使用完毕后释放
free(arr);
free(arr2);
动态内存分配的底层机制

malloc 通过系统调用（Linux 上是 brk/mmap）向操作系统申请内存。操作系统维护一个空闲内存链表（free list），malloc 在其中寻找足够大的空闲块，将其分割并返回给用户。

free 将内存归还到空闲链表中。如果释放的内存块与相邻空闲块连续，free 会将它们合并（coalescing）成一个更大的空闲块。

内存碎片：频繁分配和释放不同大小的内存块会导致外部碎片——空闲内存总量足够但分散，无法满足大块分配请求。

常见内存错误

内存泄漏（Memory Leak）：分配了内存但忘记释放。程序运行时不断消耗内存，最终可能导致系统内存耗尽。
C 
// ✗ 内存泄漏
void leak(void) {
    int *p = malloc(100 * sizeof(int));
    if (p == NULL) return;
    // 使用 p...
    return;  // ✗ 忘记 free(p)
}

// ✓ 正确做法
void no_leak(void) {
    int *p = malloc(100 * sizeof(int));
    if (p == NULL) return;
    // 使用 p...
    free(p);
    p = NULL;  // 防止悬垂指针
}

// ✗ 重复释放（double free）
int *p = malloc(4);
free(p);
free(p);  // ✗ 未定义行为！

// ✗ 使用已释放的内存
free(p);
printf("%d\n", *p);  // ✗ 未定义行为！
最佳实践：free 之后立即将指针设为 NULL。这不能防止所有问题，但能避免大部分"悬垂指针"类型的 bug。使用 valgrind 或 AddressSanitizer 工具来检测内存错误。

realloc 动态扩容模式

C 
// 动态数组：按需增长
int *arr = NULL;
size_t cap = 0, len = 0;

void push_back(int value) {
    if (len == cap) {
        size_t new_cap = cap == 0 ? 4 : cap * 2;
        int *temp = (int *)realloc(arr, new_cap * sizeof(int));
        if (temp == NULL) {
            perror("realloc");
            return;
        }
        arr = temp;
        cap = new_cap;
    }
    arr[len++] = value;
}

int main(void) {
    for (int i = 0; i < 20; i++) {
        push_back(i * 10);
    }
    // 扩容过程: 0→4→8→16→32 (指数增长，摊还 O(1))
    free(arr);
    return 0;
}

内存泄漏检测与防御

C 
// 用宏包装 malloc/free 追踪分配
#define TRACKED_MALLOC(size) \
    (track_malloc(size, __FILE__, __LINE__))

static int alloc_count = 0;

void *track_malloc(size_t size, const char *file, int line) {
    void *p = malloc(size);
    if (p) alloc_count++;
    return p;
}

void track_free(void *p) {
    if (p) {
        alloc_count--;
        free(p);
    }
}

// 程序退出前检查
void check_leaks(void) {
    if (alloc_count > 0) {
        fprintf(stderr, "警告: %d 次内存未释放!\n", alloc_count);
    }
}

结构体作为函数参数

C 
// ⚠️ 传值：整个结构体被复制，效率低
void print_student(struct Student s) {
    printf("%s: %.1f\n", s.name, s.gpa);
}

// ✓ 传指针：只复制一个地址，高效
void update_gpa(struct Student *ps, float new_gpa) {
    ps->gpa = new_gpa;
}

// ✓ const 指针：只读，兼顾效率和安全
void print_student2(const struct Student *ps) {
    printf("%s: %.1f\n", ps->name, ps->gpa);
}
结构体内存对齐

C 编译器会对结构体成员进行内存对齐，以优化 CPU 的内存访问效率。规则通常为：每个成员的起始地址必须是其类型大小的整数倍。

示例：struct { char a; int b; char c; } 在大多数平台上占 12 字节而非 6 字节：a(1) + padding(3) + b(4) + c(1) + padding(3) = 12。

成员按从大到小的顺序排列可以减少填充：struct { int b; char a; char c; } 只占 8 字节。

使用 #pragma pack(1) 可以消除对齐填充，但可能降低性能，且在某些硬件平台上会导致未定义行为。

结构体对齐实战

C 
#include <stdio.h>

struct Bad {
    char a;    // 1 字节 + 3 字节填充
    int b;     // 4 字节
    char c;    // 1 字节 + 3 字节填充
};  // sizeof = 12

struct Good {
    int b;     // 4 字节（最大对齐要求）
    char a;    // 1 字节 + 1 字节填充
    char c;    // 1 字节 + 1 字节填充
};  // sizeof = 8（节省 33%）

#pragma pack(push, 1)
struct Packed {
    char a;
    int b;
    char c;
};  // sizeof = 6（无填充，但可能影响性能）
#pragma pack(pop)

int main(void) {
    printf("Bad:  %zu\n", sizeof(struct Bad));   // 12
    printf("Good: %zu\n", sizeof(struct Good));  // 8
    printf("Pack: %zu\n", sizeof(struct Packed)); // 6
    return 0;
}

链表实现

C 
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *next;
} Node;

// 头插法
void push_front(Node **head, int val) {
    Node *n = (Node *)malloc(sizeof(Node));
    n->data = val;
    n->next = *head;
    *head = n;
}

// 遍历打印
void print_list(Node *head) {
    for (Node *p = head; p; p = p->next) {
        printf("%d → ", p->data);
    }
    printf("NULL\n");
}

// 释放链表
void free_list(Node *head) {
    while (head) {
        Node *tmp = head;
        head = head->next;
        free(tmp);
    }
}

int main(void) {
    Node *list = NULL;
    push_front(&list, 3);
    push_front(&list, 2);
    push_front(&list, 1);
    print_list(list);  // 1 → 2 → 3 → NULL
    free_list(list);
    return 0;
}

联合体（union）

C

联合体的内存布局

联合体的所有成员从同一地址开始存储。修改任何一个成员都会影响其他成员。联合体的大小等于最大成员的大小（考虑对齐后）。

联合体常用于：类型双关（type punning）——用不同的类型解释同一块内存数据，例如查看浮点数的二进制表示。

25. 位运算

位运算直接操作二进制位，是系统编程和底层优化的重要工具。

C 
// 常用位运算技巧
unsigned int x = 0b10110100;

// 1. 判断奇偶
if (x & 1) {
    printf("奇数\n");
} else {
    printf("偶数\n");
}

// 2. 乘以/除以 2 的幂
x << 1;   // ×2
x << 3;   // ×8
x >> 1;   // ÷2

// 3. 设置/清除/翻转特定位
x |= (1 << 3);     // 设置第 3 位
x &= ~(1 << 3);    // 清除第 3 位
x ^= (1 << 3);     // 翻转第 3 位

// 4. 检查第 n 位是否为 1
int is_set = (x >> 3) & 1;

// 5. 不使用临时变量交换两个数
a ^= b;
b ^= a;
a ^= b;
位运算的性能优势

位运算直接在 CPU 的算术逻辑单元（ALU）上执行，通常只需一个时钟周期，远快于乘除法运算。在嵌入式系统和高性能计算中，用位运算替代算术运算可以显著提升性能。

左移 n 位等价于乘以 2ⁿ，右移 n 位等价于除以 2ⁿ（无符号数）。编译器在优化时也会自动将乘除 2 的幂转换为移位操作。

位掩码与标志位

C 
// 用位掩码表示权限
#define PERM_READ    (1 << 0)   // 0b0001
#define PERM_WRITE   (1 << 1)   // 0b0010
#define PERM_EXEC    (1 << 2)   // 0b0100
#define PERM_DELETE  (1 << 3)   // 0b1000

unsigned int perms = PERM_READ | PERM_WRITE;  // 0b0011

// 检查是否有某个权限
if (perms & PERM_WRITE) {
    printf("有写权限\n");
}

// 添加权限
perms |= PERM_EXEC;

// 移除权限
perms &= ~PERM_WRITE;

位操作进阶技巧

C 
// 统计二进制中 1 的个数（Brian Kernighan 算法）
int popcount(unsigned int x) {
    int count = 0;
    while (x) {
        x &= (x - 1);  // 消除最低位的 1
        count++;
    }
    return count;
}

// 判断是否为 2 的幂
int is_power_of_two(unsigned int x) {
    return x > 0 && (x & (x - 1)) == 0;
}

// 取特定位段（bit field extraction）
unsigned int get_bits(unsigned int val, int pos, int len) {
    return (val >> pos) & ((1 << len) - 1);
}

// 交换两个数（不用临时变量）
void swap_xor(int *a, int *b) {
    if (a != b) {
        *a ^= *b;
        *b ^= *a;
        *a ^= *b;
    }
}

int main(void) {
    printf("popcount(0b10110100) = %d\n", popcount(0b10110100));  // 4
    printf("%s\n", is_power_of_two(16) ? "是" : "否");  // 是
    printf("bits[3:1] of 0b11010 = %d\n", get_bits(0b11010, 1, 3));  // 5
    return 0;
}

26. 文件 I/O

文件操作是 C 语言的重要组成部分，支持文本和二进制两种模式。

二进制文件读写

C 
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int id;
    char name[32];
    double score;
} Record;

int main(void) {
    // 写入二进制文件
    Record records[] = {
        {1, "Alice", 95.5},
        {2, "Bob",   87.3},
        {3, "Carol", 92.1}
    };
    int n = 3;

    FILE *fp = fopen("records.dat", "wb");
    if (!fp) { perror("fopen"); return 1; }
    fwrite(records, sizeof(Record), n, fp);
    fclose(fp);

    // 读取二进制文件
    fp = fopen("records.dat", "rb");
    Record buf;
    while (fread(&buf, sizeof(Record), 1, fp) == 1) {
        printf("ID=%d Name=%s Score=%.1f\n", buf.id, buf.name, buf.score);
    }
    fclose(fp);
    return 0;
}

文件定位（fseek / ftell / rewind）

C 
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("data.bin", "w+b");

    // 写入数据
    int nums[] = {10, 20, 30, 40, 50};
    fwrite(nums, sizeof(int), 5, fp);

    // ftell: 获取当前文件位置
    printf("当前位置: %ld\n", ftell(fp));  // 20（5×4字节）

    // fseek: 移动到文件开头
    fseek(fp, 0, SEEK_SET);

    // 读取第 3 个元素（offset=8 字节）
    fseek(fp, 2 * sizeof(int), SEEK_SET);
    int val;
    fread(&val, sizeof(int), 1, fp);
    printf("第3个元素: %d\n", val);  // 30

    // rewind: 回到开头
    rewind(fp);

    // fseek + SEEK_END: 获取文件大小
    fseek(fp, 0, SEEK_END);
    long size = ftell(fp);
    printf("文件大小: %ld 字节\n", size);  // 20

    fclose(fp);
    return 0;
}

27. 最佳实践与常见陷阱

常见陷阱

1. 缓冲区溢出：不检查边界地写入数组，可能覆盖其他变量的数据，甚至被利用执行恶意代码。
C 
// ✗ 危险
char buf[10];
gets(buf);              // 永远不要用 gets！
strcpy(buf, long_str);  // 不检查长度

// ✓ 安全
fgets(buf, sizeof(buf), stdin);
strncpy(buf, long_str, sizeof(buf) - 1);
buf[sizeof(buf) - 1] = '\0';
2. 整数溢出：有符号整数溢出是未定义行为。无符号整数溢出虽然定义明确（回绕），但通常是逻辑错误。
C 
int a = 2147483647;  // INT_MAX
a = a + 1;            // ✗ 有符号溢出 → 未定义行为！

// ✓ 安全检查
if (a > INT_MAX - 1) {
    printf("溢出!\n");
} else {
    a = a + 1;
}
3. 野指针与悬垂指针：使用未初始化的指针或已释放内存的指针。
C 
int *p;            // ✗ 未初始化，指向随机地址
*p = 42;            // ✗ 未定义行为

int *p2 = NULL;    // ✓ 初始化为 NULL
// if (p2 != NULL) *p2 = 42;  ✓ 安全检查后使用
4. scanf 格式化字符串漏洞：格式化字符串中不匹配的类型说明符可能导致崩溃或安全漏洞。

最佳实践清单

  • 始终编译时开启警告：gcc -Wall -Wextra -Wpedantic
  • 使用 static 分析工具：Clang Static Analyzer、Cppcheck
  • 使用内存检测工具：Valgrind、AddressSanitizer（-fsanitize=address）
  • const 正确性：不会修改的参数用 const 修饰
  • 避免魔数：用 #define 或 enum 给常量起名字
  • 限制函数长度：一个函数不超过 50~100 行
  • 单函数单职责：每个函数只做一件事
  • 检查所有 malloc 返回值：确保分配成功
  • 释放后置 NULL：避免悬垂指针
  • 使用 size_t 表示大小：sizeof 的返回类型是 size_t
  • 优先使用 fgets 而非 gets：gets 已在 C11 标准中被移除
  • 使用_snprintf 替代 sprintf：防止缓冲区溢出
安全编程的黄金法则：永远不要信任外部输入。所有来自用户、文件或网络的数据在使用前都必须进行验证和清洗。C 语言给了程序员最大的自由，也要求程序员承担最大的责任。
C 语言学习路线建议

入门阶段：掌握基本语法、数据类型、控制流、函数和数组。

核心阶段：深入理解指针、内存管理和字符串操作。这是 C 语言的精髓。

进阶阶段：学习结构体、文件 I/O、预处理器、位运算和多文件项目组织。

实战阶段：通过小型项目巩固知识——实现简单链表、二叉树、文件解析器、网络编程等。
