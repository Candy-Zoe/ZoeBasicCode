CSS 全面教程

从基础语法到高级布局，从盒模型到 GPU 合成层——一份覆盖 27 个核心主题的 CSS 深度指南。

1. CSS 简介

CSS（Cascading Style Sheets，层叠样式表）是用来描述 HTML 文档样式的语言。它控制页面的布局、颜色、字体、间距等视觉表现。

CSS 的三大核心特性

  • 层叠（Cascading）：多个样式规则可以作用于同一元素，浏览器按优先级决定最终生效的样式。
  • 继承（Inheritance）：子元素会自动继承父元素的部分属性值（如 color、font-family）。
  • specificity（特异性）：当多条规则冲突时，浏览器根据选择器的权重计算结果来决定哪条规则胜出。
层叠机制原理

CSS 的"C"代表 Cascading。当浏览器遇到多条匹配同一元素的规则时，会按以下顺序决定胜出者：

1. 出处：作者样式 > 用户代理样式（浏览器默认）> 用户样式

2. 特异性（Specificity）：权重高的规则胜出（详见第 21 节）

3. 源顺序：权重相同时，后出现的规则覆盖先出现的

CSS 
/* CSS 规则的基本结构 */
选择器 {
    属性: 值;      /* 声明 */
    属性: 值;      /* 多条声明用分号分隔 */
}

/* 示例：将所有段落设为蓝色 */
p {
    color: #334155;
    line-height: 1.6;
}

2. 引入方式

CSS 有三种引入方式：外部样式表、内部样式表和内联样式。

外部样式表（推荐）

通过 <link> 标签引入独立的 CSS 文件，实现样式与结构分离。

HTML 
<!-- 外部样式表 -->
<link rel="stylesheet" href="styles.css">

<!-- 带媒体查询的外部样式表 -->
<link rel="stylesheet" href="print.css" media="print">

<!-- 预加载关键 CSS -->
<link rel="preload" href="critical.css" as="style">

内部样式表

在 <style> 标签内直接编写 CSS，适用于单页面样式。

HTML 
<style>
    body {
        margin: 0;
        padding: 0;
        font-family: 'Segoe UI', sans-serif;
    }

    .container {
        max-width: 1200px;
        margin: 0 auto;
    }
</style>

内联样式

直接在 HTML 元素的 style 属性中编写，优先级最高但不推荐使用。

HTML 
<!-- 内联样式 -->
<p style="color: red; font-size: 16px;">内联样式</p>
引入方式优先级

内联样式 > 内部/外部样式（按源顺序）。当 !important 出现时，优先级被提升到最高。实际开发中，始终使用外部样式表，保持关注点分离。

3. 选择器

选择器决定了 CSS 规则应用于哪些 HTML 元素。CSS 提供了丰富且强大的选择器体系。

基础选择器

CSS 
/* 通配选择器 */
* { margin: 0; padding: 0; }

/* 元素选择器 */
p { color: #333; }

/* 类选择器 */
.highlight { background: yellow; }

/* ID 选择器 */
#header { height: 64px; }

/* 属性选择器 */
a[href] { color: blue; }
input[type="text"] { border: 1px solid #ccc; }
a[href^="https"] { color: green; }
a[href$=".pdf"] { color: red; }
a[href*="github"] { color: purple; }

组合选择器

CSS 
/* 后代选择器（空格）*/
.container p { margin: 10px 0; }

/* 子选择器（>）*/
.nav > li { display: inline-block; }

/* 相邻兄弟选择器（+）*/
h2 + p { margin-top: 0; }

/* 通用兄弟选择器（~）*/
h2 ~ p { color: gray; }

/* 分组选择器（,）*/
h1, h2, h3 { font-weight: bold; }

伪类与伪元素选择器

CSS 
/* 链接状态 */
a:hover { color: red; }
a:active { color: darkred; }
a:visited { color: purple; }
a:focus { outline: 2px solid blue; }

/* 结构伪类 */
li:first-child { font-weight: bold; }
li:last-child { border-bottom: none; }
li:nth-child(2n) { background: #f5f5f5; }
li:nth-child(3n+1) { color: red; }
p:not(.special) { color: gray; }

/* 伪元素 */
p::before { content: '📌 '; }
p::after { content: ' ✅'; }
::selection { background: #6366f1; color: white; }
CSS 选择器从右向左匹配。例如 .nav li a 先找所有 a，再向上检查是否在 li 内，最后确认是否在 .nav 内。编写选择器时应尽量避免过深的嵌套。

4. 盒模型

每个 HTML 元素都可以看作一个矩形盒子，由 content、padding、border 和 margin 四层组成。

标准盒模型 vs IE 盒模型

标准盒模型（content-box）：设置的 width 仅包含内容区域，padding 和 border 额外增加元素尺寸。

IE 盒模型（border-box）：设置的 width 包含内容 + padding + border。实际使用中 border-box 更直观，是现代开发的首选。

CSS 
/* 使用 border-box 让布局更直观 */
* {
    box-sizing: border-box;
}

.box {
    width: 300px;
    padding: 20px;
    border: 2px solid #333;
    margin: 16px auto;
    /* 实际宽度仍然是 300px（border-box）*/
    /* 如果是 content-box，实际宽度 = 300 + 40 + 4 = 344px */
}

/* margin 合并（外边距塌陷）*/
.parent {
    background: #f0f0f0;
    height: 200px;
}

.parent p {
    margin-top: 50px;  /* 不会生效，与父元素 margin 合并 */
}

/* 解决 margin 合并的方法 */
.parent {
    overflow: hidden;  /* 或 padding-top / border-top */
}

5. 单位

CSS 提供了绝对单位和相对单位两大类，合理选择单位是响应式设计的基础。

绝对单位

单位说明典型用途
px像素，屏幕上的物理点边框宽度、固定尺寸
pt印刷点（1pt = 1/72 英寸）打印样式
cm / mm厘米/毫米打印样式

相对单位（推荐）

单位相对于典型用途
em父元素的 font-size内边距、组件间距
rem根元素的 font-size（html）字体大小、间距
%父元素的对应属性值宽度、响应式布局
vw / vh视口宽度 / 高度的 1%全屏布局、视口单位
vmin / vmax视口较小 / 较大维度的 1%自适应正方形
ch"0" 字符的宽度每行字符数限制
ex / capx-height / 大写字母高度微调对齐
clamp()最小值 ~ 首选值 ~ 最大值流式排版
CSS 
/* 使用 rem 实现响应式字体 */
html {
    font-size: 16px;
}

h1 {
    font-size: 2rem;      /* 32px */
    line-height: 1.2;
}

p {
    font-size: 1rem;      /* 16px */
}

/* clamp() 实现流式排版：最小 16px，首选 2vw + 1rem，最大 24px */
p {
    font-size: clamp(1rem, 2vw + 0.5rem, 1.5rem);
}

/* 使用 vw 做全屏英雄区 */
.hero {
    min-height: 100vh;
    display: grid;
    place-items: center;
}

/* 使用 ch 限制每行字数（约 65-75 字符最佳可读性）*/
.article {
    max-width: 65ch;
}

6. 颜色

CSS 提供了多种颜色表示法，每种都有其适用场景。

CSS 
/* 关键字颜色 */
.text { color: red; }

/* 十六进制 */
.text { color: #6366f1; }           /* 6位 */
.text { color: #6366f1cc; }         /* 8位（含透明度）*/

/* RGB / RGBA */
.text { color: rgb(99, 102, 241); }
.text { color: rgb(99 102 241 / 0.8); }  /* 现代空格语法 */

/* HSL / HSLA（推荐：直观调节色调、饱和度、亮度）*/
.text { color: hsl(239, 84%, 67%); }
.text { color: hsl(239 84% 67% / 0.8); }

/* oklch（感知均匀色彩空间，新标准）*/
.text { color: oklch(0.62 0.2 264); }

/* color-mix() 动态混色 */
.text { color: color-mix(in oklch, var(--primary), white 30%); }
HSL（色相-饱和度-亮度）比 RGB 更直观：hsl(239, 84%, 67%) 表示"蓝色调、高饱和度、中等亮度"。CSS 自定义属性结合 color-mix() 可以动态生成主题色的变体。

7. 字体与文本

CSS 
body {
    /* 字体族回退机制 */
    font-family: 'Inter', 'Noto Sans SC', system-ui, sans-serif;

    /* 字体大小 */
    font-size: 16px;

    /* 字重：100(Thin) ~ 900(Black) */
    font-weight: 400;  /* normal */
    font-weight: 700;  /* bold */

    /* 行高：推荐无单位值（相对于字号）*/
    line-height: 1.6;  /* 比 24px 更灵活 */

    /* 字间距 */
    letter-spacing: 0.5px;

    /* 单词间距 */
    word-spacing: 4px;

    /* 文本装饰 */
    text-decoration: underline wavy #6366f1;
    text-decoration-thickness: 2px;
    text-underline-offset: 4px;

    /* 文本溢出处理 */
    text-overflow: ellipsis;
    white-space: nowrap;
    overflow: hidden;

    /* 多行文本截断 */
    display: -webkit-box;
    -webkit-line-clamp: 3;
    -webkit-box-orient: vertical;

    /* 文字渲染优化 */
    text-rendering: optimizeLegibility;
    -webkit-font-smoothing: antialiased;
}

@font-face 自定义字体

CSS 
@font-face {
    font-family: 'CustomFont';
    src: url('./fonts/custom.woff2') format('woff2'),
         url('./fonts/custom.woff') format('woff');
    font-weight: 100 900;   /* 可变字重 */
    font-style: normal;
    font-display: swap;    /* 先用回退字体，加载后替换 */
}
line-height 建议使用无单位值（如 1.6），它会根据当前 font-size 自动计算，比固定像素值更灵活。

8. Flexbox 弹性布局

Flexbox 是一维布局模型，最适合处理行方向或列方向的元素排列。它能轻松实现居中、等分布局、自适应宽度等常见需求。

主轴与交叉轴

Flexbox 的核心概念是主轴（main axis）和交叉轴（cross axis）。

主轴由 flex-direction 决定：默认 row（水平从左到右），设为 column 后变为垂直方向。

交叉轴始终与主轴垂直：row 时交叉轴为垂直方向，column 时为水平方向。

所有对齐属性（justify-content、align-items、align-self）都基于这两条轴工作。justify-content 沿主轴排列，align-items 沿交叉轴排列。

CSS 
/* 容器属性（父元素）*/
.flex-container {
    display: flex;

    /* 主轴方向 */
    flex-direction: row;           /* 水平从左到右（默认）*/
    flex-direction: row-reverse;   /* 水平从右到左 */
    flex-direction: column;        /* 垂直从上到下 */
    flex-direction: column-reverse; /* 垂直从下到上 */

    /* 换行控制 */
    flex-wrap: nowrap;             /* 不换行（默认）*/
    flex-wrap: wrap;              /* 换行 */

    /* 主轴对齐 */
    justify-content: flex-start;   /* 起点对齐 */
    justify-content: flex-end;     /* 终点对齐 */
    justify-content: center;      /* 居中 */
    justify-content: space-between; /* 两端贴边，中间均匀 */
    justify-content: space-around; /* 每个元素两侧等间距 */
    justify-content: space-evenly; /* 所有间距完全相等 */

    /* 交叉轴对齐 */
    align-items: stretch;         /* 拉伸填满（默认）*/
    align-items: center;         /* 交叉轴居中 */
    align-items: flex-start;      /* 交叉轴起点 */
    align-items: flex-end;        /* 交叉轴终点 */

    /* 多行时的交叉轴对齐 */
    align-content: center;

    /* 间距（替代 margin-right/bottom）*/
    gap: 16px;
    row-gap: 16px;
    column-gap: 24px;
}

/* 子元素属性 */
.flex-item {
    /* 放大比例：剩余空间的分配权重，0 = 不放大 */
    flex-grow: 1;

    /* 缩小比例：空间不足时的缩小权重，0 = 不缩小 */
    flex-shrink: 0;

    /* 初始基准大小 */
    flex-basis: 200px;            /* 固定值 */
    flex-basis: auto;            /* 由 width 决定 */
    flex-basis: 30%;             /* 百分比 */

    /* 简写：flex: grow shrink basis */
    flex: 1;                    /* 等分剩余空间 */
    flex: 0 0 200px;            /* 固定 200px，不伸缩 */
    flex: 1 1 auto;             /* 常见的自适应组合 */

    /* 单个元素在交叉轴上的对齐 */
    align-self: center;          /* 覆盖容器的 align-items */
    align-self: flex-end;

    /* 排列顺序（数值越小越靠前）*/
    order: -1;
}

Flexbox 经典布局

CSS 
/* 圣杯布局：header + (sidebar + main) + footer */
.page {
    display: flex;
    flex-direction: column;
    min-height: 100vh;
}

.page-body {
    display: flex;
    flex: 1;               /* 占满剩余空间 */
}

.sidebar { width: 260px; flex-shrink: 0; }
.main    { flex: 1; }       /* 主内容自适应 */

/* 水平垂直居中 */
.center-everything {
    display: flex;
    justify-content: center;
    align-items: center;
    min-height: 100vh;
}

/* 导航栏：左侧 logo + 右侧菜单 */
.navbar {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 0 24px;
    height: 64px;
}

/* 等宽三列 */
.cols-3 {
    display: flex;
    gap: 20px;
}
.cols-3 > * {
    flex: 1;
}

9. Grid 网格布局

CSS Grid 是二维布局系统，可以同时控制行和列。它是构建复杂页面布局（如仪表盘、画廊、杂志排版）的首选方案。

Grid 轨道与区域

轨道（Tracks）：行和列的统称。通过 grid-template-rows 和 grid-template-columns 定义。

网格线（Grid Lines）：行和列之间的分界线，编号从 1 开始。元素通过网格线定位（如 grid-column: 1 / 3 跨 2 列）。

网格区域（Grid Areas）：用 grid-template-areas 命名布局区域，然后用 grid-area 将元素放入指定区域，使布局语义化且可视化。

fr 单位：分配可用空间的分数。如 grid-template-columns: 1fr 2fr 1fr 表示三列按 1:2:1 分配。

CSS 
/* 定义网格轨道 */
.grid {
    display: grid;

    /* 固定列 + 自适应列 */
    grid-template-columns: 260px 1fr 1fr;
    grid-template-rows: auto 1fr auto;

    /* 重复轨道 */
    grid-template-columns: repeat(3, 1fr);     /* 3 等分 */
    grid-template-columns: repeat(auto-fill, minmax(250px, 1fr)); /* 自适应列数 */
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

    /* 间距 */
    gap: 16px;

    /* 对齐 */
    justify-items: center;   /* 水平居中 */
    align-items: start;      /* 顶部对齐 */
}

/* 命名区域布局 */
.layout {
    display: grid;
    grid-template-columns: 260px 1fr;
    grid-template-rows: 64px 1fr 60px;
    grid-template-areas:
        "header  header"
        "sidebar main"
        "footer  footer";
    min-height: 100vh;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

Grid 子元素定位

CSS 
/* 通过网格线定位 */
.feature {
    grid-column: 1 / 3;        /* 从第1条线到第3条线 = 跨2列 */
    grid-row: 1 / 2;
}

/* 使用 span 关键字 */
.sidebar {
    grid-column: span 1;       /* 跨1列 */
}

/* 子元素单独对齐 */
.card {
    justify-self: stretch;    /* 水平撑满 */
    align-self: center;       /* 垂直居中 */
}

/* auto-fill vs auto-fit */
/* auto-fill: 填满行，即使没有子元素也占位 */
/* auto-fit: 折叠空轨道，子元素可以撑满 */
.gallery {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
    gap: 20px;
}
auto-fit 和 auto-fill 的关键区别：auto-fit 会折叠空的轨道（让内容撑满容器），auto-fill 会保留空轨道。一般画廊/卡片用 auto-fit 更合适。

10. 定位

CSS 定位机制允许你将元素从正常的文档流中移出，精确控制其在页面上的位置。

CSS 
/* static：默认，不参与定位 */
.static { position: static; }

/* relative：相对自身原始位置偏移，仍占据原空间 */
.relative {
    position: relative;
    top: 10px;
    left: 20px;
    /* 常用作 absolute 定位的参照容器 */
}

/* absolute：相对最近的已定位祖先元素（position 非 static）偏移，脱离文档流 */
.parent {
    position: relative;
}

.child {
    position: absolute;
    top: 0;
    right: 0;
    /* 不占据空间 */
}

/* fixed：相对视口定位，始终固定在屏幕某位置 */
.fixed-nav {
    position: fixed;
    top: 0;
    left: 0;
    right: 0;
    z-index: 1000;
}

/* sticky：滚动到阈值前相对定位，之后固定 */
.sticky-header {
    position: sticky;
    top: 0;
    z-index: 100;
    background: white;
}

/* 绝对居中的经典方案 */
.absolute-center {
    position: absolute;
    inset: 0;              /* 等同于 top:0; right:0; bottom:0; left:0 */
    margin: auto;
    width: fit-content;
    height: fit-content;
}
z-index 与层叠上下文

z-index 仅对定位元素（position 非 static）或 flex/grid 子元素生效。值越大，层级越高。

层叠上下文（Stacking Context）：每个层叠上下文是一个独立的渲染单元，其子元素的 z-index 只在该上下文内比较。常见的层叠上下文触发条件：position: relative/absolute/fixed + z-index 非 auto、opacity 小于 1、transform、filter 等。

当一个父元素创建了层叠上下文，其子元素的 z-index 无法"穿透"到父元素之外与其他上下文的元素竞争层级。

11. 浮动

浮动最初用于文字环绕图片，后来被大量用于布局。如今 Flexbox 和 Grid 已全面取代浮动布局，但在特定场景（如文字环绕）仍有用处。

CSS 
/* 浮动元素会脱离文档流 */
.float-left {
    float: left;
    margin-right: 16px;
}

/* 清除浮动 */
.clearfix::after {
    content: '';
    display: block;
    clear: both;
}

/* 现代替代方案：用 overflow 触发 BFC */
.container {
    overflow: hidden;  /* 创建 BFC，包裹浮动子元素 */
}

/* 文字环绕（浮动的唯一合理用途）*/
.float-image {
    float: left;
    shape-outside: circle(50%);  /* 甚至可以用 shape 实现非矩形环绕 */
    width: 200px;
    height: 200px;
}
浮动布局的三个主要问题：1) 父元素高度塌陷（需清除浮动）；2) 无法实现等高布局；3) 响应式困难。现代布局请优先使用 Flexbox 或 Grid。

12. 背景

CSS 
.card {
    /* 纯色背景 */
    background-color: #1e293b;

    padding: 16px;

}

/* 平板：≥ 768px */

    .grid {
        grid-template-columns: repeat(2, 1fr); /* 两列 */
        padding: 24px;

}

/* 桌面：≥ 1024px */

1. 性能：移动端加载最小化的基础样式，大屏只叠加增量样式。

2. 可维护性：从简单到复杂的渐进增强，比从复杂到简单的渐进回退更清晰。

3. 渐进增强：基础功能在所有设备上都可用，大屏只是锦上添花。

18. Transition 过渡

CSS 过渡让属性值的变化有一个平滑的过渡效果，是实现交互反馈的最简单方式。

CSS 
.btn {
    background: #6366f1;
    color: white;
    padding: 12px 24px;
    border: none;
    border-radius: 8px;
    cursor: pointer;

    /* 过渡属性 */
    transition-property: background, transform, box-shadow;
    transition-duration: 0.3s;
    transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1);
    transition-delay: 0s;

    /* 简写：property duration timing-function delay */
    transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}

.btn:hover {
    background: #4f46e5;
    transform: translateY(-2px);
    box-shadow: 0 8px 16px rgba(99, 102, 241, 0.4);
}

/* 缓动函数 */
/* ease：先快后慢（默认）*/
/* linear：匀速 */
/* ease-in：先慢后快（适合进入）*/
/* ease-out：先快后慢（适合退出）*/
/* ease-in-out：先慢后快再慢（适合往返）*/

/* 高性能过渡（只动画 transform 和 opacity）*/
.card {
    transition: transform 0.3s, opacity 0.3s;
}
避免过渡 width、height、top、left、margin、padding 等属性，它们会触发布局重排（reflow）。使用 transform（如 scale()、translate()）代替，仅触发布局合成（composite），性能提升可达 40 倍以上。

20. Transform 变换

CSS Transform 可以对元素进行 2D/3D 变换，包括位移、旋转、缩放、倾斜等。它不会改变文档流，只影响视觉表现。

CSS 
/* 2D 变换 */
.translate {
    transform: translateX(50px);
    transform: translateY(-10px);
    transform: translate(50px, -10px);  /* 组合写法 */
}

.rotate {
    transform: rotate(45deg);            /* 顺时针旋转 45° */
    transform: rotate(-45deg);           /* 逆时针 */
}

.scale {
    transform: scale(1.2);              /* 放大 1.2 倍 */
    transform: scale(0.8, 0.8);         /* 缩小 */
    transform: scaleX(1.5);             /* 只水平放大 */
}

.skew {
    transform: skew(10deg);             /* 倾斜 */
}

/* 组合多个变换（注意顺序！从右到左执行）*/
.combo {
    transform: rotate(45deg) scale(1.2) translate(20px, 0);
}

/* 变换原点 */
.element {
    transform-origin: center center;    /* 默认 */
    transform-origin: top left;
    transform-origin: 50% 50%;
}

/* 3D 变换 */
.scene {
    perspective: 1000px;               /* 3D 视距 */
}

.cube {
    transform: rotateX(30deg) rotateY(45deg);
    transform-style: preserve-3d;      /* 保留 3D 空间 */
}

/* translateZ 实现视差滚动 */
.parallax-layer {
    transform: translateZ(-1px) scale(2);
}
GPU 合成与性能

transform 和 opacity 是 GPU 加速属性。浏览器在执行这些变换时，会创建合成层（Compositing Layer），将元素提升到独立的 GPU 图层进行渲染，避免触发布局重排（Reflow）和绘制（Paint）。

渲染流水线：JavaScript → Style（计算样式）→ Layout（布局/回流）→ Paint（绘制）→ Composite（合成）

只动画 transform 和 opacity 可以跳过 Layout 和 Paint 阶段，直接进入 Composite，性能开销极小。这也是为什么 transform: translate() 比 top/left 性能好得多的根本原因。

will-change 属性可以提前告知浏览器某个属性将发生变化，让浏览器提前创建合成层：will-change: transform。但不要滥用，每个合成层都消耗 GPU 内存。

21. 层叠与继承

CSS 特异性（Specificity）决定了当多条规则作用于同一元素时，哪条规则胜出。

特异性计算算法

特异性用四元组 (a, b, c, d) 表示，比较时从左到右逐位比较：

a：内联样式（style=""）—— 有则为 1，否则为 0

b：ID 选择器的数量

c：类选择器、属性选择器、伪类的数量

d：元素选择器、伪元素的数量

例如：#header .nav a.active 的特异性是 (0, 1, 2, 1)——1个ID + 2个类 + 1个元素。

div#header 的特异性是 (0, 1, 0, 1)——1个ID + 0个类 + 1个元素。

div div div 的特异性是 (0, 0, 0, 3)——0个ID + 0个类 + 3个元素。

*:not() 不增加特异性，:not() 的特异性是其参数的特异性。

!important 会覆盖所有特异性计算（最高优先级），但应尽量避免使用。

CSS 
/* 特异性比较示例 */
p { color: black; }              /* (0,0,0,1) */
.text { color: blue; }             /* (0,0,1,0) — 类胜出 */
#content { color: red; }            /* (0,1,0,0) — ID 胜出 */
p.intro { color: green; }          /* (0,0,1,1) */
#content p.intro { color: purple; } /* (0,1,1,1) — 最高 */

/* 继承属性 */
/* 可继承：color, font-*, line-height, text-align, cursor, visibility 等 */
/* 不可继承：width, height, margin, padding, border, background, display 等 */

/* 强制继承 */
.inherit-border {
    border: inherit;           /* 默认不继承，需要显式声明 */
}

/* 重置为初始值 */
.reset {
    all: unset;               /* 重置所有属性 */
    all: revert;              /* 回退到浏览器默认样式 */
    all: revert-layer;        /* 回退到上一个 @layer */
}

@layer 层叠层

22. BFC（块级格式化上下文）

什么是 BFC？

BFC（Block Formatting Context，块级格式化上下文）是一个独立的渲染区域，内部的布局不会影响外部，外部也不会影响内部。可以理解为一个"隔离的盒子"。

BFC 的作用：

1. 清除浮动（包裹浮动子元素，解决高度塌陷）

2. 防止 margin 合并（父子元素的 margin 不再合并）

3. 阻止浮动元素覆盖（BFC 不会与浮动元素重叠）

BFC 触发条件

条件说明
html根元素自动创建 BFC
float 非 nonefloat: left/right
positionabsolute 或 fixed
overflow 非 visiblehidden、auto、scroll
displayflow-root、inline-block、flex、grid、table-cell 等
containlayout、content、paint
column-span: all多列布局中跨所有列
flex/grid 容器display: flex/grid 的子元素（flex/grid 本身）
CSS 
/* 问题：父元素高度塌陷 */
.parent {
    background: #f0f0f0;
    /* 高度为 0，因为子元素浮动了 */
}

.child {
    float: left;
    width: 100px;
    height: 100px;
}

/* 解决方案 1：overflow 触发 BFC */
.parent {
    overflow: hidden;
}

/* 解决方案 2：display: flow-root（最语义化）*/
.parent {
    display: flow-root;
}

/* 解决方案 3：clear 清除浮动 */
.clearfix::after {
    content: '';
    display: table;
    clear: both;
}
推荐使用 display: flow-root 创建 BFC，它是专为此目的设计的，语义最清晰。避免使用 overflow: hidden，因为它可能裁剪内容（如阴影、下拉菜单）。

26. CSS 性能优化

渲染流水线优化

浏览器渲染流水线详解

1. Style：浏览器解析 CSS，计算每个元素的最终样式（处理层叠、继承、特异性）。

2. Layout（Reflow）：根据样式计算每个元素的几何属性（位置、大小）。改变 width、height、margin、padding、position、display 等会触发此阶段。

3. Paint：将元素绘制到图层上（边框、文字、阴影、背景等视觉属性）。改变 color、background、box-shadow、visibility 会触发此阶段，但不触发 Layout。

4. Composite：将所有图层合并输出到屏幕。transform 和 opacity 只影响此阶段，性能最好。

GPU 合成层：当使用 transform、will-change、opacity、filter 等属性时，浏览器会将元素提升为独立的合成层，使用 GPU 加速渲染。过多的合成层会消耗 GPU 内存，反而降低性能。

CSS 
/* 1. 避免触发强制同步布局（Forced Synchronous Layout）*/
/* 在 JS 中读取 offsetWidth/Height 后再修改布局属性，会强制浏览器立即计算 */
/* 解决：批量读完再批量写 */

/* 2. 只动画 transform 和 opacity */

    transition: transform 0.3s, opacity 0.3s;
    /* 不要动画: top, left, width, height, margin, padding */
}

/* 3. 使用 contain 隔离重排 */
.widget {
    contain: layout;   /* 内部的重排不影响外部 */
    contain: paint;    /* 裁剪超出部分，创建新堆叠上下文 */
    contain: content;  /* layout + paint */
}

/* 4. 减少选择器深度（降低 Style 计算成本）*/
/* 避免 */
.nav ul li a span { }  /* 5层 */
/* 推荐 */

/* 5. 避免使用通用选择器 */
/* 避免 */

/* 推荐：使用 reset 样式表精确重置 */

/* 6. 使用 content-visibility 加速首屏渲染 */

    content-visibility: auto;   /* 跳过视口外内容的渲染 */
    contain-intrinsic-size: 0 500px; /* 估算高度 */
}

/* 7. 字体加载优化 */

    font-display: swap;         /* 先用回退字体，加载后替换 */
    font-display: optional;     /* 只用网络字体，如果加载慢就用回退 */
}

/* 8. 减少 paint 面积 */

28. Container Queries（容器查询）

Container Queries 让组件根据其父容器的尺寸而非视口尺寸来调整样式，实现真正的组件级响应式。

原理讲解：Container vs Viewport

传统的 @media 查询基于视口（viewport）宽度，但组件经常被放在不同宽度的容器中（如侧边栏、弹窗、卡片网格）。Container Queries 让组件"感知"自己所在容器的大小，从而实现真正的组件级自适应。

步骤：1) 用 container-type 声明容器；2) 用 @container 查询容器尺寸。

CSS 
/* 声明容器 */
.sidebar {
    container-type: inline-size;  /* 仅监听宽度 */
    container-name: sidebar;      /* 命名容器（可选） */
}

/* 根据容器宽度调整布局 */

    .card {
        display: flex;
        flex-direction: row;
    }
    .card__image {
        width: 120px;
    }
}

@container (max-width: 399px) {
    .card {
        display: flex;
        flex-direction: column;
    }
}

/* 按名称查询特定容器 */

    .nav-item__label { display: inline; }
}
@container sidebar (max-width: 299px) {
    .nav-item__label { display: none; }
}

34. @layer 级联层

@layer 让你显式控制 CSS 的优先级顺序，无需依赖特异性或 !important。

CSS 
/* 定义层级（后定义的层级优先级更高） */
@layer reset, base, components, utilities;

@layer reset {
    * { margin: 0; padding: 0; box-sizing: border-box; }
}

@layer base {
    body { font-family: system-ui, sans-serif; }
    a    { color: blue; }
}

@layer components {
    .btn {
        padding: 8px 16px;
        border-radius: 6px;
        background: var(--primary);
    }
    .btn-primary { background: blue; }
}

@layer utilities {
    .hidden { display: none !important; }
    .text-center { text-align: center; }
}

/* 未分层的样式优先级最高 */
.custom {
    color: red;  /* 优先级高于所有 @layer 中的规则 */
}

/* 第三方库的样式放在低优先级层 */
@layer vendor {
    /* Bootstrap、Tailwind 等第三方样式 */
}

/* 你的自定义样式在高优先级层 */
@layer app {
    /* 项目自定义样式 */
}

/* 嵌套层 */
@layer components {
    @layer buttons {
        .btn { border: none; }
    }
    @layer forms {
        .input { border: 1px solid #ccc; }
    }
}
原理讲解：@layer 的优先级规则

@layer 的优先级低于未分层的样式。在 @layer 内部，后声明的层优先级更高。层内的特异性仍然有效，但只在同一层内比较。

这解决了"第三方库样式 vs 自定义样式"的优先级冲突问题：将第三方库放入低优先级层，你的样式自然覆盖它们，无需 !important。
