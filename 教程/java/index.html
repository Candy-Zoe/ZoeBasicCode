Java 编程教程

从零基础到高级特性，系统掌握 Java 编程语言。涵盖 JVM 原理、面向对象、集合框架、多线程、Lambda 表达式等核心知识。

1. Java 简介

Java 是由 Sun Microsystems（现为 Oracle）于 1995 年推出的面向对象编程语言。其核心理念是"一次编写，到处运行"（Write Once, Run Anywhere），通过 JVM 实现跨平台能力。

Java 核心特性

跨平台性：Java 源代码编译为字节码（.class 文件），由各平台的 JVM 解释执行。同一份字节码可在 Windows、Linux、macOS 上运行。

面向对象：Java 支持封装、继承、多态三大特性，一切皆对象（基本类型除外）。

自动内存管理：JVM 内置垃圾回收器（GC），自动回收不再使用的对象内存，开发者无需手动管理内存。

强类型语言：所有变量必须先声明类型后使用，编译期即可发现大量类型错误。

多线程支持：内置 Thread 类和 Runnable 接口，支持并发编程。

安全性：字节码验证、安全管理器、沙箱机制，防止恶意代码执行。

Java 技术体系

Java SE（标准版）：核心 API，包括集合、IO、多线程、网络编程等基础能力。

Java EE（企业版，现 Jakarta EE）：企业级开发框架，包括 Servlet、JSP、EJB、JPA 等。

Java ME（微型版）：嵌入式和移动设备开发（已逐步被 Android 取代）。

主流框架：Spring Boot、Spring Cloud（微服务）、MyBatis（ORM）、Maven/Gradle（构建）。

版本发布时间重要特性
Java 82014Lambda、Stream API、Optional
Java 112018长期支持版、HTTP Client、var 局部变量
Java 172021密封类、模式匹配 switch（预览）

2. 环境搭建

2.1 安装 JDK

JDK（Java Development Kit）是 Java 开发工具包，包含 JRE（运行时环境）和开发工具（javac、java、javadoc 等）。

JDK 安装步骤

1. 下载 JDK：从 Oracle 官网或 Adoptium 下载对应操作系统的 JDK 安装包（推荐 JDK 17 或 21 LTS 版本）。

2.3 项目结构与构建工具

Maven vs Gradle

Maven：基于 XML（pom.xml）的构建工具，约定优于配置，依赖管理成熟，生态完善。适合企业级项目。

Gradle：基于 Groovy/Kotlin DSL 的构建工具，构建速度快（增量编译、缓存），配置灵活。Android 官方推荐。

4. 变量与数据类型

4.1 基本数据类型

Java 八种基本数据类型

Java 有 8 种基本数据类型（primitive types），它们存储在栈内存中，直接存储值而非引用。

整数类型：byte（1 字节，-128~127）、short（2 字节）、int（4 字节，最常用）、long（8 字节，后缀 L）。

浮点类型：float（4 字节，后缀 F）、double（8 字节，默认浮点类型，精度约 15-16 位）。

字符类型：char（2 字节，Unicode 字符，如 'A'、'中'、'\u0041'）。

布尔类型：boolean（true/false，占 1 字节）。

4.2 类型转换

自动类型转换与强制转换

自动类型转换（隐式转换）：小范围类型可自动转换为大范围类型，不会丢失数据。转换顺序：byte → short → int → long → float → double，char → int。

强制类型转换（显式转换）：大范围转小范围可能导致精度丢失或溢出，需要使用强制转换符 (类型)。

注意：boolean 不参与类型转换。long 转 float、int 转 float 可能丢失精度（float 仅 32 位）。

java 
public class CastDemo {
    public static void main(String[] args) {
        // 自动类型转换（小 → 大）
        byte b = 10;
        int i = b;         // byte → int，自动转换
        long l = i;        // int → long，自动转换
        double d = l;      // long → double，自动转换

        // 强制类型转换（大 → 小）
        double pi = 3.99;
        int truncated = (int) pi;   // 结果为 3，截断小数部分

        int bigNum = 130;
        byte overflow = (byte) bigNum;  // 结果为 -126，溢出！

        // 表达式中的自动提升
        byte b1 = 10;
        byte b2 = 20;
        // byte result = b1 + b2;  // 编译错误！运算时自动提升为 int
        int result = b1 + b2;      // 正确
        byte result2 = (byte)(b1 + b2);  // 强制转换回 byte

        System.out.println("truncated: " + truncated);
        System.out.println("overflow: " + overflow);
        System.out.println("result: " + result);
    }
}
Java 中 byte、short、char 进行运算时会自动提升为 int 类型。两个 byte 相加的结果是 int，不能直接赋值给 byte 变量。

public class ComparisonLogicDemo {
    public static void main(String[] args) {
        int a = 10, b = 20;

        // 比较运算符（结果为 boolean）
        System.out.println(a == b);   // false  等于
        System.out.println(a != b);   // true   不等于

        System.out.println(t && f);   // false  短路与（都true才true）
        System.out.println(t || f);   // true   短路或（一个true就true）
        System.out.println(!t);       // false  非（取反）

        // 位运算符
        int x = 0b1010;   // 10
        int y = 0b1100;   // 12
        System.out.println(Integer.toBinaryString(x & y));   // 1000 (8)  按位与
        System.out.println(Integer.toBinaryString(x | y));   // 1110 (14) 按位或
        System.out.println(Integer.toBinaryString(x ^ y));   // 0110 (6)  按位异或
        System.out.println(Integer.toBinaryString(~x));      // 取反
        System.out.println(x << 2);   // 40   左移2位（×4）
        System.out.println(x >> 2);   // 2    右移2位（÷4）
    }
}

6. 字符串

6.1 String 类

String 的不可变性

不可变对象：String 类被 final 修饰，内部字符数组也是 final 的，一旦创建内容不可修改。任何"修改"操作都会创建新的 String 对象。

字符串常量池：JVM 在堆中维护字符串常量池，字面量创建的字符串会被缓存复用。使用 new String() 会绕过常量池创建新对象。

性能影响：频繁拼接字符串会产生大量临时对象，应使用 StringBuilder/StringBuffer。

java 
public class StringDemo {
    public static void main(String[] args) {
        // 创建方式
        String s1 = "Hello";           // 常量池
        String s2 = new String("Hello");  // 堆内存
        System.out.println(s1 == s2);       // false（引用不同）
        System.out.println(s1.equals(s2));   // true（内容相同）

        // 常用方法
        String str = "Hello, World!";
        System.out.println(str.length());              // 13
        System.out.println(str.charAt(0));              // 'H'
        System.out.println(str.substring(7));           // "World!"
        System.out.println(str.substring(0, 5));        // "Hello"
        System.out.println(str.indexOf("World"));     // 7
        System.out.println(str.contains("World"));   // true
        System.out.println(str.startsWith("Hello")); // true
        System.out.println(str.endsWith("!"));       // true
        System.out.println(str.toUpperCase());        // "HELLO, WORLD!"
        System.out.println(str.toLowerCase());        // "hello, world!"
        System.out.println(str.trim());               // 去除首尾空格
        System.out.println(str.replace("World", "Java")); // "Hello, Java!"
        System.out.println(str.isEmpty());             // false
        System.out.println(str.toCharArray);          // char[] 数组

        // 格式化
        String name = "张三";
        int age = 25;
        String formatted = String.format("姓名: %s, 年龄: %d", name, age);
        System.out.println(formatted);

        // 分割与连接
        String csv = "a,b,c,d";
        String[] parts = csv.split(",");
        System.out.println(java.util.Arrays.toString(parts));  // [a, b, c, d]
        String joined = String.join(" - ", parts);
        System.out.println(joined);  // "a - b - c - d"
    }
}

public class StringBuilderDemo {
    public static void main(String[] args) {

        sb.replace(0, 5, "Hi");       // 替换 [0, 5)

        // StringBuilder vs StringBuffer
        // StringBuffer：线程安全（方法有 synchronized），性能稍低
        // 单线程环境用 StringBuilder，多线程环境用 StringBuffer
    }
}

            case 4 -> "星期四";
            case 5 -> "星期五";
            case 6, 7 -> "周末";  // 多值匹配
            default -> "未知";
        };
        System.out.println(dayName);

        // switch 支持 String（Java 7+）
        String fruit = "apple";
        switch (fruit) {
            case "apple" -> System.out.println("苹果");
            case "banana" -> System.out.println("香蕉");
            default -> System.out.println("未知水果");
        }
    }
}
传统 switch 中忘记写 break 会导致"穿透"（fall-through），继续执行下一个 case 的代码。Java 14+ 的箭头语法（->）不会穿透，更安全。

10.1 类的定义

面向对象编程基础

类（Class）：对象的模板，定义了对象的属性（字段）和行为（方法）。类是逻辑上的抽象。

对象（Object）：类的实例，通过 new 关键字在堆内存中创建。每个对象有自己的属性副本。

11. 继承

继承机制详解

继承（Inheritance）：子类（派生类）继承父类（基类）的字段和方法，实现代码复用。Java 使用 extends 关键字，只支持单继承（一个类只能有一个直接父类）。

super 关键字：指向父类引用。super() 调用父类构造方法（必须在子类构造方法第一行），super.方法名 调用父类被覆盖的方法。

方法重写（Override）：子类重新定义父类中已有的方法。要求方法签名相同、返回类型相同或协变、访问权限不能更严格。

Object 类：所有类的根类，提供 toString()、equals()、hashCode()、clone() 等方法。自定义类应重写 toString() 和 equals()。

12. 多态

多态的原理

多态（Polymorphism）：同一引用类型，使用不同的实例而执行不同的操作。核心条件：继承关系 + 方法重写 + 父类引用指向子类对象。

向上转型：Animal a = new Dog("旺财", 3, "金毛"); 父类引用指向子类对象，编译时看父类，运行时看子类（动态绑定）。

向下转型：Dog d = (Dog) a; 需要强转，且必须确保原对象确实是该类型。使用 instanceof 检查后再转型。

编译看左边，运行看右边：编译器检查父类是否有该方法，运行时调用子类重写的方法。

13.2 接口

接口 vs 抽象类

接口（Interface）：纯粹的行为契约，定义方法签名（Java 8 前不能有实现）。类用 implements 实现接口，支持多实现。

抽象类：可以有字段、构造方法、具体方法和抽象方法。类用 extends 继承，只能单继承。

选择原则："是一个"关系用继承（Dog is Animal），"能做某事"用接口（Dog is Serializable）。

Java 8+ 接口新特性：默认方法（default）提供默认实现，静态方法可直接通过接口调用。

15. 包装类

自动装箱与拆箱

包装类：基本类型对应的引用类型（int→Integer, double→Double, boolean→Boolean 等）。提供类型转换、解析字符串、常量等工具方法。

自动装箱（Autoboxing）：基本类型自动转换为包装类，如 Integer i = 42;，编译器自动调用 Integer.valueOf(42)。

自动拆箱（Unboxing）：包装类自动转换为基本类型，如 int n = i;，编译器自动调用 i.intValue()。

缓存机制：Integer.valueOf() 对 -128~127 范围内的值使用缓存，所以 Integer a = 127; Integer b = 127; a == b 为 true，超出范围则为 false。

java 
public class WrapperDemo {
    public static void main(String[] args) {
        // 自动装箱
        Integer a = 100;       // Integer.valueOf(100)
        Double b = 3.14;      // Double.valueOf(3.14)
        Boolean c = true;    // Boolean.valueOf(true)

        // 自动拆箱
        int n = a;             // a.intValue()
        double d = b;          // b.doubleValue()

        // 缓存陷阱
        Integer x = 127, y = 127;
        System.out.println(x == y);   // true（缓存范围）

        Integer m = 200, n2 = 200;
        System.out.println(m == n2);  // false（超出缓存范围）
        System.out.println(m.equals(n2));  // true（用 equals 比较内容）

        // 常用方法
        System.out.println(Integer.MAX_VALUE);     // 2147483647
        System.out.println(Integer.MIN_VALUE);     // -2147483648
        System.out.println(Integer.parseInt("123")); // 123
        System.out.println(Integer.toBinaryString(10));  // "1010"
        System.out.println(Integer.toHexString(255));  // "ff"
        System.out.println(Integer.compare(10, 20));  // -1

        // Optional（防止空指针）
        Optional<Integer> opt = Optional.ofNullable(null);
        int value = opt.orElse(0);  // null 时使用默认值
        System.out.println(value);  // 0
    }
}

16. 集合框架

Java 集合框架概览

Collection 体系：List（有序可重复）、Set（无序不重复）、Queue（队列）。常用的实现类：ArrayList、LinkedList、HashSet、TreeSet、PriorityQueue。

Map 体系：键值对映射。常用实现：HashMap（哈希表，O(1) 查找）、TreeMap（红黑树，有序）、LinkedHashMap（保持插入顺序）、ConcurrentHashMap（线程安全）。

选择原则：需要快速随机访问用 ArrayList，频繁增删用 LinkedList，去重用 HashSet，排序用 TreeSet，键值对用 HashMap。

17. 泛型

泛型的本质

泛型（Generics）：参数化类型，允许在定义类、接口、方法时使用类型参数。编译后进行类型擦除，泛型信息只在编译期存在，运行时被替换为 Object 或上界类型。

类型擦除：List<String> 和 List<Integer> 在运行时都是 List，所以不能 new T() 或 instanceof T。

通配符：?（未知类型）、? extends T（上界通配符，读取）、? super T（下界通配符，写入）。遵循 PECS 原则：Producer Extends, Consumer Super。

18. 异常处理

Java 异常体系

Throwable：所有异常的根类。分为 Error（系统级错误，不可恢复，如 OutOfMemoryError）和 Exception（程序可处理）。

检查异常（Checked Exception）：编译期强制处理，如 IOException、SQLException。必须 try-catch 或 throws 声明。

非检查异常（Unchecked/Runtime Exception）：运行时异常，如 NullPointerException、ArrayIndexOutOfBoundsException。不强制处理。

try-with-resources（Java 7+）：自动关闭实现了 AutoCloseable 的资源，无需手动 finally 关闭。

java 
import java.io.*;
import java.util.*;

public class ExceptionDemo {

    // 声明可能抛出的异常
    public static String readFile(String path) throws IOException {
        try (BufferedReader br = new BufferedReader(
                new FileReader(path))) {
            return br.readLine();
        } // br 自动关闭，无需 finally
    }

    // 多重 catch
    public static void processData(String input) {
        try {
            int num = Integer.parseInt(input);
            int[] arr = new int[3];
            arr[5] = num;  // 会抛出异常

        } catch (ArrayIndexOutOfBoundsException e) {

        } catch (Exception e) {  // 捕获所有其他异常

        } finally {

        }

        if (age < 0 || age > 150) {

                "年龄无效: " + age);
        }
        System.out.println("年龄有效: " + age);
    }

        processData("abc");

20. 多线程

Java 多线程核心概念

线程 vs 进程：进程是资源分配的基本单位，线程是 CPU 调度的基本单位。同一进程的多个线程共享堆内存，各自拥有独立的栈空间。

创建线程的方式：继承 Thread 类、实现 Runnable 接口（推荐）、实现 Callable 接口（有返回值）、线程池 ExecutorService。

线程同步：synchronized 关键字（对象锁/类锁）、ReentrantLock（显式锁）、volatile（保证可见性，不保证原子性）。

线程状态：NEW → RUNNABLE → BLOCKED/WAITING/TIMED_WAITING → TERMINATED。

21.1 Lambda 表达式

Lambda 的本质

Lambda 表达式：匿名函数的简写形式，只能用于函数式接口（只有一个抽象方法的接口）。编译器自动推断参数类型。

函数式接口：使用 @FunctionalInterface 注解标识。Java 内置的核心函数式接口：Predicate<T>（判断）、Function<T,R>（转换）、Consumer<T>（消费）、Supplier<T>（供给）。

方法引用：Lambda 的进一步简写，如 System.out::println 等价于 x -> System.out.println(x)。

java 
import java.util.function.*;

public class LambdaDemo {
    public static void main(String[] args) {
        // Lambda 语法：(参数) -> { 方法体 }

        // 1. Predicate：T -> boolean（判断条件）
        Predicate<String> isLong = s -> s.length() > 5;
        System.out.println(isLong.test("Hello"));   // false
        System.out.println(isLong.test("HelloWorld")); // true

        // 组合条件
        Predicate<String> startsWithH = s -> s.startsWith("H");
        Predicate<String> combined = isLong.and(startsWithH);
        System.out.println(combined.test("HelloWorld")); // true

        // 2. Function：T -> R（转换）
        Function<String, Integer> toLength = String::length;
        System.out.println(toLength.apply("Java"));  // 4

        // 组合函数
        Function<Integer, String> toStr = Object::toString;
        Function<String, String>> upper = String::toUpperCase;
        Function<Integer, String>> pipeline = toStr.andThen(upper);
        System.out.println(pipeline.apply(42));  // "42"

        // 3. Consumer：T -> void（消费）
        Consumer<String> print = System.out::println;
        print.accept("Hello Lambda!");

        // 4. Supplier：() -> T（供给）
        Supplier<Double> random = Math::random;
        System.out.println(random.get());

        // 5. 方法引用
        // 静态方法引用：ClassName::staticMethod
        Function<String, Integer> parseInt = Integer::parseInt;

        // 实例方法引用：object::instanceMethod
        String str = "hello";
        Supplier<String> upperSupplier = str::toUpperCase;

        // 任意对象实例方法引用：ClassName::instanceMethod
        Function<String, String> toUpper = String::toUpperCase;
    }
}

import java.util.*;
import java.util.stream.*;

public class StreamDemo {
    public static void main(String[] args) {
        List<Student> students = List.of(
            new Student("张三", 20, 95),
            new Student("李四", 22, 88),
            new Student("王五", 21, 92),
            new Student("赵六", 23, 78),
            new Student("孙七", 20, 85)
        );

        // 1. 过滤 + 排序 + 收集
        List<String> topStudents = students.stream()
            .filter(s -> s.getScore() >= 90)    // 过滤
            .sorted(Comparator
                .comparing(Student::getScore).reversed())  // 排序
            .map(Student::getName)              // 提取
            .collect(Collectors.toList());      // 收集
        System.out.println(topStudents);  // [张三, 王五]

        // 2. 聚合操作
        double avgScore = students.stream()
            .mapToDouble(Student::getScore)
            .average()
            .orElse(0);
        System.out.printf("平均分: %.1f%n", avgScore);

        int maxAge = students.stream()
            .mapToInt(Student::getAge)
            .max()
            .orElse(0);

        // 3. 分组
        Map<Integer, List<Student>> byAge = students.stream()
            .collect(Collectors.groupingBy(Student::getAge));
        byAge.forEach((age, list) ->
            System.out.printf("%d 岁: %d 人%n", age, list.size()));

        // 4. 字符串拼接
        String names = students.stream()
            .map(Student::getName)

22. 反射

反射机制详解

反射（Reflection）：在运行时动态获取类的信息（字段、方法、构造器），并动态操作对象。是 Spring IoC、JUnit、ORM 框架的基础。

获取 Class 对象：Class.forName("全限定类名")、对象.getClass()、类名.class。每种方式获取的是同一个 Class 对象。

主要能力：动态创建对象、访问/修改字段值、调用方法、检查注解、判断类型关系。

性能影响：反射比直接调用慢，但 JVM 会进行优化（如 setAccessible 跳过安全检查）。框架中大量使用，应用代码谨慎使用。

import java.lang.reflect.*;

public class ReflectionDemo {

    // 一个简单的类用于演示
    public static class Person {
        private String name;
        private int age;

        public Person(String name, int age) {
            this.name = name;
            this.age = age;
        }

        public String greet() {
            return "我是 " + name + "，今年 " + age + " 岁";
        }

        private String secret() {
            return "这是私有方法";
        }
    }

    public static void main(String[] args) throws Exception {
        // 1. 获取 Class 对象
        Class<?> clazz = Person.class;
        System.out.println("类名: " + clazz.getName());
        System.out.println("简单类名: " + clazz.getSimpleName());

        // 2. 创建实例
        Constructor<?> constructor = clazz.getConstructor(String.class, int.class);
        Person person = (Person) constructor.newInstance("张三", 25);

        // 3. 访问字段
        Field nameField = clazz.getDeclaredField("name");
        nameField.setAccessible(true);  // 突破 private 限制
        System.out.println("name 字段值: " + nameField.get(person));
        nameField.set(person, "李四");  // 修改字段值
        System.out.println("修改后: " + nameField.get(person));

        // 4. 调用方法
        Method greetMethod = clazz.getMethod("greet");
        String result = (String) greetMethod.invoke(person);
        System.out.println(result);

        // 调用私有方法
        Method secretMethod = clazz.getDeclaredMethod("secret");
        secretMethod.setAccessible(true);
        System.out.println(secretMethod.invoke(person));

        // 5. 获取所有字段
        System.out.println("\n--- 所有字段 ---");
        for (Field f : clazz.getDeclaredFields()) {
            f.setAccessible(true);
            System.out.printf("%s %s = %s%n",
                f.getType().getSimpleName(), f.getName(), f.get(person));
        }

        // 6. 获取所有方法
        System.out.println("\n--- 所有方法 ---");
        for (Method m : clazz.getDeclaredMethods()) {
            System.out.printf("%s %s(%s)%n",
                m.getReturnType().getSimpleName(), m.getName(),
                java.util.Arrays.toString(m.getParameterTypes()));
        }

        // 7. 动态代理
        Person proxy = (Person) Proxy.newProxyInstance(
            clazz.getClassLoader(),
            clazz.getInterfaces(),
            (proxyObj, method, methodArgs) -> {
                System.out.println("调用前: " + method.getName());
                Object res = method.invoke(person, methodArgs);
                System.out.println("调用后: " + method.getName());
                return res;
            }
        );
        proxy.greet();
    }
}

23. JVM 内存模型

JVM 运行时数据区

程序计数器（Program Counter）：当前线程执行的字节码行号指示器。线程私有，唯一不会发生 OOM 的区域。

虚拟机栈（VM Stack）：每个方法调用创建一个栈帧，包含局部变量表、操作数栈、动态链接、方法出口。线程私有。

本地方法栈（Native Method Stack）：为 Native 方法服务，类似虚拟机栈。

堆（Heap）：所有对象实例分配的区域，GC 的主要工作区域。线程共享，分为新生代（Eden + S0 + S1）和老年代。

方法区/元空间（Metaspace）：存储类信息、常量池、静态变量。Java 8 后使用本地内存的元空间替代永久代。

垃圾回收（GC）机制

可达性分析：从 GC Roots（虚拟机栈引用、静态变量、常量池引用等）出发，不可达的对象将被回收。

GC 算法：标记-清除（产生碎片）、标记-整理（移动对象）、复制算法（新生代使用，空间换时间）。

分代收集：新生代用复制算法（Minor GC），老年代用标记-清除/整理（Major GC/Full GC）。

垃圾收集器：Serial（单线程）、Parallel（吞吐量优先）、CMS（低延迟）、G1（JDK 9 默认，平衡吞吐和延迟）、ZGC（JDK 15+，亚毫秒停顿）。

类加载机制

类加载过程：加载 → 验证 → 准备 → 解析 → 初始化。

双亲委派模型：类加载器收到加载请求时，先委托父加载器处理。Bootstrap → Extension → Application → Custom。保证核心类不被篡改。

打破双亲委派：线程上下文类加载器（TCCL）、OSGi、Tomcat 的 WebAppClassLoader。

自定义类加载器：继承 ClassLoader，重写 findClass() 方法，可实现热部署、加密解密等。

自动装箱的内存陷阱

Integer 缓存池：Integer.valueOf() 对 -128~127 范围内的值使用缓存，该范围内的 Integer 对象是同一个实例。

字符串常量池：字面量创建的字符串存储在常量池中，String.intern() 可手动将字符串放入常量池。

内存溢出排查：使用 -Xmx、-Xms 设置堆大小，jmap 生成堆转储，jvisualvm 或 MAT 分析内存泄漏。

        return switch (payment) {
            case CreditCard cc -> "信用卡支付，手续费: " + cc.calculateFee();
            case PayPal pp -> "PayPal 支付，手续费: " + pp.calculateFee();
            case BankTransfer bt -> "银行转账，手续费: " + bt.calculateFee();
        };
    }

    public static void main(String[] args) {
        Payment cc = new CreditCard("4111-xxxx", 100);
        Payment pp = new PayPal("user@email.com", 50);

        System.out.println(processPayment(cc));
        System.out.println(processPayment(pp));
    }
