JavaScript 完全教程

从零基础到进阶，全面掌握 JavaScript 核心概念与实战技巧。本教程涵盖事件循环、闭包、原型链、异步编程等 JavaScript 最重要的特性。

1. JavaScript 简介

JavaScript 是一种轻量级、解释型的编程语言，最初由 Brendan Eich 在 1995 年用 10 天时间设计。如今它已成为 Web 开发的核心技术之一，与 HTML（结构）和 CSS（样式）共同构成前端三驾马车。

JavaScript 的应用范围早已超越浏览器：

  • 浏览器端：页面交互、DOM 操作、表单验证、单页应用（SPA）
  • 服务器端：Node.js 构建高性能后端服务
  • 移动端：React Native、Flutter (Dart 语法类似) 跨平台开发
  • 桌面端：Electron 开发桌面应用（VS Code 就是用 Electron 构建的）
  • 嵌入式：物联网设备、智能硬件的编程控制
原理讲解：为什么 JavaScript 如此流行？

JavaScript 成功的关键因素：

1. 无需编译，浏览器原生支持——用户无需安装任何开发环境，打开浏览器就能运行。这极大地降低了编程入门门槛。

2. 事件驱动 + 非阻塞 I/O——Node.js 的事件循环模型让单线程也能处理高并发请求，这是 JavaScript 在服务端崛起的技术基础。

3. 语言本身的灵活性——函数是一等公民、动态类型、原型继承等特性让 JavaScript 极其灵活（但也带来了陷阱，后续章节会详细讲解）。

4. 庞大的生态系统——npm 上有超过 200 万个开源包，几乎任何需求都能找到现成的解决方案。

原理讲解：JavaScript 引擎的工作流程

当你在浏览器中执行 JavaScript 代码时，引擎会经过以下步骤：

1. 词法分析（Lexical Analysis）——将源代码拆分成一个个 Token（词法单元），如关键字、标识符、运算符等。

2. 语法分析（Parsing）——根据 ECMAScript 规范，将 Token 流构建成抽象语法树（AST）。如果语法有误，会在这里报 SyntaxError。

3. 编译（Compilation）——现代引擎（V8、SpiderMonkey）会将 AST 编译成字节码或机器码，这就是 JIT（即时编译）技术。

4. 执行（Execution）——在执行上下文中运行代码，创建变量对象、作用域链、this 绑定。

理解这个流程有助于你理解后续的作用域、变量提升、闭包等重要概念。

4. 变量与数据类型

变量声明方式

JavaScript 提供三种变量声明方式，它们的行为有重要区别：

JavaScript 
// var：函数作用域，存在变量提升
console.log(x);  // undefined（变量提升，不报错）
var x = 10;

// let：块级作用域，无变量提升，暂时性死区
// console.log(y);  // ReferenceError!
let y = 20;

// const：块级作用域，声明时必须赋值，不可重新赋值
const z = 30;
// z = 40;  // TypeError: Assignment to constant variable.
优先使用 const，只在需要重新赋值时使用 let，完全避免使用 var。

原始数据类型

JavaScript 有 7 种原始类型（Primitive Types），它们是不可变的：

类型说明示例
number整数和浮点数，还包括 Infinity、-Infinity、NaN42, 3.14, NaN
bigint任意精度整数9007199254740991n
string文本字符串"hello", 'world', `template`
boolean逻辑值true, false
undefined未定义的值let x; → undefined
null有意的空值let x = null;
symbol唯一标识符Symbol('id')
JavaScript 
// typeof 运算符检测类型
console.log(typeof 42);          // "number"
console.log(typeof "hello");     // "string"
console.log(typeof true);        // "boolean"
console.log(typeof undefined);   // "undefined"
console.log(typeof null);        // "object"（历史遗留 bug！）
console.log(typeof []);          // "object"
console.log(typeof {});          // "object"
原理讲解：原始类型 vs 引用类型

原始类型（primitive）的值直接存储在栈内存中，赋值时会复制值：

当你执行 let a = 1; let b = a; 时，b 获得的是 a 的一个独立副本，修改 b 不会影响 a。

引用类型（对象、数组、函数）存储在堆内存中，变量存储的是引用地址：

当你执行 let arr1 = [1,2,3]; let arr2 = arr1; 时，arr1 和 arr2 指向同一个数组对象，修改一个会影响另一个。

这就是为什么 typeof null 返回 "object"——在 JS 最初的实现中，值在底层以 32 位存储，前 3 位为类型标志，而 null 被表示为全零（与对象的类型标志相同），这个 bug 因为兼容性原因被保留了下来。

JavaScript 的数字类型是 IEEE 754 双精度浮点数，存在精度问题：0.1 + 0.2 !== 0.3。在金融计算等场景中，建议使用整数运算或 BigInt。

算术运算符

JavaScript 
let a = 10, b = 3;

a + b    // 13  加法
a - b    // 7   减法
a * b    // 30  乘法
a / b    // 3.333...  除法
a % b    // 1   取模（余数）

0.1 + 0.2           // 0.30000000000000004（精度问题）

比较运算符

JavaScript 
// == 和 !=（宽松相等，会进行类型转换）
1 == "1"      // true（字符串 "1" 转为数字 1）
0 == false    // true（false 转为 0）
"" == 0        // true（空字符串转为 0）
null == undefined  // true

逻辑运算符

JavaScript 
// 逻辑与 &&（短路求值）
true && true    // true
true && false   // false
"hello" && 42    // 42（非空字符串是 truthy）
null && "hi"    // null（null 是 falsy，短路返回）

// 逻辑或 ||（短路求值）
false || false  // false
null || "默认值"  // "默认值"（null 是 falsy）
"有值" || "不会执行"  // "有值"

// 逻辑非 !（一元运算符）
!true    // false
!0       // true（0 是 falsy）
!"hi"    // false（非空字符串是 truthy）
原理讲解：JavaScript 的真值（Truthy）与假值（Falsy）

JavaScript 中所有值在布尔上下文中都会被隐式转换为 true 或 false。以下是仅有的 7 个 Falsy 值：

false、0、-0、0n（BigInt 零）、""（空字符串）、null、undefined、NaN

其他所有值都是 Truthy，包括：

[]（空数组）、{}（空对象）、"0"（字符串零）、false 的包装对象等。这些常常让人感到意外。

短路求值（Short-circuit evaluation）利用了这个特性：a || b 返回第一个 truthy 值，a && b 返回第一个 falsy 值。这在设置默认值时非常有用：const name = input || "匿名"。

6. 字符串

JavaScript 
// 三种定义方式
let s1 = '单引号';
let s2 = "双引号";
let s3 = `模板字符串`;

// 模板字符串（强烈推荐）
let name = "张三";
let age = 25;
let greeting = `你好，我是${name}，今年${age}岁`;
console.log(greeting);  // "你好，我是张三，今年25岁"

// 模板字符串支持多行
let html = `
<div class="card">
    <h2>${name}</h2>
    <p>年龄: ${age}</p>
</div>
`;

// 常用字符串方法
let str = "Hello, JavaScript!";
str.length              // 19
str.toUpperCase()       // "HELLO, JAVASCRIPT!"
str.toLowerCase()       // "hello, javascript!"
str.includes("Java")   // true
str.startsWith("Hello") // true
str.endsWith("!")      // true
str.indexOf("Java")    // 7
str.slice(7, 17)        // "JavaScript"
str.replace("JavaScript", "JS")  // "Hello, JS!"
str.split(", ")         // ["Hello", "JavaScript!"]

// 字符串是不可变的
let hello = "hello";
hello[0] = "H";
console.log(hello);  // "hello"（没有改变！）
原理讲解：字符串的不可变性

JavaScript 中的字符串是不可变的（immutable）。当你尝试修改字符串中的某个字符时（如 str[0] = 'H'），这个操作会静默失败（严格模式下会抛出 TypeError）。

这意味着字符串方法永远不会修改原始字符串，而是返回一个新字符串。例如 str.toUpperCase() 不会改变 str，而是返回一个新的全大写字符串。

在性能敏感的场景中（如循环内拼接字符串），频繁创建新字符串可能影响性能。现代引擎会做一些优化，但使用 Array.join() 或模板字符串拼接通常是更好的选择。

常用数组方法

JavaScript 
let fruits = ["苹果", "香蕉", "橙子"];

// 增删改
fruits.push("葡萄");       // 末尾添加 → ["苹果","香蕉","橙子","葡萄"]
fruits.pop();               // 末尾删除 → ["苹果","香蕉","橙子"]
fruits.unshift("草莓");    // 开头添加
fruits.shift();             // 开头删除
fruits.splice(1, 1);        // 从索引1删除1个元素
fruits.splice(1, 0, "芒果"); // 在索引1插入元素

// 查找
fruits.includes("香蕉");    // true
fruits.indexOf("橙子");    // 索引
fruits.find(f => f.startsWith("香"));  // "香蕉"
fruits.findIndex(f => f === "橙子");   // 索引

// 遍历（高阶函数）
fruits.forEach((fruit, i) => {
    console.log(`${i}: ${fruit}`);
});

// map：映射为新数组
let upper = fruits.map(f => f.toUpperCase());

// filter：过滤
let long = fruits.filter(f => f.length > 2);

// reduce：归约
let nums = [1, 2, 3, 4, 5];
let sum = nums.reduce((acc, n) => acc + n, 0);  // 15

// 展开运算符和解构
let arr = [1, 2, 3];
let copy = [...arr, 4, 5];   // [1, 2, 3, 4, 5]
let [first, second, ...rest] = arr;  // rest = [3]
数组的 push/pop 操作的是最后一个元素，时间复杂度 O(1)；而 shift/unshift 操作的是第一个元素，时间复杂度 O(n)，因为需要移动所有元素。

8. 对象

JavaScript 
// 对象字面量（最常用）
let person = {
    name: "张三",
    age: 25,
    "favorite color": "蓝色",  // 含空格的键必须加引号
    greet() {                   // 方法简写
        return `你好，我是${this.name}`;
    }
};

// 计算属性名
let key = "age";
let obj = { [key]: 25 };  // { age: 25 }

// 属性访问
person.name          // 点号访问（属性名是合法标识符时）
person["age"]       // 方括号访问（动态属性名）

// 添加/修改/删除属性
person.email = "zhangsan@example.com";
person.age = 26;
delete person.age;

// 解构赋值
let { name, age } = person;
let { name: personName } = person;  // 重命名
let { name, address = "未知" } = person;  // 默认值

// 展开运算符（浅拷贝）
let copy = { ...person, age: 30 };

// Object 静态方法
Object.keys(person);      // ["name", "email"]
Object.values(person);    // ["张三", "zhangsan@example.com"]
Object.entries(person);   // [["name","张三"], ["email","..."]]
Object.freeze(person);   // 冻结对象（不可增删改属性）
原理讲解：JavaScript 对象的本质

JavaScript 中一切皆对象（除了原始类型）。对象本质上是一个无序的键值对集合（也称为属性字典）。

与 Java/C++ 的类不同，JS 对象的属性是动态的——可以随时添加或删除，不需要预先定义"类结构"。这种设计来自 Self 语言的"原型"思想。

属性描述符：每个属性其实包含 4 个描述符——value（值）、writable（是否可写）、enumerable（是否可枚举）、configurable（是否可配置）。通过 Object.getOwnPropertyDescriptor() 可以查看。

this 绑定规则：对象方法中的 this 指向调用该方法的对象。但当方法被赋值给变量后调用，this 会丢失绑定——这是 JS 中最常见的陷阱之一。

10. 循环语句

JavaScript 
// for 循环
for (let i = 0; i < 5; i++) {
    console.log(i);
}

// while 循环
let count = 0;
while (count < 5) {
    count++;
}

// do...while 循环（至少执行一次）
let input;
do {
    input = prompt("请输入密码：");
} while (input !== "secret");

// for...of（遍历可迭代对象的值）
let arr = [10, 20, 30];
for (let val of arr) {
    console.log(val);
}

// for...in（遍历对象的键）
let obj = { a: 1, b: 2, c: 3 };
for (let key in obj) {
    console.log(key, obj[key]);
}

// break 和 continue
for (let i = 0; i < 10; i++) {
    if (i === 3) continue;  // 跳过 3
    if (i === 7) break;      // 到 7 停止
    console.log(i);
}
// 输出: 0, 1, 2, 4, 5, 6
推荐使用
// for...of：遍历值
for (const item of array) {
    // item 是数组元素
}

// forEach：数组专用
array.forEach((item, index) => {
    // 处理每个元素
});
避免使用
// for...in：遍历键（有原型链风险）
for (const key in array) {
    // key 是字符串索引！
    // 会遍历原型链上的属性
}

// 传统 for：容易出错
for (var i = 0; i < arr.length; i++) {
    // var 作用域问题
    // arr.length 每次都重新计算
}
原理讲解：for...of vs for...in 的本质区别

for...in 遍历的是对象的可枚举属性名（键），包括原型链上的可枚举属性。它设计用于遍历普通对象的键，不适合遍历数组（因为数组索引本质上是字符串，而且可能遍历到原型上的方法）。

for...of 遍历的是可迭代对象（Iterable）的值。数组、字符串、Map、Set 等都实现了迭代器协议（Symbol.iterator）。它不会访问原型链，也不会访问属性名。

简单记忆：用 for...of 遍历数组，用 for...in 遍历对象。

11. 函数定义

JavaScript 
// 函数声明（会被提升）
function greet(name) {
    return `你好，${name}！`;
}

// 函数表达式（不会被提升）
const add = function(a, b) {
    return a + b;
};

// 默认参数
function createUser(name, role = "user") {
    return { name, role };
}
createUser("张三");           // { name: "张三", role: "user" }
createUser("张三", "admin");  // { name: "张三", role: "admin" }

// 剩余参数
function sum(...numbers) {
    return numbers.reduce((a, b) => a + b, 0);
}
sum(1, 2, 3, 4, 5);  // 15

// 解构参数
function printUser({ name, age, email = "N/A" }) {
    console.log(`${name}, ${age}, ${email}`);
}
printUser({ name: "张三", age: 25 });  // "张三, 25, N/A"

// 立即执行函数表达式（IIFE）
(function() {
    const secret = "这是私有变量";
    console.log(secret);
})();
原理讲解：函数是一等公民

在 JavaScript 中，函数和数字、字符串一样，是"一等公民"（First-class Citizen）。这意味着函数可以：

1. 赋值给变量：const fn = function() {}

2. 作为参数传递：setTimeout(callback, 1000)

3. 作为返回值：function createFn() { return function() {}; }

4. 拥有属性：fn.name、fn.length（形参个数）

5. 存储在数据结构中：可以放进数组、对象等

这个特性是闭包、高阶函数、回调模式、函数式编程的理论基础。理解"函数是值"这个概念，是掌握 JavaScript 高级特性的关键。

12. 箭头函数

JavaScript 
// 基本语法

// 单参数可省略括号
const double = x => x * 2;

// 无参数必须有括号

// 箭头函数不会创建自己的 this

原理讲解：闭包是什么？

闭包（Closure）是指一个函数能够记住并访问它被创建时所在的词法作用域，即使这个函数在该作用域之外执行。

实现原理：

1. 每个函数在创建时都会保存一个对「词法环境」的引用——这个环境包含该函数定义时的所有局部变量。

2. 当内部函数引用了外部函数的变量，这些变量不会被垃圾回收，因为内部函数仍然持有对它们的引用。

3. 即使外部函数已经执行完毕，只要内部函数还活着，它引用的外部变量就不会被回收。

闭包的应用场景：数据封装（私有变量）、函数工厂、柯里化、模块模式、防抖/节流等。它是 JavaScript 中最强大也最容易被误用的特性之一。

    x => x.toLowerCase(),

function debounce(fn, delay) {
    let timer;
    return (...args) => {
        clearTimeout(timer);
        timer = setTimeout(() => fn(...args), delay);
    };
}

// 5. 节流函数（Throttle）
function throttle(fn, limit) {
    let inThrottle;
    return (...args) => {
        if (!inThrottle) {
            fn(...args);
            inThrottle = true;
            setTimeout(() => inThrottle = false, limit);
        }
    };
}

1. 更具声明性——代码表达的是"意图"而不是"步骤"。

2. 减少错误——不需要手动管理索引、边界条件。

3. 可组合性强——可以用 pipe 将多个操作串联起来。

防抖和节流是高阶函数在实际开发中最经典的应用场景：防抖用于搜索输入（用户停止输入后再发送请求），节流用于滚动事件（限制事件处理频率）。

15. 原型与原型链

}

原理讲解：原型链的工作机制

JavaScript 使用原型链（Prototype Chain）实现继承，而非传统的类继承。这是 JS 最核心的设计理念之一。

原型链查找规则：当你访问 obj.prop 时：

第一步：在 obj 自身属性中查找，如果找到就返回。

第二步：如果没找到，沿着 obj.[[Prototype]] 链接向上查找。

第三步：持续向上，直到 [[Prototype]] 为 null（即 Object.prototype 的原型），此时返回 undefined。

关键点：所有对象最终都继承自 Object.prototype，而 Object.prototype.__proto__ 为 null，这就是原型链的终点。

性能考量：原型链越长，属性查找越慢。将共享方法放在 prototype 上，而非实例上，可以大幅节省内存——因为所有实例共享同一个方法引用。

2. 创建 Dog 构造函数本身，将其 [[Prototype]] 指向 Animal（这样静态方法也能继承）。

原理讲解：Promise 的三种状态

Promise 是一个状态机，有且只有三种状态：

1. Pending（等待中）——初始状态，异步操作尚未完成。

2. Fulfilled（已完成）——异步操作成功完成，调用 resolve(value) 进入此状态。

3. Rejected（已拒绝）——异步操作失败，调用 reject(error) 进入此状态。

关键特性：状态一旦改变就不可逆。这保证了 .then() 和 .catch() 中的回调只会被执行一次。

.then() 返回新 Promise：每次调用 .then() 都会返回一个全新的 Promise，这就是链式调用的原理。如果回调函数返回一个 Promise，后续的 .then() 会等待该 Promise 完成。

原理讲解：事件循环（Event Loop）的工作原理

JavaScript 是单线程语言（主线程只有一个），但浏览器/Node.js 提供了多线程能力（网络请求、定时器、文件 I/O 等由浏览器 API 处理）。事件循环是协调这些操作的核心机制。

执行模型：

1. 执行调用栈（Call Stack）中所有同步代码——直到调用栈清空。

2. 清空微任务队列（Microtask Queue）——Promise.then/catch/finally、queueMicrotask、MutationObserver 都是微任务。微任务在当前宏任务结束后、下一个宏任务开始前全部清空。

3. 取一个宏任务（Macrotask）执行——setTimeout/setInterval、setImmediate（Node.js）、I/O、UI 渲染 都是宏任务。

4. 回到步骤 2——再次清空所有微任务，然后执行下一个宏任务。

为什么 Promise 比 setTimeout 先执行？ 因为 Promise.then 是微任务，setTimeout 是宏任务。微任务永远优先于宏任务执行。

为什么需要微任务？ 微任务确保 Promise 的回调在当前同步代码执行完后立即执行，而不需要等待下一个定时器或渲染周期。这保证了 Promise 链的连续性。

原理讲解：暂时性死区（Temporal Dead Zone）

let 和 const 声明的变量也会被提升到所在块作用域的顶部，但在声明语句执行之前，它们处于暂时性死区（TDZ）——访问会抛出 ReferenceError。

原理讲解：生成器为什么重要？

生成器（Generator）是一种可以暂停和恢复执行的特殊函数。它不会一次性执行完所有代码，而是每次遇到 yield 就暂停，将控制权交还给调用者。

双向通信：yield 可以向外输出值，next(value) 也可以向生成器内部传入值。这使得生成器可以作为协程使用。

async/await 的基础：实际上，async/await 就是基于生成器和 Promise 实现的语法糖。理解生成器的工作原理有助于深入理解 async/await 的行为。

原理讲解：WeakMap/WeakSet 的弱引用机制

普通 Map/Set 对键持有强引用——只要 Map/Set 还活着，键对象就不会被垃圾回收，即使你已经在其他地方把键的引用设为了 null。

WeakMap/WeakSet 对键持有弱引用——如果一个对象除了 WeakMap/WeakSet 之外没有其他引用，垃圾回收器会自动回收这个对象，WeakMap/WeakSet 中对应的条目也会消失。

为什么需要弱引用？ 防止内存泄漏。当你需要给对象关联一些额外数据，但不想因为这些数据的存在而阻止对象被回收时，WeakMap 是理想选择。

为什么 WeakMap 没有 size、没有 forEach、不能遍历？ 因为弱引用的对象可能在任何时候被回收，引擎无法保证遍历时所有条目都还存在。这是刻意的设计，不是缺陷。

30. Web Workers 基础

原理讲解：Web Workers 的线程模型

JavaScript 是单线程的，长时间运行的任务会阻塞主线程，导致页面卡顿。Web Workers 允许在后台线程中运行 JavaScript，不会阻塞主线程的 UI 渲染和用户交互。

Worker 线程与主线程之间通过消息传递（postMessage）通信，不能直接访问 DOM 或共享内存（除非使用 SharedArrayBuffer）。Worker 适合 CPU 密集型任务：大数据排序、图像处理、加密解密、复杂计算等。

// 1. 防抖（Debounce）— 延迟执行，重复触发则重新计时
function debounce(fn, delay, immediate = false) {
    let timer;
    return function(...args) {
        clearTimeout(timer);
        if (immediate && !timer) {
            fn.apply(this, args);
        }
        timer = setTimeout(() => {
            if (!immediate) fn.apply(this, args);
            timer = null;
        }, delay);
    };
}

// 2. 节流（Throttle）— 固定间隔内只执行一次
function throttle(fn, interval) {
    let lastTime = 0;
    return function(...args) {
        const now = Date.now();
        if (now - lastTime >= interval) {
            lastTime = now;
            fn.apply(this, args);
        }
    };
}

// 使用示例
const handleSearch = debounce((e) => {
    console.log("搜索：", e.target.value);
}, 300);

const handleScroll = throttle(() => {
    console.log("滚动位置：", window.scrollY);
}, 200);

function deepEqual(a, b) {
    if (a === b) return true;
    if (!a || !b || typeof a !== typeof b) return false;
    if (typeof a !== "object") return false;

    const keysA = Object.keys(a);
    const keysB = Object.keys(b);

    if (keysA.length !== keysB.length) return false;

    return keysA.every(key => deepEqual(a[key], b[key]));
}

// 6. 手写 Promise.all
function promiseAll(promises) {
    return new Promise((resolve, reject) => {
        const results = [];
        let completed = 0;
        if (promises.length === 0) return resolve([]);
        promises.forEach((p, i) => {
            Promise.resolve(p).then(val => {
                results[i] = val;
                completed++;
                if (completed === promises.length) resolve(results);
            }).catch(reject);
        });
    });
}
原理讲解：防抖 vs 节流的核心区别

防抖（Debounce）：事件触发后等待 N 毫秒，如果期间再次触发则重新计时。适用于搜索输入、窗口 resize 等只需要最终结果的场景。

节流（Throttle）：事件触发后立即执行，然后在 N 毫秒内忽略后续触发。适用于滚动、鼠标移动等需要定期响应的场景。

简单记忆：防抖是"等你停下来再做"，节流是"每隔一段时间做一次"。
