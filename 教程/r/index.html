1. R 语言简介

R 语言是为统计计算和图形绘制而设计的开源编程语言与软件环境。自 1993 年由 Ross Ihaka 和 Robert Gentleman 发布以来，R 已成为数据科学、生物信息学、金融分析等领域最流行的工具之一。

为什么选择 R？

统计原生：R 的核心库由统计学家设计，内置了海量的统计函数与概率分布，无需额外依赖即可进行假设检验、回归分析、时间序列等操作。

向量化计算：R 默认以向量为基本运算单元，无需显式循环即可对整个数据集进行批量操作。这不仅使代码更简洁，还利用了底层 C/Fortran 的 SIMD 优化。

可视化生态：从 base R 的绑图到 ggplot2 的图形语法，R 拥有最成熟的可视化体系。ggplot2 基于 Leland Wilkinson 的图形语法理论，将图形分解为数据、映射、几何对象、统计变换、坐标系和分面等组件。

CRAN 生态：CRAN 上收录了超过 20,000 个包，覆盖从机器学习 (caret, mlr3) 到地理空间分析 (sf, terra) 的几乎所有领域。

R 的版本历史

  • R 1.0.0 (2000)：正式发布，奠定核心语法
  • R 3.0 (2013)：引入长向量支持 (>2^31 元素)
  • R 4.0 (2020)：默认字符串编码改为 UTF-8，引入新管道操作符 |>
  • R 4.3 (2023)：改进错误提示，原生管线 |> 更成熟
R 语言的名称来源于两位作者名字首字母 R & R，也有人说它致敬了 S 语言（R 是 S 的开源实现）。

惰性求值 (Lazy Evaluation)

R 的函数参数使用惰性求值——参数不会在函数调用时立即计算，而是等到实际使用时才求值。这意味着：

  • 未使用的参数不会触发错误（即使表达式非法）
  • 函数可以安全地包裹用户表达式
  • substitute() 和 enquo() 可以捕获未求值的表达式
R 
# 惰性求值示例
f <- function(x, y) x    # y 从未被使用
f(1, stop("error!"))      # 正常返回 1，不会报错

# 利用惰性求值做延迟计算
lazy_val <- function(expr) function() expr
expensive <- lazy_val(heavy_computation())  # 立即调用时不计算
expensive()  # 只在调用时才真正计算

5. 向量

向量化计算原则

R 的核心设计哲学：向量是基本运算单元。几乎所有内置函数都自动对向量逐元素操作，无需显式循环。向量化有两个关键优势：

  1. 性能：向量化操作在 C 层执行，避免了 R 解释器的循环开销。处理百万级数据时，向量化通常比 for 循环快 10-100 倍。
  2. 可读性：x * 2 比 for(i in seq_along(x)) x[i] <- x[i] * 2 更直观。

编写 R 代码时，应始终优先考虑向量化方案，仅在无法向量化时才使用显式循环。

R 
# 创建向量
v1 <- c(1, 2, 3, 4, 5)       # c() 是 combine/concatenate
v2 <- 1:10                   # 序列：1, 2, ..., 10
v3 <- seq(0, 1, 0.2)        # 等间隔序列
v4 <- rep(1, 5)              # 重复：1 1 1 1 1
v5 <- rep(c(1, 2), each=3) # 1 1 1 2 2 2

# 向量化运算
v1 * 2                  # [1]  2  4  6  8 10
v1 ^ 2                  # [1]  1  4  9 16 25
v1 + c(10, 20, 30, 40, 50)  # [1] 11 22 33 44 55

# 向量函数
length(v1)     # 5
sum(v1)        # 15
mean(v1)       # 3
sort(v1, decreasing=TRUE)  # [1] 5 4 3 2 1
rev(v1)        # [1] 5 4 3 2 1
unique(c(1,2,2,3,3,3))  # [1] 1 2 3

# 命名向量
score <- c(Alice=90, Bob=85, Carol=92)
score["Bob"]      # 85
names(score)    # "Alice" "Bob" "Carol"

6. 矩阵与数组

矩阵：二维同质容器

矩阵 (matrix) 是二维的同质数据结构——所有元素必须是同一类型。R 的矩阵在内存中以列优先（column-major）方式存储，这源自 Fortran 传统。理解这一点对重塑和索引操作至关重要。

R 
# 创建矩阵
m <- matrix(1:12, nrow=3, ncol=4)
m
#      [,1] [,2] [,3] [,4]
# [1,]    1    4    7   10
# [2,]    2    5    8   11
# [3,]    3    6    9   12

# 列优先填充！
matrix(1:6, nrow=2, byrow=TRUE)  # 按行填充

# 按行绑定
rbind(c(1,2,3), c(4,5,6))

# 按列绑定
cbind(c(1,4), c(2,5), c(3,6))

# 矩阵运算
m + 10             # 所有元素 +10
m * 2              # 所有元素 *2（逐元素）
m %*% t(m)          # 矩阵乘法（3×3 结果）

# 常用矩阵函数
t(m)              # 转置（4×3）
dim(m)            # c(3, 4)
nrow(m)           # 3
ncol(m)           # 4
diag(3)           # 3×3 单位矩阵
det(matrix(c(1,2,3,4), 2, 2))  # 行列式 = -2
solve(matrix(c(1,2,3,4), 2, 2))  # 求逆

数据框 (Data Frame)

数据框：R 的表格数据核心

数据框是列表的特化形式——每个元素是等长的向量（列），不同列可以是不同类型。它是 R 处理表格数据的主力结构，也是大多数统计函数和建模函数的输入格式。

9. 循环语句

R 
# for 循环
for (i in 1:5) {
  cat("i =", i, "\n")
}

# 遍历向量
fruits <- c("苹果", "香蕉", "橘子")
for (fruit in fruits) {
  cat("我喜欢", fruit, "\n")
}

# while 循环
n <- 1
while (n <= 5) {
  cat("n =", n, "\n")
  n <- n + 1
}

# repeat + break
x <- 1
repeat {
  if (x^2 > 100) break
  x <- x + 1
}

# next — 跳过当前迭代
for (i in 1:10) {
  if (i %% 2 == 0) next  # 跳过偶数
  cat(i, " ")
}
# 1 3 5 7 9
R 的 for 循环比其他语言慢。对于大规模数据，应优先使用向量化操作或 apply 族函数。for 循环适合：迭代次数少（<1000）、每步需要副作用（绘图、写文件）、无法向量化的算法。

错误处理

R 
# try / tryCatch
result <- try(sqrt(-1))
if (inherits(result, "try-error")) {
  cat("计算失败：", conditionMessage(result))
}

  {
    result <- read.csv("不存在的文件.csv")
  },

    cat("文件不存在：", conditionMessage(e), "\n")
  },
  warning = function(w) {
    cat("警告：", conditionMessage(w), "\n")
  }
)

# stop() — 主动抛出错误
validate_age <- function(age) {
  if (!is.numeric(age) || age < 0) {
    stop("age 必须是非负数字")
  }
  TRUE
}

# warning() — 警告
warning("这是一个警告")

11. apply 族函数

函数式编程思想

apply 族函数体现了函数式编程的核心思想：将函数应用于数据结构的每个元素，而不是手动遍历。这比 for 循环更简洁、更安全（避免了索引错误），且在某些场景下性能更优。

R 的函数式编程工具还包括 Reduce()、Map()、Filter()、Reduce() 等高阶函数。

R 
# apply — 对矩阵的行或列应用函数
m <- matrix(1:12, 3, 4)
apply(m, 1, sum)    # 按行求和 → c(22, 26, 30)
apply(m, 2, mean)   # 按列求均值 → c(2, 5, 8, 11)

# lapply — 对列表/向量的每个元素应用函数，返回列表
nums <- list(a=1:10, b=21:30)
lapply(nums, mean)
# $a → 5.5
# $b → 25.5

# sapply — 同 lapply，但尽量返回向量（简化结果）
sapply(nums, mean)   # named vector: a=5.5, b=25.5

# vapply — 指定返回类型（更安全的 sapply）
vapply(nums, mean, numeric(1))

# tapply — 对分组数据应用函数（类似 SQL GROUP BY）
scores <- c(85, 92, 78, 95, 88, 76)
groups <- c("A", "A", "B", "A", "B", "B")
tapply(scores, groups, mean)
#     A     B
# 90.00 83.00

# mapply — 多参数版本的 lapply
mapply(rep, 1:3, 3:1)
# [[1]] 1 1 1
# [[2]] 2 2
# [[3]] 3

# Reduce / Map / Filter（函数式编程）
Reduce(`+`, 1:10)           # 55
Map(function(x,y) x+y, 1:3, 10:12)  # list(11, 13, 15)
Filter(function(x) x %% 2 == 0, 1:10)  # [1] 2 4 6 8 10
推荐使用 purrr 包的 map()、map_dbl()、map_chr() 等函数替代 base R 的 apply 族。它们更一致、类型更安全，且支持公式语法（~ .x^2）。

16. ggplot2

图形语法 (Grammar of Graphics)

ggplot2 基于 Leland Wilkinson 的图形语法理论，将每个统计图形分解为以下核心组件：

  1. 数据 (Data)：要可视化的数据集
  2. 映射 (Aesthetics)：将数据变量映射到视觉属性（x, y, color, fill, size, shape, alpha）
  3. 几何对象 (Geom)：数据的视觉表现（点、线、柱、面等）
  4. 统计变换 (Stat)：对数据的数学处理（密度估计、分箱、回归拟合）
  5. 坐标系 (Coord)：数据在平面上的映射方式（笛卡尔、极坐标）
  6. 分面 (Facet)：按变量将图形分组展示
  7. 主题 (Theme)：非数据驱动的视觉样式

这些组件通过 + 号叠加组合，形成完整的图形。这种分层思想让同一份数据可以通过更换 geom 快速生成不同类型的图表。

18. 假设检验

假设检验框架

假设检验是统计推断的核心方法：

  1. 建立假设：零假设 H₀ 和备择假设 H₁
  2. 选择检验：根据数据类型和分布选择合适的检验方法
  3. 计算检验统计量和 p 值
  4. 决策：p 值 < α（通常 0.05）则拒绝 H₀

R 的 t.test()、chisq.test()、wilcox.test() 等函数返回完整的检验结果对象，包含 p 值、置信区间、统计量等。

R 
# ============ t 检验 ============

# 单样本 t 检验（均值是否等于某值）
t.test(mtcars$mpg, mu=20)

# 双样本 t 检验（两组均值是否相等）
group1 <- rnorm(30, mean=5)
group2 <- rnorm(30, mean=6)
t.test(group1, group2)

# 配对 t 检验
before <- rnorm(20, mean=100)
after  <- before + rnorm(20, mean=5)
t.test(before, after, paired=TRUE)

# ============ 非参数检验 ============

# Wilcoxon 秩和检验（Mann-Whitney U）
wilcox.test(group1, group2)

# Wilcoxon 符号秩检验
wilcox.test(before, after, paired=TRUE)

# ============ 方差分析 (ANOVA) ============
result <- aov(mpg ~ factor(cyl), data=mtcars)
summary(result)

# 多重比较
TukeyHSD(result)

# ============ 卡方检验 ============
# 独立性检验
chisq.test(table(mtcars$cyl, mtcars$gear))

# ============ 正态性检验 ============
shapiro.test(mtcars$mpg)
ks.test(mtcars$mpg, "pnorm", mean=mean(mtcars$mpg), sd=sd(mtcars$mpg))
p 值不能证明零假设为"真"——它只是表示在零假设为真的条件下，观测到当前数据的概率。不要将 p < 0.05 理解为"有 95% 的把握"。

20. 面向对象 (S3/S4)

R 的对象系统

R 拥有三套面向对象系统，它们的设计哲学不同：

  • S3：最轻量、最常用。基于属性 (attribute) 的"鸭子类型"，无需显式定义类。print、summary、plot 等泛型函数通过 UseMethod() 分派到类特定的方法。
  • S4：更严格的 OOP。需要显式定义类 (setClass)、方法 (setMethod) 和泛型 (setGeneric)。支持多分派和参数验证。
  • R5/Reference Classes：可变对象（引用语义），类似于其他语言的类。使用 setRefClass() 定义。
  • R6：第三方包，轻量级可变类，语法类似 Python/Java。
R 
# ============ S3 系统 ============

# 创建 S3 对象
person <- list(name="Alice", age=30)
class(person) <- "Person"    # 设置类属性

# S3 方法
print.Person <- function(x, ...) {
  cat(sprintf("人物: %s, 年龄: %d\n", x$name, x$age))
}

summary.Person <- function(object, ...) {
  cat(sprintf("%s 的年龄是 %d 岁\n", object$name, object$age))
}

print(person)    # 自动调用 print.Person
summary(person)  # 自动调用 summary.Person

# 构造函数（良好习惯）
Person <- function(name, age) {
  structure(
    list(name=name, age=age),
    class = "Person"
  )
}
p <- Person("Bob", 25)

# ============ S4 系统 ============

# 定义类
setClass("Animal",
  slots = list(name="character", age="numeric"),
  prototype = list(name="", age=0)
)

# 创建实例
dog <- new("Animal", name="旺财", age=5)
dog@name     # "旺财"

# 定义泛型和方法
setGeneric("speak", function(object) standardGeneric("speak"))
setMethod("speak", "Animal", function(object) {
  cat(object@name, "说: 汪汪!\n")
})
speak(dog)    # 旺财 说: 汪汪!

24. 高级数据操作 (dplyr)

管道与 across

dplyr 的管道操作符 %>%（或 |>）让数据处理链式调用更清晰。across() 允许对多列同时应用操作，where() 按列类型选择，大幅减少重复代码。

R 
library(tidyverse)

# 创建示例数据
df <- tibble(
  name = c("Alice", "Bob", "Charlie", "Diana"),
  age = c(25, 30, 35, 28),
  math = c(90, 85, 70, 95),
  science = c(88, 92, 75, 90),
  english = c(78, 80, 85, 92)
)

# across：对多列同时计算
df |>
  mutate(
    across(where(is.numeric) & !everything(), # 除 name 外所有数值列
           ~ round(.x * 0.9),  # 缩放10%
           .names = "{.col}_scaled")
  )

# across + 列名模式匹配
df |>
  summarise(
    across(ends_with("e"), # 以 e 结尾的列（math, science）
           list(
             mean = mean,
             sd = sd
           ),
           .names = "{.col}_{.fn}")
  )

# where 按条件选列
df |>
  mutate(
    across(where(~ is.numeric(.x) & max(.x) > 50),

26. 函数式编程 (purrr)

purrr 的核心思想

purrr 提供了一套一致的函数式编程工具。map 系列替代 lapply，possibly() 和 safely() 处理错误，reduce() 折叠。这些函数与管道配合，让数据处理流水线更优雅。

R 
library(purrr)

# map 及其变体
nums <- list(a = 1:3, b = 4:6, c = 7:9)
map(nums, sum)           # 返回 list
map_dbl(nums, mean)      # 返回 double 向量
map_chr(nums, ~paste(.x, collapse = "-"))

# map2：同时遍历两个列表
map2(c(1, 2, 3), c(10, 20, 30), ~ .x + .y)

# possibly：容错版 map
safe_log <- possibly(log, otherwise = NA_real_)
map_dbl(c(1, -1, 0), safe_log)  # -1 返回 NA

# safely：捕获错误详情
safe_calc <- safely(~ 1 / .x)
results <- map(list(1, 2, 0), safe_calc)
map_dbl(results, "result")  # 提取结果
map(results, "error")       # 提取错误

# reduce：折叠/归约
reduce(list(1, 2, 3, 4), ~ .x + .y)  # 10
reduce(list(1, 2, 3, 4), ~ .x * .y)  # 24

# accumulate：带中间结果的 reduce
accumulate(1:5, ~ .x + .y)  # 1, 3, 6, 10, 15

# 实际应用：批量读取和处理
files <- list.files("data/", pattern = "\\.csv$")
all_data <- files |>
  map(~ read_csv(paste0("data/", .x))) |>
  reduce(bind_rows) |>
  filter(year >= 2020)

31. Shiny 入门

交互式 Web 应用

Shiny 让 R 用户无需学习 HTML/CSS/JavaScript 即可构建交互式 Web 应用。通过响应式编程模型，用户输入自动驱动输出更新。

R (Shiny) 
library(shiny)
library(ggplot2)

ui <- fluidPage(
  titlePanel("汽车数据分析"),
  
  sidebarLayout(
    sidebarPanel(
      selectInput("x_var", "X 轴变量:",
                  choices = names(mtcars),
                  selected = "wt"),
      selectInput("y_var", "Y 轴变量:",
                  choices = names(mtcars),
                  selected = "mpg"),
      sliderInput("point_size", "点大小:",
                  min = 1, max = 10, value = 3)
    ),
    
    mainPanel(
      plotOutput("scatter"),
      verbatimTextOutput("summary")
    )
  )
)

server <- function(input, output) {
  output$scatter <- renderPlot({
    ggplot(mtcars, aes(.data[[input$x_var]],
                        .data[[input$y_var]])) +
      geom_point(size = input$point_size) +
      geom_smooth(method = "lm") +
      theme_minimal()
  })
  
  output$summary <- renderPrint({
    summary(mtcars[c(input$x_var, input$y_var)])
  })
}

shinyApp(ui = ui, server = server)
