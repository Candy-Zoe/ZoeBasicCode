1. Lua语言简介

Lua是什么？

Lua是一门小巧、快速、可移植的脚本语言，诞生于1993年的巴西里约热内卢天主教大学（PUC-Rio）。名字"Lua"在葡萄牙语中意为"月亮"，呼应了巴西国旗上的月亮图案。Lua以其极小的体积（标准库编译后仅约200KB）、极快的执行速度（JIT版本可达C的1/3速度）和出色的可嵌入性而闻名于世。

Lua的设计哲学是"提供机制而非策略"（mechanisms, not policies）。它不会替你决定如何编程，而是提供一套精巧的原语，让你自由组合出所需的特性。这种设计使得Lua成为了游戏开发、嵌入式系统、Web服务器等领域的首选脚本语言。

Lua的设计哲学

极致的简洁性：Lua的语法核心只有约20个关键字，完整的语言规范文档不过百页。但这种简洁并非功能的缺失——通过元表（metatable）、闭包（closure）和协程（coroutine）等机制，Lua可以表达极其复杂的编程模式。

表驱动架构（Table-Driven）：Lua中"表"（table）是唯一的数据结构。数组、字典、对象、模块、甚至命名空间——一切皆表。这种统一性使得Lua的概念数量极少，却能灵活应对各种场景。

渐进式扩展：Lua不追求语言本身的庞大，而是通过C API让宿主程序将自身能力"注入"到Lua环境中。LuaJIT的FFI、LuaSocket等扩展都体现了这种"小核心、大生态"的理念。

Lua的应用领域

游戏开发：Lua是游戏脚本领域的事实标准。World of Warcraft、Angry Birds、Roblox、Garry's Mod等知名游戏均使用Lua作为脚本语言。LÖVE、Defold、Solar2D等游戏引擎以Lua为核心。

嵌入式系统：Lua的微型体积使其非常适合资源受限的环境。许多路由器固件（如OpenWrt）、IoT设备和工业控制器使用Lua作为配置和扩展语言。

Web开发：OpenResty/Nginx通过Lua实现了高性能的Web服务。Lapis、Sailor等框架让Lua也能胜任Web后端开发。

数据库扩展：Redis从2.6版本开始内置Lua解释器，支持用Lua脚本实现原子性的复杂操作。MySQL也支持Lua存储过程。

网络工具：Nmap的脚本引擎（NSE）、Wireshark的协议解析器都使用Lua编写。

Lua版本演进

Lua 5.0（2003年）：引入协程（coroutine），实现真正的非对称协程模型。

Lua 5.1（2006年）：引入模块系统（require/module），垃圾回收器改为分代式增量回收，是目前使用最广泛的稳定版本。

Lua 5.2（2011年）：移除模块系统的隐式全局变量，引入可变参数的更好支持，增加goto语句。

Lua 5.3（2015年）：引入原生64位整数支持和位运算库，加强了与C的互操作性。

Lua 5.4（2020年）：引入新的垃圾回收器（分代+增量混合），支持即时值（ephemeron），改进了弱引用语义。

LuaJIT：Mike Pall开发的Lua即时编译器，提供接近C的执行性能，是Lua性能的标杆。

Lua

-- Lua的核心优势一览
print("体积: 约200KB")
print("关键字: 仅20个")
print("数据结构: 仅table一种")
print("设计理念: 机制而非策略")

3. 基本语法

Lua的语法规则

Lua的语法设计追求最小惊奇原则。如果你有其他脚本语言的经验，Lua的大部分语法都会觉得很熟悉。Lua使用缩进不敏感的语法（与Python不同），使用end关键字结束代码块（与Ruby/Bash类似），注释使用--（单行）和--[[ ]]（多行）。

大小写敏感：Lua区分大小写，variable、Variable和VARIABLE是三个不同的标识符。

标识符命名：以字母或下划线开头，后跟字母、数字或下划线。Lua约定以下划线开头的变量是"私有"的（如_private），全大写用于常量（如MAX_SIZE）。

Lua 
-- Lua的20个关键字（Lua 5.4）
-- and       break     do        else      elseif
-- end       false     for       function  goto
-- if        in        local     nil       not
-- or        repeat    return    then      true
-- until     while

-- 基本输出
print("Hello, Lua!")
print(42)           -- 整数
print(3.14)         -- 浮点数
print(true)         -- 布尔值
print(nil)          -- 空值

-- 注释
-- 这是单行注释

--[[
    这是多行注释
    可以跨越多行
]]

--[=[
    这也是多行注释
    使用 [=[ 和 ]=] 作为界定符

]=]

-- 语句结束符（可选）

-- do...end 代码块

    local x = 10

-- 多重赋值

local x, y = 10, 20
local p, q = 1     -- p=1, q=nil（未赋值的变量为nil）

4. 变量与类型

Lua的动态类型系统

Lua是动态类型语言，变量本身没有类型，只有值才有类型。Lua提供8种基本类型：

nil：空值类型，全局唯一的nil值。所有未初始化的变量都是nil。nil既是"没有值"的表示，也是"删除表字段"的工具。

boolean：布尔类型，只有true和false两个值。在Lua中，只有nil和false是假值，其他所有值（包括0和空字符串""）都是真值。

number：数字类型，Lua 5.3+统一了整数（integer）和浮点数（float），不再有显式区分。

string：字符串类型，不可变的字节序列。Lua字符串是二进制安全的，可以包含任意字节。

function：函数类型，Lua中的函数是一等公民，可以赋值给变量、作为参数传递。

table：表类型，Lua唯一的数据结构。关联数组的实现，可同时充当数组和字典。

userdata：用户数据类型，用于将C/C++数据暴露给Lua。

thread：协程类型，用于实现协作式多任务。

Lua 
-- 使用 type() 函数检查变量类型
print(type(nil))          -- nil
print(type(true))         -- boolean
print(type(42))           -- number
print(type(3.14))         -- number
print(type("hello"))      -- string
print(type(print))        -- function
print(type({}))           -- table
print(type(nil))          -- nil

-- 整数与浮点数（Lua 5.3+）
local int_val = 42         -- 整数
local float_val = 3.14     -- 浮点数
print(math.type(int_val))   -- integer
print(math.type(float_val)) -- float

-- 数字字面量的多种写法
local a = 42            -- 十进制整数
local b = 0xFF          -- 十六进制
local c = 0b1010        -- 二进制（Lua 5.2+）
local d = 1e3           -- 科学计数法（1000）
local e = 3.14e-2       -- 0.0314
local f = 1_000_000     -- 下划线分隔（Lua 5.2+）

-- 两种变量声明方式
x = 10              -- 全局变量（不推荐）
local y = 20        -- 局部变量（推荐）
Lua的真值系统

Lua采用了一种极简的真值判断：只有nil和false是假值，其他一切都是真值。这意味着：

0是真值（与C/Python不同），""（空字符串）是真值，{}（空表）是真值。这种设计避免了"0是否为假"这类歧义，简化了条件判断逻辑。

Lua 
-- Lua的真值系统
if 0 then print("0 是真值！") end         -- 会执行
if "" then print("空字符串是真值！") end  -- 会执行
if {} then print("空表是真值！") end      -- 会执行
if nil then print("这条不会显示") end   -- 不执行
if false then print("这条也不会显示") end -- 不执行

-- 变量作用域与生命期
do
    local a = 1    -- a 的作用域从这里开始
    print(a)       -- 1
end
-- print(a)  -- 错误！a 已经超出作用域

-- 变量遮蔽（Shadowing）
local x = 10
do
    local x = 20   -- 这是一个新的 x，遮蔽了外部的 x
    print(x)       -- 20
end
print(x)          -- 10（外部的 x）

5. 运算符

Lua运算符概览

Lua提供了算术、关系、逻辑、位运算、连接和长度六大类运算符。运算符优先级从高到低排列：一元运算符 > 连接 > 算术 > 关系 > 逻辑 > 赋值。

值得注意的是，Lua的逻辑运算符采用短路求值，但它们返回的是操作数本身而非布尔值（类似JavaScript的||和&&）。这个特性在设置默认值时非常有用。

Lua 
-- 算术运算符
print(10 + 3)     -- 13  加法
print(10 - 3)     -- 7   减法
print(10 * 3)     -- 30  乘法
print(10 / 3)     -- 3.333... 除法
print(10 // 3)    -- 3   整除（Lua 5.3+）
print(10 % 3)     -- 1   取模
print(10 ^ 3)     -- 1000 乘方

-- 一元运算符
print(-5)           -- -5   取负
print(#"hello")     -- 5    长度运算符
print(#{}           -- 0    空表长度

-- 关系运算符（返回 boolean）
print(1 == 1)       -- true  等于
print(1 ~= 2)       -- true  不等于
print(1 < 2)        -- true  小于
print(2 > 1)        -- true  大于
print(1 <= 1)       -- true  小于等于
print(2 >= 2)       -- true  大于等于

-- 逻辑运算符（短路求值，返回操作数）
print(true and "yes")    -- "yes"（返回第二个操作数）
print(false and "yes")   -- false（短路返回第一个操作数）
print(nil or "default")  -- "default"（nil为假，返回第二个）
print(false or "hi")    -- "hi"
print(not false)         -- true

-- 常用模式：设置默认值
local name = nil
local display_name = name or "匿名"
print(display_name)  -- "匿名"

-- 位运算符（Lua 5.3+）
print(0xFF & 0x0F)    -- 15   按位与
print(0xF0 | 0x0F)    -- 255  按位或
print(0xFF ~ 0x0F)    -- 240  按位异或
print(~0)              -- -1   按位取反
print(1 << 8)          -- 256  左移
print(256 >> 4)        -- 16   右移
Lua的逻辑运算符返回操作数而非布尔值。nil or 0返回0，false and 1返回false。在需要布尔结果时，请显式使用not not x进行转换。

6. 字符串

Lua字符串的内部实现

Lua字符串是不可变的字节序列，由自动内存管理（GC）负责分配和回收。每个字符串在Lua中都是内驻化（interned）的——相同的字符串字面量在内存中只存在一份副本，通过哈希表管理。这意味着字符串比较（==）实际上是比较指针，时间复杂度为O(1)。

Lua字符串是二进制安全的，可以包含任意字节（包括\0）。长度运算符#返回字符串的字节数而非字符数（对于UTF-8字符串，字节数 ≠ 字符数）。

Lua

local s2 = "双引号字符串"
local s3 = [[多行字符串
可以跨越多行
不需要转义]]

-- 长括号语法（防止嵌套问题）
local s4 = [=[
    这可以包含 [[ ]] 而不会产生嵌套问题
    使用 [=[ 和 ]=] 作为界定符
]=]

-- 转义序列
print("换行符: \n制表符: \t反斜杠: \\")
print("空字符: \0二进制安全")  -- 字符串可以包含 \0
print("十六进制: \x48\x65\x6C\x6C\x6F")  -- Hello（Lua 5.2+）

-- Unicode支持（Lua 5.3+）
print("\u{4F60}\u{597D}")  -- 你好

-- 字符串长度

print(#"你好")           -- 6（UTF-8编码的字节数）

-- 字符串操作函数
local s = "Hello, World!"

-- 大小写转换
print(string.upper(s))     -- HELLO, WORLD!
print(string.lower(s))     -- hello, world!

-- 查找与提取
local start, stop = string.find(s, "World")

    "小明", 25, 1.75))

print(string.reverse("abc"))  -- cba
print(string.rep("ha", 3))    -- hahaha

-- 字符串与数值转换
local num = tonumber("42")     -- 42
local str = tostring(42)       -- "42"

-- 字符串拼接
local full = "Hello" .. ", " .. "World!"
print(full)                  -- Hello, World!

-- table.concat 高效拼接多字符串
local parts = {"Lua", "is", "great"}
print(table.concat(parts, " "))  -- Lua is great
Lua 
-- 模式匹配（Pattern Matching）— Lua的杀手锏
-- Lua不使用正则表达式，而是使用自己的模式匹配系统
-- 模式比正则更简洁，但功能也略有不同

local text = "Today is 2025-01-15"

-- 基本匹配
local date = string.match(text, "%d%d%d%d%-%d%d%-%d%d")
print(date)  -- 2025-01-15

-- 捕获组（使用括号）
local year, month, day = string.match(text, "(%d%d%d%d)%-(%d%d)%-(%d%d)")
print(year, month, day)  -- 2025  01  15

-- 迭代所有匹配
local s = "cat, dog, fish"
for animal in string.gmatch(s, "%w+") do
    print(animal)
end
-- 输出: cat, dog, fish

-- 替换
local result = string.gsub(text, "%d+", "**")
print(result)  -- Today is **-**-**

-- 模式匹配特殊字符
-- .  匹配任意字符
-- %a 匹配字母
-- %d 匹配数字
-- %s 匹配空白字符
-- %w 匹配字母和数字
-- +  一次或多次
-- *  零次或多次
-- -  零次或多次（最短匹配）

7. 表(Table)

表的内部实现原理

Lua的表（table）是整个语言中最核心的数据结构，也是唯一的数据结构。它在底层实际上是一个混合数据结构，根据使用方式的不同，Lua会自动选择最优的存储策略：

数组部分（Array Part）：当表的键是连续的正整数（1, 2, 3, ...）时，Lua会将其存储在一个连续的C数组中，类似其他语言的动态数组。这使得按下标访问的时间复杂度为O(1)，与C数组一样快。

哈希部分（Hash Part）：对于非整数键（字符串键、负数键、稀疏整数键），Lua使用开放寻址哈希表实现。哈希表使用控制探针（controlled probing）来解决冲突，保证良好的缓存局部性。

自动重组：当Lua检测到表的使用模式发生变化时（如从连续数组变为稀疏使用），会自动重新组织内部存储。例如，当你向一个只有整数键的表中插入字符串键时，Lua会分配哈希部分。

Lua 
-- 表的创建与基本操作
local fruit = {}           -- 创建空表
fruit[1] = "苹果"          -- 数组式访问
fruit[2] = "香蕉"
fruit[3] = "橙子"

-- 构造器语法
local colors = {"红", "绿", "蓝"}      -- 数组
local person = {name = "张三", age = 30}  -- 字典
local mixed = {1, 2, name = "测试"}       -- 混合

-- 访问方式
print(colors[1])           -- 红（下标访问）
print(person.name)         -- 张三（点号访问）
print(person["name"])      -- 张三（字符串键访问）

-- 表长度
print(#colors)             -- 3（整数序列长度）
print(#person)             -- 0（没有整数键，长度为0）

-- 遍历
for i, v in ipairs(colors) do  -- ipairs: 只遍历整数序列
    print(i, v)
end

for k, v in pairs(person) do  -- pairs: 遍历所有键值对
    print(k, v)
end
Lua 
-- 表的高级用法

-- 插入与删除
local list = {1, 2, 3}
table.insert(list, 4)         -- 在末尾插入
table.insert(list, 2, 99)    -- 在位置2插入
print(table.concat(list, ", "))  -- 1, 99, 2, 3, 4

table.remove(list, 1)        -- 删除位置1的元素
print(table.concat(list, ", "))  -- 99, 2, 3, 4

-- 排序
local nums = {5, 3, 1, 4, 2}
table.sort(nums)
print(table.concat(nums, " "))  -- 1 2 3 4 5

-- 自定义排序
local names = {"Charlie", "Alice", "Bob"}
table.sort(names, function(a, b) return a < b end)
print(table.concat(names, ", "))  -- Alice, Bob, Charlie

-- 表作为栈和队列
local stack = {}
table.insert(stack, "a")   -- push
table.insert(stack, "b")   -- push
local top = table.remove(stack)  -- pop → "b"

-- 多维数组
local matrix = {}
for i = 1, 3 do
    matrix[i] = {}
    for j = 1, 3 do
        matrix[i][j] = i * j
    end
end
print(matrix[2][3])  -- 6

8. 条件判断

Lua的控制流结构

Lua提供了三种条件判断结构：if...then...end、if...elseif...else...end和三元运算符模式（利用逻辑运算符）。所有条件判断都基于真值系统：只有nil和false为假。

注意：Lua没有switch/case语句。对于多分支判断，可以使用if...elseif链，或者利用表映射模拟switch。Lua 5.2引入的goto语句也可以模拟某些switch模式。

Lua 
-- 基本 if...then

9. 循环语句

10. 函数

Lua函数的本质

Lua中的函数是一等公民（first-class citizen），这意味着函数可以赋值给变量、作为参数传递、作为返回值返回。在底层，Lua函数实际上是一个闭包（closure），包含一个函数原型（prototype）和一个引用环境（upvalue引用链）。

函数的定义有两种语法：function foo() end是foo = function() end的语法糖。Lua还支持局部函数（local function），其效率比全局函数更高，因为局部变量的访问比全局变量快得多。

Lua 
-- 函数定义的两种等价方式
function greet(name)
    print("你好, " .. name .. "!")
end

local greet2 = function(name)
    print("你好, " .. name .. "!")
end

-- 局部函数（推荐使用）
local function add(a, b)
    return a + b
end

-- 可变参数
local function sum(...)
    local args = {...}
    local total = 0
    for _, v in ipairs(args) do
        total = total + v
    end
    return total
end

print(sum(1, 2, 3, 4, 5))  -- 15

-- Lua 5.0 风格的可变参数（更高效）
local function printf(fmt, ...)
    local args = table.pack(...)
    for i = 1, args.n do
        args[i] = tostring(args[i])
    end
    print(string.format(fmt, table.unpack(args, 1, args.n)))
end

-- 尾调用优化（Tail Call Optimization）
local function factorial(n, acc)
    acc = acc or 1
    if n <= 1 then
        return acc  -- 尾调用：return f(args) 的形式
    end
    return factorial(n - 1, n * acc)  -- 尾调用优化
end

print(factorial(100))  -- 不会栈溢出！

11. 多返回值

多返回值机制

Lua的函数可以同时返回多个值，这是Lua最强大的特性之一。在底层，多返回值通过Lua栈实现——函数将返回值依次压入栈中，调用者再依次弹出。

需要注意的是，多返回值在赋值时会被完整接收，但在作为函数参数传递或作为表达式使用时，只有第一个值会被保留（除非使用括号强制保留所有值）。

Lua 
-- 多返回值函数
local function swap(a, b)
    return b, a
end

local x, y = swap(1, 2)
print(x, y)  -- 2  1

-- 常见模式：返回值 + 状态
local function find(tbl, target)
    for i, v in ipairs(tbl) do
        if v == target then
            return i, true  -- 找到：返回位置和成功标志
        end
    end
    return nil, false  -- 未找到：返回nil和失败标志
end

local list = {10, 20, 30, 40}
local idx, found = find(list, 30)
if found then
    print("找到位置: " .. idx)
end

-- 调整返回值数量（适配左值数量）

local d = swap(1, 2)
print(d)        -- 2（只取第一个返回值）

-- 标准库中的多返回值函数
local string.find(s, pattern) returns start, stop

local math.modf(x) returns integer_part, fractional_part

print(int_part, frac_part)  -- 3  0.14

12. 闭包

闭包的实现机制

闭包（closure）是Lua最优雅的特性之一。一个闭包由两部分组成：一个内部函数和对该函数外部局部变量（upvalue）的引用。即使外部函数已经返回，闭包仍然可以访问和修改那些局部变量的值。

在Lua虚拟机内部，upvalue通过链表管理。当函数首次创建时，所有upvalue都是"打开"状态——直接指向栈上的变量。当外部函数返回后，Lua会将这些upvalue"关闭"——从栈上复制到堆上，确保它们在外部函数销毁后仍然存活。

Lua 
-- 经典的计数器闭包
local function create_counter(start)
    local count = start  -- 这个局部变量被闭包捕获
    return function()
        count = count + 1
        return count
    end
end

local counter = create_counter(0)
print(counter())  -- 1
print(counter())  -- 2
print(counter())  -- 3

-- 每个闭包都有自己独立的状态
local counter2 = create_counter(100)
print(counter2())  -- 101
print(counter2())  -- 102

-- 闭包实现函数工厂
local function create_multiplier(factor)
    return function(x)
        return x * factor
    end
end

local double = create_multiplier(2)
local triple = create_multiplier(3)
print(double(5))   -- 10
print(triple(5))   -- 15

-- 闭包实现迭代器
local function range(start, stop, step)
    step = step or 1
    local current = start - step
    return function()
        current = current + step
        if current <= stop then
            return current
        end
    end
end

for n in range(1, 10, 2) do
    print(n)  -- 1, 3, 5, 7, 9
end

-- 闭包实现私有变量（模拟对象）
local function create_bank_account(owner, initial)
    local balance = initial  -- 私有变量
    return {
        deposit = function(amount)
            balance = balance + amount
            print(string.format("存入 %.2f, 余额 %.2f", amount, balance))
        end,
        withdraw = function(amount)
            if amount > balance then
                print("余额不足！")
                return false
            end
            balance = balance - amount
            print(string.format("取出 %.2f, 余额 %.2f", amount, balance))
            return true
        end,
        get_balance = function()
            return balance
        end
    }
end

account.withdraw(200)

13. 元表与元方法

元表的底层机制

元表（metatable）是Lua实现运算符重载、属性自定义和面向对象的核心机制。每个表（以及userdata）都可以拥有一个元表，元表定义了该表在特定操作下的行为。

在底层，元表是一个普通表，其中的键是元方法名（以双下划线__开头），值是函数。当Lua对一个表执行某种操作时（如加法、索引访问、tostring），它会检查该表是否有元表，如果有则查找对应的元方法并调用。

元方法查找机制：Lua提供了两个控制元方法查找的元方法：__index（控制键不存在时的查找）和__newindex（控制新键赋值时的行为）。这两个元方法可以是函数，也可以是另一个表（表作为继承链）。

Lua 
-- 常用元方法一览
-- __index     : 索引访问 t[key] 时触发
-- __newindex  : 索引赋值 t[key]=v 时触发
-- __add       : 加法 t + other 时触发
-- __sub       : 减法 t - other
-- __mul       : 乘法 t * other
-- __div       : 除法 t / other
-- __mod       : 取模 t % other
-- __pow       : 乘方 t ^ other
-- __unm       : 取负 -t
-- __concat    : 连接 t .. other
-- __len       : 长度 #t
-- __eq        : 相等 t == other
-- __lt        : 小于 t < other
-- __le        : 小于等于 t <= other
-- __call      : 函数调用 t()
-- __tostring  : 转字符串 tostring(t)

-- __index 元方法：基本的属性查找
local person = {
    name = "张三",
    age = 30
}

-- 设置元表
local mt = {
    __index = function(t, key)
        if key == "greeting" then
            return "你好，我是" .. t.name
        end
        return nil
    end
}
setmetatable(person, mt)

print(person.name)       -- 张三（直接访问）
print(person.greeting)   -- 你好，我是张三（通过 __index）
print(person.email)      -- nil（__index 返回 nil）

-- __index 使用表（更高效的继承方式）
local defaults = {
    color = "红色",
    size = "中号",
    font = "宋体"
}

local config = {color = "蓝色"}
setmetatable(config, {__index = defaults})

print(config.color)  -- 蓝色（自身有）
print(config.size)   -- 中号（从 defaults 继承）
Lua 
-- 运算符重载示例：向量类
local Vector = {}
Vector.__index = Vector

function Vector.new(cls, x, y)
    return setmetatable({x = x or 0, y = y or 0}, cls)
end

function Vector:__add(other)
    return Vector:new(self.x + other.x, self.y + other.y)
end

function Vector:__sub(other)
    return Vector:new(self.x - other.x, self.y - other.y)
end

function Vector:__mul(scalar)
    return Vector:new(self.x * scalar, self.y * scalar)
end

function Vector:__eq(other)
    return self.x == other.x and self.y == other.y
end

function Vector:__tostring()
    return string.format("Vector(%g, %g)", self.x, self.y)
end

function Vector:__len()
    return math.sqrt(self.x ^ 2 + self.y ^ 2)
end

-- 使用
local v1 = Vector:new(3, 4)
local v2 = Vector:new(1, 2)

print(v1 + v2)          -- Vector(4, 6)
print(v1 - v2)          -- Vector(2, 2)
print(v1 * 2)           -- Vector(6, 8)
print(#v1)              -- 5（向量长度）
print(v1 == v2)         -- false
__call 与 __len 的深层含义

__call元方法使表可以像函数一样被调用。这在实现代理模式、工厂模式和惰性求值时非常有用。在底层，t(args)会被转化为getmetatable(t).__call(t, args)。

__len元方法允许自定义#t的行为。标准库中，string和table的长度运算都使用了元方法。如果表没有__len元方法，Lua会使用序列长度（sequence length）——即从1开始的连续整数键的数量。

14. 面向对象

Lua的面向对象实现

Lua没有内置的类（class）或对象（object）概念，但通过表、元表和闭包的组合，可以实现完整的面向对象编程。这种实现方式的核心思想是：

对象就是一个表，包含数据（字段）和操作（方法）。类就是一个元表，定义了对象的行为。继承通过元表链实现——子类的__index指向父类，形成原型链。

这种实现方式与JavaScript的原型继承类似，但更加灵活——因为Lua的元表机制允许你拦截任何操作。

Lua 
-- 创建一个"类"
local Animal = {}
Animal.__index = Animal

-- 构造函数
function Animal.new(name, sound)
    local self = setmetatable({}, Animal)
    self.name = name
    self.sound = sound
    self.energy = 100
    return self
end

-- 方法（使用冒号语法自动传递 self）
function Animal:speak()
    print(self.name .. "说: " .. self.sound .. "!")
end

function Animal:eat(food)
    self.energy = self.energy + 10
    print(self.name .. "吃了" .. food)
end

function Animal:get_energy()
    return self.energy
end

-- 使用
local cat = Animal:new("小猫", "喵")
cat:speak()     -- 小猫说: 喵!
cat:eat("鱼")   -- 小猫吃了鱼
print(cat:get_energy())  -- 110
Lua 
-- 继承：从 Animal 派生 Dog 类
local Dog = setmetatable({}, {__index = Animal})
Dog.__index = Dog

function Dog.new(name)
    local self = Animal.new(name, "汪")  -- 调用父类构造函数
    return setmetatable(self, Dog)
end

function Dog:fetch(item)
    print(self.name .. "叼回了" .. item)
    self.energy = self.energy - 5
end

-- 覆盖父类方法
function Dog:speak()
    print(self.name .. "大声叫: " .. self.sound .. "!!!")
end

-- 使用继承的类
local dog = Dog:new("旺财")
dog:speak()       -- 旺财大声叫: 汪!!!（子类方法）
dog:eat("骨头")  -- 旺财吃了骨头（继承的方法）
dog:fetch("球")  -- 旺财叼回了球

-- 类型检查
function Animal:is_a(cls)
    local mt = getmetatable(self)
    while mt do
        if mt == cls then return true end
        mt = mt.__index
    end
    return false
end

print(dog:is_a(Dog))      -- true
print(dog:is_a(Animal))   -- true

15. 模块系统

Lua模块的加载机制

Lua的模块系统基于require函数和package表。当调用require("module_name")时，Lua会按照package.path定义的路径搜索模块文件，执行该文件，并返回其返回的表。模块只会被加载一次，后续require调用会返回缓存的结果。

模块的标准模式是创建一个局部表，将所有公开接口放入表中，最后返回该表。这确保了模块不会污染全局命名空间。

function M.circle_area(radius)
    return PI * radius ^ 2
end

function M.circle_perimeter(radius)
    return 2 * PI * radius
end

-- 返回模块表
return M

16. 协程

协程的实现原理

Lua的协程（coroutine）是一种协作式多任务机制，与操作系统线程不同，协程的切换完全由程序控制。每个协程都有自己的独立栈、指令指针和局部变量，但它们运行在同一个操作系统线程中。

在底层，Lua协程通过longjmp/setjmp实现上下文切换。当协程挂起（yield）时，Lua会将整个调用栈保存到堆上；当恢复（resume）时，再将栈恢复。这意味着协程的切换开销比线程小得多，但每个协程的栈占用更多内存。

Lua提供两种协程类型：非对称协程（asymmetric coroutine，Lua默认）和对称协程（symmetric coroutine，通过库实现）。非对称协程只能从创建者处挂起和恢复。

Lua 
-- 协程的基本状态
-- "suspended" — 挂起状态（初始状态和yield后）
-- "running"   — 运行状态
-- "normal"    — 正常状态（resume后在父协程中）
-- "dead"      — 死亡状态（函数执行完毕或错误）

-- 创建协程
local co = coroutine.create(function()
    print("协程开始执行")
    coroutine.yield("挂起时返回的值")
    print("协程恢复执行")
    return "最终返回值"
end)

print(coroutine.status(co))  -- suspended

local success, value = coroutine.resume(co)
print(success, value)  -- true  挂起时返回的值

local success, value = coroutine.resume(co)
print(success, value)  -- true  最终返回值

print(coroutine.status(co))  -- dead

-- 协程间传递数据
local producer = coroutine.create(function()
    for i = 1, 5 do
        coroutine.yield(i * 10)  -- 产出数据
    end
end)

-- 消费者模式
while coroutine.status(producer) ~= "dead" do
    local success, value = coroutine.resume(producer)
    if success and value then
        print("收到:", value)
    end
end
Lua 
-- 协程实现协作式调度器
local scheduler = {}

function scheduler.create(func)
    local co = coroutine.create(func)
    table.insert(scheduler, co)
end

function scheduler.run()
    while #scheduler > 0 do
        local co = table.remove(scheduler, 1)
        local success, err = coroutine.resume(co)
        if not success then
            print("协程错误:", err)
        end
        if coroutine.status(co) ~= "dead" then
            table.insert(scheduler, co)
        end
    end
end

-- 使用调度器
scheduler.create(function()
    for i = 1, 3 do
        print("任务A:", i)
        coroutine.yield()
    end
end)

scheduler.create(function()
    for i = 1, 3 do
        print("任务B:", i)
        coroutine.yield()
    end
end)

scheduler.run()
-- 输出: 任务A:1, 任务B:1, 任务A:2, 任务B:2, 任务A:3, 任务B:3

-- 协程实现异步I/O模式
local function async_read(filename)
    print("开始读取" .. filename)
    coroutine.yield()  -- 模拟异步等待
    return "文件内容"
end

17. 垃圾回收

Lua垃圾回收器的演进

Lua使用自动垃圾回收（GC）管理内存，开发者无需手动分配和释放。Lua的GC经历了多次重大改进：

Lua 5.0：使用简单的标记-清除（Mark-Sweep）算法。每次GC会遍历整个对象图，暂停时间与对象总数成正比。

Lua 5.1：引入增量式垃圾回收（Incremental GC）。将GC工作分散到多个步骤中，每步只处理一小部分对象，大幅减少最长暂停时间。同时引入分代回收（Generational GC）的实验性支持。

Lua 5.2-5.3：改进增量GC的参数调优，支持更细粒度的GC控制。

Lua 5.4：引入分代+增量混合的GC。分代GC假设"大多数对象是短命的"，将对象分为"年轻代"和"老年代"，对年轻代进行更频繁的回收。

Lua 
-- Lua 5.4 垃圾回收器的增量算法
-- 分为两个阶段：
-- 1. 标记阶段（Mark Phase）：遍历所有可达对象，标记为"存活"
-- 2. 清除阶段（Sweep Phase）：回收未标记的对象
-- 增量方式：将标记和清除工作分散到多个小步骤中

-- GC 控制函数
collectgarbage("collect")      -- 强制执行一次完整的GC
collectgarbage("count")       -- 返回当前内存使用量（KB）
collectgarbage("countpages")  -- 返回内存使用量的页数

-- 控制GC步长（增量GC）
collectgarbage("setpause", 100)   -- 设置GC暂停时间百分比
collectgarbage("setstepmul", 200) -- 设置GC步长倍增因子

-- 查看GC统计信息
print(collectgarbage("count"))  -- 当前内存（KB）
print(collectgarbage("gennum"))  -- 分代GC的代数（Lua 5.4）

-- 弱引用表（Weak Tables）
-- 元表中的 __mode 字段控制弱引用类型
-- "k" — 键为弱引用（键可被GC回收）
-- "v" — 值为弱引用（值可被GC回收）
-- "kv" — 键和值都是弱引用

local cache = {}
setmetatable(cache, {__mode = "v"})  -- 值为弱引用

local key = {name = "临时对象"}
cache[key] = "数据"

print(cache[key])   -- "数据"
key = nil           -- 删除对键的引用
collectgarbage("collect")
print(cache[key])   -- nil（数据已被GC回收）

-- GC 的实际使用场景
-- 1. 内存监控
local function check_memory()
    local before = collectgarbage("count")
    collectgarbage("collect")
    local after = collectgarbage("count")
    print(string.format("GC回收了 %.2f KB", before - after))
end

19. 与C交互

Lua C API的工作原理

Lua与C的交互通过栈（stack）实现。所有Lua值的传递都通过一个虚拟栈进行：C代码将参数压入栈，调用Lua函数，然后从栈中弹出返回值。这个栈是类型安全的——每个槽位存储一个Lua值，C代码可以检查和操作这些值。

Lua C API的核心函数分为几类：栈操作（push/get/pop）、类型检查（is*/check*）、函数调用（call/pcall）和内存管理（userdata创建）。

C 
// mylib.c — 一个简单的Lua C扩展
#include "lua.h"
#include "lauxlib.h"
#include "lualib.h"

// C函数实现：加法
static int lua_add(lua_State *L) {
    // 从栈中获取参数
    double a = luaL_checknumber(L, 1);
    double b = luaL_checknumber(L, 2);
    
    // 将结果压入栈
    lua_pushnumber(L, a + b);
    
    // 返回1个值
    return 1;
}

// 注册函数到Lua
static const luaL_Reg mylib[] = {
    {"add", lua_add},
    {NULL, NULL}  // 终止标记
};

// 模块入口函数
int luaopen_mylib(lua_State *L) {
    luaL_newlib(L, mylib);
    return 1;
}

Userdata与Lightuserdata

Userdata是Lua管理的内存块，用于在Lua中存储C数据。创建userdata时，Lua会分配一块内存并返回一个指向它的指针。可以为userdata设置元表，为其添加方法和操作符。

Lightuserdata是存储在Lua值中的C指针。它不被Lua管理（不参与GC），适用于存储C对象的指针。轻量级userdata通常用于与C库交互。

C 
// Userdata 示例：自定义Vector
typedef struct {
    double x, y;
} Vector;

static int lua_vector_new(lua_State *L) {
    double x = luaL_optnumber(L, 1, 0);
    double y = luaL_optnumber(L, 2, 0);
    
    // 创建userdata
    Vector *v = (struct Vector *)lua_newuserdata(L, sizeof(Vector));
    v->x = x;
    v->y = y;
    
    // 设置元表
    luaL_setmetatable(L, "VectorMT");
    
    return 1;  // 返回userdata
}

static int lua_vector_add(lua_State *L) {
    Vector *a = (struct Vector *)luaL_checkudata(L, 1, "VectorMT");
    Vector *b = (struct Vector *)luaL_checkudata(L, 2, "VectorMT");
    
    Vector *result = (struct Vector *)lua_newuserdata(L, sizeof(Vector));
    result->x = a->x + b->x;
    result->y = a->y + b->y;
    
    luaL_setmetatable(L, "VectorMT");
    return 1;
}

20. 游戏开发应用

Lua在游戏开发中的地位

Lua是游戏脚本领域的事实标准。几乎所有主流游戏引擎都支持Lua作为脚本语言。Lua在游戏开发中的优势包括：

嵌入性：Lua可以轻松嵌入C/C++游戏引擎，不需要修改引擎代码。

性能：LuaJIT提供接近C的执行速度，适合游戏逻辑。

安全性：游戏逻辑运行在Lua沙箱中，即使脚本出错也不会崩溃游戏。

热重载：修改Lua脚本后无需重新编译，可以即时生效。

-- 游戏实体组件系统（ECS）基础

        entities = {},

function ECS:create_entity()
    local id = #self.entities + 1

function ECS:add_component(entity_id, component_name, data)
    if not self.components[component_name] then
        self.components[component_name] = {}
    end
    self.components[component_name][entity_id] = data
end

function ECS:get_component(entity_id, component_name)
    return self.components[component_name] and
           self.components[component_name][entity_id]
end

        end
    end

-- 游戏状态管理（有限状态机）
local StateMachine = {}
StateMachine.__index = StateMachine

function StateMachine.new(states)
    local self = setmetatable({
        states = states,
        current = nil,
        global_state = nil
    }, StateMachine)
    return self
end

function StateMachine:change(state_name, enter_data)
    if self.current then
        self.current.exit(self.owner, enter_data)
    end
    self.current = self.states[state_name]
    if self.current then
        self.current.enter(self.owner, enter_data)
    end
end

function StateMachine:update(dt)
    if self.global_state then
        self.global_state.update(self.owner, dt)
    end
    if self.current then
        self.current.update(self.owner, dt)
    end
end

项目结构建议

模块化：将功能拆分为独立模块，每个模块职责单一。使用require管理依赖。

命名约定：模块名使用小写下划线（my_module），类名使用大驼峰（MyClass），私有函数以下划线开头（_helper）。
