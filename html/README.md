# 编程语言 HTML 教程

系统化编程语言教程，从零基础到进阶，深入原理讲解，配有丰富代码示例。

## 运行方式

直接用浏览器打开 `index.html` 即可浏览所有教程。

## 目录结构

```
html/
├── index.html              # 首页（教程导航）
├── assets/
│   └── style.css           # 共享样式
├── python/index.html       # Python 教程（25章）
├── javascript/index.html   # JavaScript 教程（27章）
├── typescript/index.html   # TypeScript 教程（21章）
├── java/index.html         # Java 教程（24章）
├── c/index.html            # C 语言教程（26章）
├── cpp/index.html          # C++ 教程（27章）
├── csharp/index.html       # C# 教程（26章）
├── go/index.html           # Go 教程（27章）
├── rust/index.html         # Rust 教程（25章）
├── kotlin/index.html       # Kotlin 教程（24章）
├── shell/index.html        # Shell 教程（19章）
├── sql/index.html          # SQL 教程（24章）
├── lua/index.html          # Lua 教程（21章）
├── r/index.html            # R 教程（23章）
└── css/index.html          # CSS 教程（27章）
```

## 教程特色

- **暗色主题**：护眼的深色界面设计
- **侧边栏导航**：快速跳转到任意章节
- **原理讲解**：每个核心概念都配有深入的原理解析
- **代码高亮**：丰富的语法高亮代码示例
- **响应式设计**：支持手机、平板、桌面端浏览

## 推荐学习路线

| 方向 | 推荐顺序 |
|------|----------|
| 前端开发 | HTML → CSS → JavaScript → TypeScript |
| 后端开发 | Python/Java/Go → SQL → Shell |
| 系统编程 | C → C++ → Rust |
| 数据科学 | Python → R → SQL |
| 移动开发 | Kotlin (Android) / C# (Unity) |
