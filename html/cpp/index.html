C++ 教程

从基础语法到高级特性，深入理解 C++ 的核心机制。涵盖面向对象、模板元编程、STL、智能指针、移动语义、并发编程等关键主题。

1. C++ 简介

C++ 是由 Bjarne Stroustrup 于 1979 年在贝尔实验室开发的通用编程语言。它在 C 语言的基础上增加了面向对象编程、泛型编程和异常处理等特性，同时保持了 C 语言的高性能和底层控制能力。

C++ 的设计哲学是"零开销抽象"（Zero-overhead Abstraction）：你不需要为你不使用的特性付出代价，你也不能通过其他方式实现得比语言内置机制更好。

设计哲学

直接映射硬件：C++ 的抽象可以直接编译为高效的机器码，没有垃圾回收器、没有虚拟机层。

多范式支持：过程式、面向对象、泛型、函数式编程范式均可在同一项目中混合使用。

向后兼容 C：C++ 可以直接调用 C 代码，绝大多数 C 代码无需修改即可在 C++ 编译器下编译。

C++ 的主要应用领域包括：

  • 系统软件：操作系统、编译器、数据库引擎（如 MySQL、PostgreSQL）
  • 游戏引擎：Unreal Engine、CryEngine 等主流引擎均使用 C++
  • 高性能计算：金融交易系统、科学计算、物理模拟
  • 嵌入式系统：对性能和资源有严格限制的设备
  • 浏览器引擎：Chrome (V8)、Firefox (SpiderMonkey)
C++
// C++ Hello World —— 一切的起点
#include <iostream>

int main() {
    std::cout << "Hello, C++ World!" << std::endl;
    return 0;
}
C++ 标准版本演进：C++98 → C++03 → C++11 → C++14 → C++17 → C++20 → C++23。现代 C++（C++11 及以后）引入了大量现代特性，是当前推荐的开发标准。

2. C 与 C++ 的区别

C++ 是 C 的超集，但在设计哲学和编程范式上存在根本性差异：

特性CC++
编程范式过程式多范式（OOP + 泛型 + 函数式）
内存管理malloc / freenew / delete + 智能指针
类型系统弱类型，隐式转换多强类型，支持模板、concept
错误处理返回值 / errno异常 try-catch
代码复用函数 + 宏类 + 模板 + 继承 + 多态
命名空间不支持namespace
函数重载不支持支持
引用类型不支持支持（&）
默认参数不支持支持
标准库libc（I/O、字符串、数学）STL（容器、迭代器、算法、智能指针等）
为什么选 C++ 而不是 C？

C++ 提供了更高的抽象层级，同时通过零开销抽象保证性能。类和继承让代码组织更清晰；模板提供类型安全的代码复用；RAII 和智能指针大幅减少了内存管理错误。

然而，C 在某些场景（如内核开发、极简嵌入式）仍然不可替代。选择取决于项目需求和团队能力。

C vs C++
// C 风格：手动管理内存，无类型安全
#include <stdlib.h>
#include <string.h>

struct Person {
    char* name;
    int age;
};

struct Person* create_person(const char* name, int age) {
    struct Person* p = (struct Person*)malloc(sizeof(struct Person));
    p->name = (char*)malloc(strlen(name) + 1);
    strcpy(p->name, name);
    p->age = age;
    return p;
}

void destroy_person(struct Person* p) {
    free(p->name);  // 容易忘记！
    free(p);
}

// C++ 风格：RAII + 类封装，自动管理
#include <string>
#include <iostream>

class Person {
private:
    std::string name_;
    int age_;
public:
    Person(const std::string& name, int age)
        : name_(name), age_(age) {}

    const std::string& name() const { return name_; }
    int age() const { return age_; }
};  // 析构时自动释放内存，无需手动 free

5. 引用与指针

指针

指针是 C/C++ 中最强大也最危险的特性。它存储的是内存地址，可以实现动态内存分配、数据结构和底层系统编程。

C++
int value = 42;
int* ptr = &value;      // 取地址
int& deref = *ptr;       // 解引用

// 指针运算
int arr[] = {10, 20, 30};
int* p = arr;            // 指向首元素
*(p + 1);                // == arr[1] == 20

// 指针与 const
const int* p1 = &value;  // 指向常量的指针（不能通过 p1 修改值）
int* const p2 = &value;  // 常量指针（不能改变指向）
const int* const p3 = &value; // 两者都不能改

// void 指针 —— 可以指向任何类型
void* vptr = &value;
int* ip = static_cast<int*>(vptr);  // 需要显式转换

引用

引用是 C++ 对指针的安全封装。它是一个对象的别名，必须在声明时初始化，且一旦绑定就不可更改。

引用 vs 指针

引用：必须初始化，不可重新绑定，不可为 null，语法更简洁（无需 * 和 &）。

指针：可以不初始化（不推荐），可以重新指向，可以为 null，可以进行指针运算。

选择原则：如果不需要"可选"语义或重新绑定，优先使用引用。

C++
// 左值引用
int x = 10;
int& ref = x;           // 绑定到左值
ref = 20;                // 修改 x 的值

// const 引用 —— 可以绑定到右值
const int& cref = 42;   // OK：常量引用延长临时对象生命周期

// 右值引用（C++11）—— 见第23节
int&& rref = 42;       // 绑定到右值

// 引用作为函数参数 —— 避免拷贝
void swap(int& a, int& b) {
    int temp = a;
    a = b;
    b = temp;
}

// 引用作为返回值 —— 允许链式赋值
int& at(std::vector<int>& vec, int idx) {
    return vec[idx];
}
at(vec, 0) = 100;  // 可以直接赋值

6. 运算符重载

运算符重载允许你为自定义类型定义运算符行为，使对象的操作更加直观。C++ 中几乎所有运算符都可以重载（除了 ::、.、.*、?:、sizeof）。

C++
class Vec2 {
public:
    float x, y;

    Vec2(float x = 0, float y = 0) : x(x), y(y) {}

    // 成员函数重载
    Vec2 operator+(const Vec2& other) const {
        return {x + other.x, y + other.y};
    }

    Vec2& operator+=(const Vec2& other) {
        x += other.x;
        y += other.y;
        return *this;
    }

    // 标量乘法（成员函数）
    Vec2 operator*(float scalar) const {
        return {x * scalar, y * scalar};
    }

    // 比较运算符（C++20 三路比较）
    auto operator<=>(const Vec2& other) const = default;

    // 输出运算符（友元函数）
    friend std::ostream& operator<<(std::ostream& os, const Vec2& v) {
        return os << "(" << v.x << ", " << v.y << ")";
    }
};

// 非成员函数重载（标量在左）
Vec2 operator*(float scalar, const Vec2& v) {
    return v * scalar;
}

// 使用
Vec2 a(1, 2), b(3, 4);
std::cout << a + b << std::endl;      // (4, 6)
std::cout << 2.0f * a << std::endl;   // (2, 4)
运算符重载应当遵循直觉：加法运算符实现加法语义，比较运算符实现比较语义。不要为了语法糖而滥用运算符重载，这会降低代码可读性。

7. 字符串

std::string

标准库的 std::string 是处理文本的首选工具，它封装了动态内存管理，提供了丰富的操作接口。

C++
#include <string>
#include <string_view>  // C++17
#include <iostream>

void string_demo() {
    // 创建
    std::string s1 = "Hello";
    std::string s2(5, 'A');              // "AAAAA"
    std::string s3(s1, 1, 3);            // "ell"
    std::string s4 = s1 + ", World!";   // 拼接

    // 访问
    char first = s1[0];               // 'H'（无边界检查）
    char safe = s1.at(0);             // 'H'（有边界检查，越界抛异常）
    const char* cstr = s1.c_str();    // C 风格字符串

    // 查找
    size_t pos = s1.find("ell");     // 位置 1
    if (pos != std::string::npos) { ... }

    // 修改
    s1.append(" there");
    s1.insert(0, "Oh, ");
    s1.erase(0, 4);
    s1.replace(0, 5, "Hi");

    // C++17 string_view —— 非拥有视图，零拷贝
    std::string_view sv = s1;         // 不拷贝内容
    std::cout << sv.substr(0, 2) << std::endl;

    // C++20 格式化
    auto formatted = std::format("Name: {}, Age: {}", "Alice", 30);
}
string_view 的优势

零拷贝：string_view 只是一个指针加长度，不会分配内存或复制字符串内容。

性能：在只读场景中用 string_view 替代 const string& 参数，可以避免从 C 字符串或子串构造临时 string 对象。

注意：string_view 不拥有数据，确保原始字符串在 string_view 使用期间保持有效。

8. 类与对象

类是 C++ 面向对象编程的核心。它将数据和操作数据的函数封装在一起，通过访问控制隐藏实现细节。

C++
class BankAccount {
private:                          // 私有：外部不可访问
    std::string owner_;
    double balance_;
    int pin_;

protected:                        // 受保护：子类可访问
    double interest_rate_;

public:                           // 公有：外部可访问
    // 构造函数
    BankAccount(const std::string& owner, double balance, int pin)
        : owner_(owner), balance_(balance), pin_(pin),
          interest_rate_(0.02) {}

    // 成员函数
    bool withdraw(double amount, int pin) {
        if (pin != pin_) return false;
        if (amount > balance_) return false;
        balance_ -= amount;
        return true;
    }

    void deposit(double amount) {
        balance_ += amount;
    }

    // const 成员函数 —— 不修改对象状态
    double balance() const { return balance_; }
    const std::string& owner() const { return owner_; }

    // 静态成员 —— 属于类而非对象
    static int instance_count() { return instance_count_; }

private:
    static int instance_count_;
};

int BankAccount::instance_count_ = 0;

访问控制与封装

封装的意义

数据隐藏：私有成员只能通过公有接口访问，外部代码无法直接修改对象内部状态。

不变量维护：类可以在成员函数中检查前置条件，确保对象始终处于合法状态。

实现自由：公有接口不变的情况下，可以自由修改私有实现，不影响外部代码。

9. 构造与析构

构造函数

C++
class Resource {
    int* data_;
    size_t size_;
    std::string name_;

public:
    // 1. 默认构造函数
    Resource() : data_(nullptr), size_(0) {}

    // 2. 参数化构造函数
    Resource(const std::string& name, size_t size)
        : name_(name), size_(size),
          data_(new int[size]{}) {}

    // 3. 拷贝构造函数
    Resource(const Resource& other)
        : name_(other.name_ + "_copy"),
          size_(other.size_),
          data_(new int[other.size_]) {
        std::copy(other.data_, other.data_ + size_, data_);
    }

    // 4. 移动构造函数（C++11）
    Resource(Resource&& other) noexcept
        : data_(other.data_),
          size_(other.size_),
          name_(std::move(other.name_)) {
        other.data_ = nullptr;    // 源对象置空
        other.size_ = 0;
    }

    // 5. 委托构造函数（C++11）
    Resource(size_t size) : Resource("default", size) {}

    // 6. initializer_list 构造函数
    Resource(std::initializer_list<int> init)
        : size_(init.size()),
          data_(new int[init.size()]) {
        std::copy(init.begin(), init.end(), data_);
    }

    // 析构函数
    ~Resource() {
        delete[] data_;
    }
};

特殊成员函数（Rule of Five）

Rule of Five / Rule of Zero

Rule of Five：如果你需要自定义以下任意一个，就应该同时定义全部五个：

1. 析构函数   2. 拷贝构造函数   3. 拷贝赋值运算符   4. 移动构造函数   5. 移动赋值运算符

Rule of Zero（推荐）：尽可能让编译器自动生成所有五个。使用 RAII 包装类型（如 std::unique_ptr、std::vector）管理资源，就不需要自定义任何特殊成员函数。

C++
// Rule of Zero 的最佳实践
class Person {
    std::string name_;            // std::string 管理自己的内存
    std::vector<int> scores_;    // std::vector 管理自己的内存
    std::unique_ptr<Job> job_;   // unique_ptr 管理堆内存

public:
    // 无需自定义任何特殊成员函数！
    // 编译器生成的默认版本完全正确
    Person() = default;
    Person(std::string name) : name_(std::move(name)) {}
};

10. 继承

继承允许新类（派生类）复用已有类（基类）的代码。C++ 支持单继承、多继承、虚拟继承等。

C++
// 基类
class Shape {
protected:
    double x_, y_;
public:
    Shape(double x, double y) : x_(x), y_(y) {}
    virtual ~Shape() = default;   // 虚析构函数！

    virtual double area() const = 0;  // 纯虚函数 → 抽象类
    virtual double perimeter() const = 0;

    void print() const {
        std::cout << "Area: " << area() << std::endl;
    }
};

// 派生类
class Circle : public Shape {
    double radius_;
public:
    Circle(double x, double y, double r)
        : Shape(x, y), radius_(r) {}

    double area() const override {   // override 关键字（C++11）
        return 3.14159265 * radius_ * radius_;
    }

    double perimeter() const override {
        return 2 * 3.14159265 * radius_;
    }
};

class Rectangle : public Shape {
    double w_, h_;
public:
    Rectangle(double x, double y, double w, double h)
        : Shape(x, y), w_(w), h_(h) {}

    double area() const override { return w_ * h_; }
    double perimeter() const override { return 2 * (w_ + h_); }
};

继承方式

方式public 成员protected 成员private 成员
public 继承publicprotected不可访问
protected 继承protectedprotected不可访问
private 继承privateprivate不可访问
多继承可能导致菱形继承问题（Diamond Problem）。使用虚继承（class Derived : public virtual Base）确保公共基类只有一份实例。C++17 引入的结构化绑定和 C++20 的 concept 也在一定程度上减少了多继承的需求。

11. 多态

多态是面向对象编程的核心能力：同一接口，不同行为。C++ 通过虚函数实现运行时多态（动态绑定）。

C++
// 运行时多态 —— 通过基类指针/引用调用派生类方法
void print_area(const Shape& shape) {
    shape.print();  // 根据实际类型调用对应的 area()
}

Circle c(0, 0, 5.0);
Rectangle r(0, 0, 4, 6);

print_area(c);  // Area: 78.54
print_area(r);  // Area: 24

// 编译时多态 —— 模板（见第13节）
template<typename T>
void print_val(const T& val) {
    std::cout << val << std::endl;
}
静态多态 vs 动态多态

静态多态（编译时）：通过模板和重载实现。编译器在编译期确定调用哪个函数，性能无开销。

动态多态（运行时）：通过虚函数实现。运行时通过 vtable 查找正确的函数调用，有间接调用开销。

选择原则：如果类型在编译期已知，用模板（更快）。如果需要在运行时处理不同类型（如基类指针容器），用虚函数。

12. 虚函数

虚函数表（vtable）机制详解

虚函数的实现依赖于虚函数表（vtable）。每个包含虚函数的类都有一个 vtable，其中存储了该类所有虚函数的地址。

vtable 内部结构

对象内存布局：包含虚函数的类对象，其内存布局的第一个成员是一个指向 vtable 的指针（vptr）。

vtable 结构：一个函数指针数组，按声明顺序存放该类的虚函数地址。如果派生类覆盖了某个虚函数，则对应位置存放派生类的函数地址。

虚析构函数：如果没有虚析构函数，通过基类指针删除派生类对象会导致派生类部分不被析构（未定义行为）。

调用过程：1. 通过 vptr 找到 vtable → 2. 在 vtable 中按偏移量找到函数指针 → 3. 调用目标函数。

C++
// 虚析构函数 —— 防止内存泄漏
class Base {
public:
    virtual ~Base() {
        std::cout << "~Base" << std::endl;
    }

    virtual void hello() {
        std::cout << "Base::hello" << std::endl;
    }
};

class Derived : public Base {
    int* data_;
public:
    Derived() : data_(new int[100]) {}
    ~Derived() override {
        delete[] data_;
        std::cout << "~Derived" << std::endl;
    }

    void hello() override {
        std::cout << "Derived::hello" << std::endl;
    }
};

// ✅ 正确：虚析构确保 Derived 被正确析构
Base* p = new Derived();
delete p;   // 输出 ~Derived → ~Base

// ❌ 错误：如果 ~Base() 不是 virtual，~Derived() 永远不会被调用

    void push(T value) {
        std::lock_guard<std::mutex> lock(mutex_);
        data_.push(std::move(value));

        std::lock_guard<std::mutex> lock(mutex_);
        if (data_.empty()) return std::nullopt;
        T val = std::move(data_.top());
        data_.pop();
        return val;
    }

    size_t size() const {
        std::lock_guard<std::mutex> lock(mutex_);
        return data_.size();
    }
};

17. 迭代器

迭代器是连接容器和算法的桥梁。它提供了一种统一的方式来遍历容器中的元素，而不需要暴露容器的内部实现。

迭代器类别

输入迭代器：只能向前读取（如 istream_iterator）。

输出迭代器：只能向前写入（如 ostream_iterator）。

前向迭代器：可以多次读写，只能向前移动（如 forward_list、unordered_map）。

双向迭代器：可以向前和向后移动（如 list、set、map）。

随机访问迭代器：支持任意位置跳转（如 vector、deque、array）。

C++
// 迭代器基本用法

// 正向遍历

    std::cout << *it << " ";
}

// 反向遍历
for (auto it = vec.rbegin(); it != vec.rend(); ++it) {
    std::cout << *it << " ";
}

// const 迭代器 —— 只读访问

    // *it = 100;  // ❌ 编译错误
}

// 迭代器失效注意事项

// ++it;  // ❌ 未定义行为！erase 使 it 失效

20. 智能指针

智能指针是 C++11 引入的 RAII 包装器，自动管理堆内存的生命周期，从根本上消除了内存泄漏。

智能指针内部原理

unique_ptr：独占所有权。内部只存储一个裸指针，没有额外开销。通过移动语义转移所有权，不可拷贝。析构时自动 delete。

shared_ptr：共享所有权。内部维护一个控制块（control block），包含引用计数和删除器。拷贝时引用计数 +1，析构时 -1，归零时 delete。控制块在首次创建时分配。

weak_ptr：不拥有对象，不增加引用计数。用于打破循环引用。通过 lock() 获取 shared_ptr，如果对象已销毁则返回空。

C++
#include <memory>

// unique_ptr —— 独占所有权（首选）
{
    auto p = std::make_unique<int>(42);
    auto arr = std::make_unique<int[]>(10);

    // 移动所有权
    auto p2 = std::move(p);   // p 现在是 nullptr
    auto raw = p2.get();       // 获取裸指针（不转移所有权）
    auto released = p2.release(); // 释放所有权，返回裸指针

    p2.reset();                // 手动释放
}

// shared_ptr —— 共享所有权
{
    auto sp1 = std::make_shared<std::string>("Hello");
    std::cout << sp1.use_count() << std::endl;  // 1

    {
        auto sp2 = sp1;       // 引用计数 +1
        std::cout << sp1.use_count() << std::endl;  // 2
    }  // sp2 析构，引用计数 -1

    std::cout << sp1.use_count() << std::endl;  // 1
}

// weak_ptr —— 打破循环引用
struct Node {
    std::string name;

    std::weak_ptr<Node> prev;    // 弱引用（不增加计数）

21. RAII

RAII（Resource Acquisition Is Initialization）是 C++ 最重要的编程范式：资源的生命周期与对象的生命周期绑定。

RAII 核心原理

资源获取即初始化：在构造函数中获取资源（分配内存、打开文件、加锁），在析构函数中释放资源。

自动保证：栈对象在离开作用域时自动析构，无论函数是正常返回还是异常抛出。

异常安全：RAII 保证了"基本异常安全"——即使抛出异常，资源也会被正确释放。

C++
// RAII 文件管理
class FileGuard {
    FILE* file_;
public:
    FileGuard(const char* path, const char* mode)
        : file_(std::fopen(path, mode)) {
        if (!file_) throw std::"Failed to open file");
    }

    ~FileGuard() {
        if (file_) std::fclose(file_);
    }

    // 禁止拷贝
    FileGuard(const FileGuard&) = delete;
    FileGuard& operator=(const FileGuard&) = delete;

    FILE* get() { return file_; }
};

// 使用 RAII —— 无需手动关闭文件
void write_data() {
    FileGuard f("data.txt", "w");
    std::fprintf(f.get(), "Hello, RAII!\n");
}  // f 析构 → 文件自动关闭（即使中途抛异常）

// 标准库的 RAII 工具
std::lock_guard<std::mutex> lock(mtx);     // 互斥锁
std::unique_lock<std::mutex> ulock(mtx);  // 可移动的锁
std::scoped_lock<std::mutex, std::mutex> sl(m1, m2);  // 多锁（C++17）
C++ 
// RAII 锁守卫模式 —— 互斥锁自动管理
class ThreadSafeCounter {
    int count_ = 0;
    mutable std::mutex mtx_;

public:
    int increment() {
        std::lock_guard<std::mutex> guard(mtx_);  // 构造时加锁
        return ++count_;
    }  // 析构时自动解锁，即使抛异常

        std::lock_guard<std::mutex> guard(mtx_);
        return count_;
    }

// Scope Guard —— 确保清理操作一定执行

class ScopeGuard {

    bool active_ = true;
public:

22. 移动语义

移动语义是 C++11 最重要的特性之一。它允许"偷取"临时对象的资源，而不是复制它们，从而大幅提升性能。

移动语义核心原理

左值 vs 右值：左值有名字、有地址（可以取地址）。右值是临时对象、字面量、或表达式的结果（没有名字）。

移动构造：将源对象的内部指针直接"偷"到目标对象，然后将源对象置为空状态。避免了深拷贝。

std::move：不做任何移动！它只是将左值强制转换为右值引用，告诉编译器"这个对象可以被移动"。

性能提升：对于持有堆内存的容器（如 vector），移动的代价是指针赋值（O(1)），而拷贝是 O(n) 的内存复制。

C++
// 移动语义实例
class Buffer {
    int* data_;
    size_t size_;
public:
    Buffer(size_t n) : data_(new int[n]{}, size_(n) {}

    // 拷贝构造 —— 深拷贝（昂贵）
    Buffer(const Buffer& other)
        : data_(new int[other.size_]),
          size_(other.size_) {
        std::copy(other.data_, other.data_ + size_, data_);
        std::cout << "Copy!" << std::endl;
    }

    // 移动构造 —— 偷指针（廉价）
    Buffer(Buffer&& other) noexcept
        : data_(other.data_),
          size_(other.size_) {
        other.data_ = nullptr;
        other.size_ = 0;
        std::cout << "Move!" << std::endl;
    }

    ~Buffer() { delete[] data_; }
};

// 使用
Buffer create_buffer(size_t n) {
    Buffer b(n);
    return b;  // 编译器应用 NRVO 或移动语义
}

Buffer b1 = create_buffer(1024);  // 可能是 NRVO（零拷贝）
Buffer b2 = std::move(b1);         // 移动构造
// b1 现处于有效但未指定的状态，不应使用其值

// 移动赋值运算符
Buffer& operator=(Buffer&& other) noexcept {
    if (this != &other) {
        delete[] data_;
        data_ = other.data_;
        size_ = other.size_;
        other.data_ = nullptr;
        other.size_ = 0;
    }
    return *this;
}
C++ 
// 移动构造函数 —— 高效窃取资源
class DynamicArray {
    int* data_;
    size_t size_, capacity_;

public:
    // 移动构造：O(1) 指针交换
    DynamicArray(DynamicArray&& other) noexcept
        : data_(other.data_),
          size_(other.size_),
          capacity_(other.capacity_) {
        other.data_ = nullptr;
        other.size_ = other.capacity_ = 0;
    }

    // 移动赋值：自我保护 + 窃取
    DynamicArray& operator=(DynamicArray&& other) noexcept {
        if (this != &other) {
            delete[] data_;
            data_ = std::exchange(other.data_, nullptr);
            size_ = std::exchange(other.size_, 0);
            capacity_ = std::exchange(other.capacity_, 0);
        }
        return *this;
    }
};

23. 右值引用

C++
// 右值引用 —— 绑定到临时对象
int&& rref = 42;              // 右值引用绑定到字面量

// 完美转发 —— 保持参数的值类别
template<typename T>
void wrapper(T&& arg) {     // T&& 是万能引用（转发引用）
    // std::forward 保持 arg 的原始值类别
    target(std::forward<T>(arg));
}

// 万能引用的规则
template<typename T>
void f1(T&& x);   // 万能引用（推导 T）

void f2(int&& x);  // 右值引用（不推导，固定 int&&）

// 使用场景
template<typename T>
void push_to_vec(std::vector<T>& vec, T&& value) {
    vec.emplace_back(std::forward<T>(value));  // 完美转发
}

std::vector<std::string> v;
std::string s = "hello";
push_to_vec(v, s);               // s 是左值 → T=string& → 拷贝
push_to_vec(v, "world");         // 临时值 → T=string&& → 移动
push_to_vec(v, std::move(s));     // move 产生右值 → T=string&& → 移动
值类别总结

左值（lvalue）：有名字、有地址、生命周期可预测。可以出现在赋值表达式的左边。

右值（rvalue）：临时对象、字面量、表达式结果。生命周期仅限当前表达式。

xvalue（将亡值）：std::move() 的结果。语法上是右值，但代表"即将被移动的对象"。

万能引用（universal reference）：模板参数推导时 T&& 既可以绑定左值也可以绑定右值。

// 线程池（简化概念）
class ThreadPool {
    std::vector<std::thread> workers_;
    std::queue<std::function<void()>> tasks_;
    std::mutex queue_mutex_;
    std::condition_variable condition_;
    bool stop_ = false;

public:
    ThreadPool(size_t n) {
        for (size_t i = 0; i < n; ++i) {
            workers_.emplace_back([this] {
                while (true) {
                    std::function<void()> task;
                    {
                        std::unique_lock<std::mutex> lock(queue_mutex_);
                        condition_.wait(lock, [this] {
                            return stop_ || !tasks_.empty();
                        });
                        if (stop_ && tasks_.empty()) return;
                        task = std::move(tasks_.front());
                        tasks_.pop();
                    }
                    task();
                }
            });
        }
    }

    ~ThreadPool() {
        { std::lock_guard<std::mutex> lock(queue_mutex_); stop_ = true; }
        condition_.notify_all();
        for (auto& w : workers_) w.join();
    }

    template<typename F>
    auto enqueue(F&& f) -> std::future<decltype(f())> {
        auto task = std::make_shared<std::decltype(f())()>>(
            std::forward<F>(f));
        std::future<decltype(f())> res = task->get_future();
        { std::lock_guard<std::mutex> lock(queue_mutex_);
          tasks_.emplace([task]() { (*task)(); }); }
        condition_.notify_one();
        return res;
    }
};
数据竞争是并发编程中最常见的 bug。使用 std::mutex 保护共享可变数据，或使用 std::atomic 替代简单的计数器。std::lock_guard 和 std::scoped_lock 是管理锁的最佳实践（RAII）。

26. 内存模型

C++ 内存模型定义了多线程环境下内存访问的规则，是并发正确性的基础。

C++ 内存模型详解

内存序（Memory Order）：C++ 提供六种内存序，从最强到最弱：

memory_order_seq_cst（默认）→ memory_order_acquire / release → memory_order_consume → memory_order_relaxed

seq_cst：全局一致性顺序，最强保证但可能最慢。

acquire/release：确保"先发生"关系。release 之前的写入对 acquire 之后的读取可见。

relaxed：只保证原子性，不保证顺序。用于无依赖的计数器。

C++
// 内存模型示例
#include <atomic>
#include <thread>
#include <cassert>

std::atomic<bool> ready{false};
int data = 0;

void producer() {
    data = 42;                    // 1. 普通写入
    ready.store(true,
        std::memory_order_release);  // 2. release 语义：确保 1 在 2 之前完成
}

void consumer() {
    while (!ready.load(
        std::memory_order_acquire))  // 3. acquire 语义
        ;  // 自旋等待

    // 4. 保证能看到 data == 42
    assert(data == 42);  // 永远不会失败
}

// release-acquire 对建立"happens-before"关系：
// producer 中 release 之前的所有写入
// 对 consumer 中 acquire 之后的所有读取可见

// memory_order_relaxed —— 最弱保证
std::atomic<int> counter(0);
void increment() {
    // 只保证原子性，不保证其他线程看到的顺序
    counter.fetch_add(1, std::memory_order_relaxed);
}

虚函数的性能影响

虚函数 vs 模板（性能对比）

虚函数开销：每次调用需要两次间接跳转（vptr → vtable → 函数），同时阻止内联优化。对性能关键路径有显著影响。

模板优势：编译期确定类型，可以直接内联，零运行时开销。

缓存友好性：虚函数调用可能跳转到不同的内存位置，导致指令缓存未命中。模板实例化的代码更紧凑。

建议：性能敏感的场景优先考虑 CRTP 或模板方案；需要运行时多态时再使用虚函数。
