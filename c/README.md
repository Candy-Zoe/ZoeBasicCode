# C 语言基础语法学习

## 编译运行方式

### Windows (MinGW / GCC)
```bash
gcc 文件名.c -o 输出文件名
输出文件名.exe
```

### Linux / macOS
```bash
gcc 文件名.c -o 输出文件名
./输出文件名
```

## 目录结构

### 01_基础语法
- `01_变量和数据类型.c` - 变量、数据类型、格式化输出
- `02_运算符.c` - 算术、关系、逻辑、位运算符

### 02_流程控制
- `01_条件语句.c` - if/else、switch、三元表达式
- `02_循环语句.c` - for、while、do-while、break/continue

### 03_函数
- `01_函数基础.c` - 函数定义、声明、递归、指针参数

### 04_数据结构
- `01_数组和指针.c` - 数组、指针、字符串、动态内存

### 05_面向对象
- `01_结构体.c` - 结构体、枚举、联合

### 06_常用操作
- `01_文件操作.c` - 文件读写、错误处理

## 推荐学习顺序
1. 基础语法 → 2. 流程控制 → 3. 函数 → 4. 数据结构 → 5. 结构体 → 6. 文件操作
