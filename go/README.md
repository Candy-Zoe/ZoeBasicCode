# Go 基础语法学习

## 运行方式

```bash
go run 文件名.go
```

或者编译后运行：
```bash
go build 文件名.go
./文件名.exe
```

## 前置要求
- Go 1.16 或更高版本
- 配置好 GOPATH 环境变量

## 目录结构

### 01_基础语法
- `01_变量和数据类型.go` - 变量、类型、数组、切片、map、结构体

### 02_流程控制和函数
- `02_流程控制和函数.go` - 条件、循环、函数、闭包、defer

### 03_面向对象和常用操作
- `03_面向对象和常用操作.go` - 结构体、接口、文件、JSON、时间

## 推荐学习顺序
1. 基础语法 → 2. 流程控制和函数 → 3. 面向对象和常用操作

## Go 语言特色
- 简洁的语法，只有25个关键字
- 内置 goroutine 并发支持
- 没有 class，用 struct + method 实现面向对象
- 接口是鸭子类型，隐式实现
- 错误处理用多返回值，没有 try-catch
- defer 延迟执行，recover 捕获 panic
