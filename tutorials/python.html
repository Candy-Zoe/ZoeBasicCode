Python 基础语法教程

Python 简介

Python 是一种广泛使用的高级编程语言，它的语法简洁得就像读英语句子一样，因此被很多人称为"编程世界的普通话"。无论你是想做网站、开发游戏、处理数据，还是写个小工具自动化办公，Python 都能帮你轻松搞定！

💡 Python 能做什么？
  • 网站开发：Instagram、YouTube 后台都在用 Django/Flask
  • 数据分析：处理 Excel、做图表、数据分析报告
  • 人工智能：机器学习、深度学习、图像识别
  • 自动化办公：自动处理文件、发送邮件、定时任务
  • 爬虫抓数据：自动获取网页信息，做市场调研
  • 游戏开发：很多独立游戏用 Python 写原型
🌟 为什么编程小白首选 Python？

想象一下，如果你要用积木搭房子：

  • 其他语言：需要记住各种积木的尺寸、材质、拼接方式...
  • Python：只需要说"我要红色积木"，它就自动给你准备好了！

Python 就是这么简单直接，让你专注于解决问题，而不是纠结于语法细节。

第一个程序

传统上，编程的第一步就是让电脑显示"Hello, World!"（你好，世界）。让我们来试试：

Python 
print("Hello, World!")
Hello, World!
⚠️ 运行方法

保存为 hello.py，然后在终端运行：

python hello.py

为什么叫 print？

print 的意思是"打印"，但在这里不是打印机，而是把内容显示到屏幕上。就像你说的话被"打印"出来让别人看到一样。

变量和数据类型

变量就像是一个有名字的盒子，我们把数据放进去，给盒子贴上标签（变量名），这样下次就能快速找到它了！

Python 是动态类型语言，意思是：

  • 不需要提前告诉电脑"我要放整数"还是"要放字符串"
  • 直接赋值就行，Python 会自动"猜"出这是什么类型
💡 什么是数据类型？

就像现实生活中的物品有不同的分类：

  • 整数：1、2、3、100（就像苹果的数量）
  • 小数：3.14、1.75（就像身高、体重）
  • 字符串："Hello"、"你好"（就像一串文字）
  • 布尔值：True/False（就像开关的开和关）

基本变量

Python 
# 字符串类型 - 用引号包围的文字
name = "张三"
# 整数类型 - 没有小数点的数字
age = 25
# 浮点数类型 - 带小数点的数字
height = 1.75
# 布尔类型 - 真或假
is_student = True

# f-string: 在字符串中嵌入变量，非常方便！
print(f"姓名: {name}")
print(f"年龄: {age}")
print(f"身高: {height}")
print(f"是否学生: {is_student}")
姓名: 张三
年龄: 25
身高: 1.75
是否学生: True
⚠️ 注意

变量名不能以数字开头，也不能包含空格或特殊符号（除了下划线 _）。

查看变量类型

如果不确定一个变量是什么类型，可以用 type() 函数来"检查"它：

Python 
name = "张三"
age = 25

print(type(name))  # 查看字符串的类型
print(type(age))   # 查看整数的类型
<class 'str'>（str 就是 string，字符串）
<class 'int'>（int 就是 integer，整数）

类型转换

有时候我们需要把一种类型变成另一种类型，就像把"字符串数字"变成"真正的数字"：

Python 
# 场景：用户输入的都是字符串，但我们需要当数字用

# 字符串转整数
num_str = "123"
num_int = int(num_str)  # int() 把字符串变成整数

# 整数转字符串
age = 25
age_str = str(age)  # str() 把整数变成字符串

# 字符串转浮点数
pi_str = "3.14"
pi = float(pi_str)  # float() 把字符串变成小数

print(f"整数: {num_int}, 类型: {type(num_int)}")
print(f"字符串: {age_str}, 类型: {type(age_str)}")
✅ 记忆小技巧
  • int → int() → 整数（integer）
  • str → str() → 字符串（string）
  • float → float() → 浮点数（小数，float）
✅ 提示 Python 中字符串可以用单引号 ' 或双引号 " 包围，效果一样。

运算符

运算符就是用来做数学运算和逻辑判断的符号，就像我们平时用的 +（加）、-（减）、=（等于）一样。

算术运算符

算术运算符就是数学里常见的加减乘除，但有几个需要注意的点：

Python 
a, b = 10, 3
print(f"加法: {a} + {b} = {a + b}")  # 10 + 3 = 13
print(f"减法: {a} - {b} = {a - b}")  # 10 - 3 = 7
print(f"乘法: {a} * {b} = {a * b}")  # 10 × 3 = 30
print(f"除法: {a} / {b} = {a / b}")  # 10 ÷ 3 = 3.33...（注意！除法结果是小数）
print(f"整除: {a} // {b} = {a // b}")  # 10 ÷ 3 = 3（取整数部分）
print(f"取余: {a} % {b} = {a % b}")  # 10 ÷ 3 = 3...1（取余数）
print(f"幂运算: {a} ** {b} = {a ** b}")  # 10³ = 1000（10的3次方）
加法: 10 + 3 = 13
减法: 10 - 3 = 7
乘法: 10 × 3 = 30
除法: 10 ÷ 3 = 3.333...（注意！除法结果是小数）
整除: 10 ÷ 3 = 3（取整数部分）
取余: 10 ÷ 3 = 1（取余数）
幂运算: 10³ = 1000（10的3次方）
💡 什么时候用 // 和 %？

想象一下分糖果的场景：

  • 10 颗糖分给 3 个人，// 告诉每个人能分到几颗整糖
  • 10 颗糖分给 3 个人，% 告诉还剩几颗糖

比较运算符

比较运算符用来比较两个值的大小，结果只有 True（真）或 False（假）：

Python 
m, n = 10, 20
print(f"{m} == {n}: {m == n}")  # False（等于）
print(f"{m} != {n}: {m != n}")  # True（不等于）
print(f"{m} > {n}: {m > n}")    # False（大于）
print(f"{m} < {n}: {m < n}")    # True（小于）
print(f"{m} >= {n}: {m >= n}")  # False（大于等于）
print(f"{m} <= {n}: {m <= n}")  # True（小于等于）
⚠️ 特别注意

== 是"等于"（比较），= 是"赋值"（存入）。别搞混了！

逻辑运算符

逻辑运算符用来组合多个条件，就像说"并且"、"或者"、"不是"：

Python 
p, q = True, False
print(f"p and q: {p and q}")  # False（并且：两个都要真）
print(f"p or q: {p or q}")    # True（或者：至少一个为真）
print(f"not p: {not p}")      # False（不是：取反）
💡 逻辑运算记忆口诀
  • and：and 就是"和"，要两个都对才返回 True（就像同时满足两个条件）
  • or：or 就是"或"，至少一个对就返回 True（就像满足任一条件）
  • not：not 就是"非"，取反（对的变错，错的变对）

条件语句

条件语句就像我们日常生活中的决策：如果...就...，否则如果...就...，否则就...

Python 使用 if（如果）、elif（否则如果）、else（否则）来进行条件判断。

基本 if 语句

最简单的场景：如果条件满足，就做一件事，否则做另一件事。

Python 
age = 18
if age >= 18:
    print("你已经成年了")
else:
    print("你还未成年")
你已经成年了
💡 语法小提示

注意代码前的缩进（4个空格或1个Tab）！Python 用缩进来区分代码块，不像其他语言用大括号 {}。

多条件判断

生活中经常有多个条件，比如考试成绩判断：

Python 
score = 85
if score >= 90:
    grade = "A"  # 90分以上是A
elif score >= 80:
    grade = "B"  # 80-89分是B
elif score >= 60:
    grade = "C"  # 60-79分是C
else:
    grade = "D"  # 60分以下是D

print(f"成绩 {score} 分，等级: {grade}")
成绩 85 分，等级: B
💡 多个条件的判断顺序

计算机会从上到下检查条件，一旦找到满足的条件就执行对应的代码，后面的条件就不会再检查了。

所以要把更具体的条件放前面，更宽泛的条件放后面。

三元表达式

如果只想根据条件返回一个值，可以用更简洁的方式：

Python 
a, b = 10, 20
# 格式：值1 if 条件 else 值2
max_val = a if a > b else b
print(f"{a} 和 {b} 中较大的是: {max_val}")
10 和 20 中较大的是: 20

循环语句

循环就是让计算机重复做某件事。想象一下要打印 100 次"你好"，不用循环就要写 100 遍，有了循环就只需要 1 行代码！

for 循环

for 循环就像按顺序遍历一个清单：

Python 
# 遍历列表（一个一个地处理）
fruits = ["苹果", "香蕉", "橙子"]
for fruit in fruits:  # 每次循环，fruit 都会变成下一个水果
    print(f"水果: {fruit}")

# 使用 range() 产生数字序列
print("\n使用 range:")
for i in range(5):  # 产生 0, 1, 2, 3, 4
    print(f"第 {i} 次循环")
水果: 苹果
水果: 香蕉
水果: 橙子

使用 range:
第 0 次循环
第 1 次循环
...
💡 range() 小技巧
  • range(5) → 0, 1, 2, 3, 4（从0开始，不包含5）
  • range(1, 5) → 1, 2, 3, 4（从1开始，不包含5）
  • range(0, 10, 2) → 0, 2, 4, 6, 8（步长为2）

while 循环

while 循环就像满足条件就一直做：只要条件为真，就一直重复执行。

Python 
count = 1
while count <= 5:  # 只要 count <= 5，就一直循环
    print(f"count = {count}")
    count += 1  # 重要！每次循环后递增，否则会无限循环！
count = 1
count = 2
count = 3
count = 4
count = 5
⚠️ 警告：无限循环！

使用 while 循环时，一定要确保循环条件最终会变为 False，否则程序会一直运行下去，不会停止！

就像热水器，如果忘记关，就会一直烧水，直到...

break 和 continue

有时候我们需要提前退出循环或跳过某次循环：

Python 
# break: 提前退出循环（整个循环结束）
print("break 示例:")
for i in range(10):
    if i == 5:
        break  # 当 i=5 时，退出整个循环
    print(i, end=" ")
print("\n遇到 break，循环结束")

# continue: 跳过当前迭代（进入下一次循环）
print("\ncontinue 示例:")
for i in range(10):
    if i % 2 == 0:  # 如果是偶数
        continue  # 跳过这次循环，继续下一次
    print(i, end=" ")
print("\n只打印了奇数")
break 示例:
0 1 2 3 4
遇到 break，循环结束

continue 示例:
1 3 5 7 9
只打印了奇数
💡 break vs continue
  • break：提前下班，直接结束整个循环
  • continue：跳过这次，但继续下一次循环

函数

函数就是一段可以重复使用的代码。就像一个会做特定事情的机器，你给它原料（参数），它给你产出（返回值）。

💡 为什么需要函数？

想象一下：你要写 100 遍"你好，张三！"，还是写一个函数然后调用 100 次？

函数让代码不重复、更简洁、易维护。

定义函数

Python 
def greet():
    """简单的问候函数 - 文档字符串"""
    print("Hello, World!")

def greet_user(name):
    """向指定用户问候"""
    print(f"你好，{name}！")

def add(a, b):
    """返回两个数的和"""
    return a + b  # return 返回结果

# 调用函数
greet()
greet_user("张三")
result = add(3, 5)
print(f"3 + 5 = {result}")
Hello, World!
你好，张三！
3 + 5 = 8
💡 def 是什么意思？

def 是 define（定义）的缩写，告诉计算机"我要创建一个函数"。

默认参数

参数可以设置默认值，这样调用时就可以省略：

Python 
def power(base, exponent=2):
    """计算幂，默认是平方"""
    return base ** exponent

print(f"3的平方: {power(3)}")   # 使用默认值 exponent=2
print(f"3的立方: {power(3, 3)}")  # 手动指定 exponent=3
3的平方: 9
3的立方: 27

可变参数

有时候不确定会有多少个参数，用 *args 可以接收任意数量：

Python 
def sum_all(*args):
    """计算所有参数的和 - args 是元组类型"""
    total = 0
    for num in args:  # 遍历所有传入的参数
        total += num
    return total

print(f"sum_all(1, 2, 3) = {sum_all(1, 2, 3)}")
print(f"sum_all(1, 2, 3, 4, 5) = {sum_all(1, 2, 3, 4, 5)}")
sum_all(1, 2, 3) = 6
sum_all(1, 2, 3, 4, 5) = 15

Lambda 表达式

Lambda（λ）是匿名函数，适合写一些简单的一次性函数：

Python 
# 匿名函数 - 用来创建一个简单函数
square = lambda x: x ** 2
print(f"5的平方: {square(5)}")

# 结合 map() 使用 - 对列表中每个元素操作
nums = [1, 2, 3, 4, 5]
squared = list(map(lambda x: x ** 2, nums))  # map 对每个元素执行函数
print(f"平方后: {squared}")
5的平方: 25
平方后: [1, 4, 9, 16, 25]

数据结构

数据结构就是组织和存储数据的方式。就像不同的容器（盒子、抽屉、柜子）适合装不同的东西，Python 也有多种数据结构来应对不同场景。

列表 (List)

列表就像一个会变的序列，可以随时往里面添加、删除元素。就像购物清单，可以随时增减商品。

Python 
fruits = ["苹果", "香蕉", "橙子"]
print(f"列表: {fruits}")
print(f"第一个: {fruits[0]}")  # Python 从 0 开始计数！
print(f"最后一个: {fruits[-1]}")  # -1 表示倒数第一个

# 添加元素
fruits.append("葡萄")  # append 追加到末尾
print(f"添加后: {fruits}")

# 删除元素
fruits.remove("香蕉")  # remove 删除指定元素
print(f"删除后: {fruits}")
列表: ['苹果', '香蕉', '橙子']
第一个: 苹果
最后一个: 橙子
添加后: ['苹果', '香蕉', '橙子', '葡萄']
删除后: ['苹果', '橙子', '葡萄']
⚠️ 注意索引从 0 开始！

在大多数编程语言中，列表的第一个元素索引是 0，不是 1。

就像楼层：第 1 层其实是 0 楼（ground floor）。

字典 (Dictionary)

字典就像真实字典，通过"键"（词语）查找"值"（解释）。访问速度超快！

Python 
person = {
    "name": "张三",  # "name" 是键，张三 是值
    "age": 25,
    "city": "北京"
}
print(f"字典: {person}")
print(f"姓名: {person['name']}")  # 通过键访问
print(f"年龄: {person.get('age')}")  # get 方法更安全

# 添加/修改
person["job"] = "工程师"
print(f"添加后: {person}")

# 遍历
for key, value in person.items():  # items() 返回键值对
    print(f"  {key}: {value}")
💡 字典 vs 列表
  • 列表：按顺序存储，适合需要按位置访问的场景
  • 字典：按键值对存储，适合需要快速查找的场景

集合 (Set)

集合就像一个不重复的袋子，自动去除重复元素。适合做集合运算（交集、并集）。

Python 
s = {1, 2, 3, 2, 1}  # 自动去重！
print(f"集合: {s}")  # 输出: {1, 2, 3}

# 集合运算
a = {1, 2, 3, 4, 5}
b = {4, 5, 6, 7, 8}
print(f"交集: {a & b}")   # 两个集合都有的元素: {4, 5}
print(f"并集: {a | b}")   # 合并所有元素: {1, 2, 3, 4, 5, 6, 7, 8}
print(f"差集: {a - b}")   # a 有 b 没有的: {1, 2, 3}

面向对象

面向对象编程（OOP）是一种把现实世界抽象成代码的思想。就像在创建"模具"（类），然后用模具造出具体的"产品"（对象）。

💡 类 vs 对象 的区别
  • 类 (Class)：就像设计图，定义了"人"应该有什么（属性和方法）
  • 对象 (Object)：就像用设计图造出来的真人，比如张三、李四

定义类

Python 
class Person:
    def __init__(self, name, age):
        """构造方法 - 创建对象时自动调用的初始化方法"""
        self.name = name  # self 指代对象本身
        self.age = age

    def greet(self):
        """方法 - 对象能做什么"""
        print(f"你好，我是{self.name}，今年{self.age}岁")

# 创建对象（实例化）
person1 = Person("张三", 25)  # 创建了一个"张三"这个人
person1.greet()  # 调用对象的方法
你好，我是张三，今年25岁
💡 __init__ 是什么意思？

__init__ 是 Python 的构造方法，创建对象时会自动调用。

self 指向对象本身，就像说"我自己"。

继承

继承就是子类继承父类的特性，就像儿子会继承父亲的一些特征，还能有自己的独特能力。

Python 
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(f"{self.name} 发出声音")

class Dog(Animal):  # Dog 继承自 Animal
    def speak(self):  # 重写父类的方法
        print(f"{self.name} 汪汪叫")

class Cat(Animal):
    def speak(self):
        print(f"{self.name} 喵喵叫")

# 创建对象
dog = Dog("旺财")
cat = Cat("咪咪")
dog.speak()  # 子类的方法
cat.speak()
旺财 汪汪叫
咪咪 喵喵叫

文件操作

文件操作就是读取和写入文件。就像打开文件夹、读取里面的内容，或者创建新文件并保存内容。

读写文件

Python 
# 写入文件
with open("test.txt", "w", encoding="utf-8") as f:
    """with 自动管理文件关闭，不用担心忘记 f.close()"""
    f.write("第一行\n")  # \n 表示换行
    f.write("第二行\n")

# 读取文件
with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read()  # 读取全部内容
    print(content)
💡 open() 模式说明
  • r：read，只读模式（默认）
  • w：write，写入模式（会覆盖原内容）
  • a：append，追加模式（在末尾添加）
✅ 推荐使用 with

with 语句会在代码块结束后自动关闭文件，即使出错了也会关闭，比手动调用 f.close() 更安全。

逐行读取

Python 
# 逐行读取 - 适合大文件
with open("test.txt", "r", encoding="utf-8") as f:
    for line in f:  # 每次只读取一行，节省内存
        print(line.strip())  # strip() 去除首尾空白
