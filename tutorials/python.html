Python 基础语法教程

Python 简介

Python 是一种广泛使用的高级编程语言，以其简洁易读的语法著称，非常适合编程初学者入门。

💡 Python 特点
  • 语法简洁，代码可读性高
  • 动态类型语言，不需要声明变量类型
  • 丰富的标准库和第三方库
  • 跨平台支持

第一个程序

Python 
print("Hello, World!")
Hello, World!

变量和数据类型

Python 是动态类型语言，变量不需要声明类型，直接赋值即可。

基本变量

Python 
# 字符串类型
name = "张三"
# 整数类型
age = 25
# 浮点数类型
height = 1.75
# 布尔类型
is_student = True

print(f"姓名: {name}")
print(f"年龄: {age}")
print(f"身高: {height}")
print(f"是否学生: {is_student}")
姓名: 张三
年龄: 25
身高: 1.75
是否学生: True

查看变量类型

Python 
name = "张三"
age = 25

print(type(name))  # <class 'str'>
print(type(age))   # <class 'int'>

类型转换

Python 
# 字符串转整数
num_str = "123"
num_int = int(num_str)

# 整数转字符串
age = 25
age_str = str(age)

# 字符串转浮点数
pi_str = "3.14"
pi = float(pi_str)

print(f"整数: {num_int}, 类型: {type(num_int)}")
print(f"字符串: {age_str}, 类型: {type(age_str)}")
✅ 提示 Python 中字符串可以用单引号 ' 或双引号 " 包围。

运算符

算术运算符

Python 
a, b = 10, 3
print(f"加法: {a} + {b} = {a + b}")
print(f"减法: {a} - {b} = {a - b}")
print(f"乘法: {a} * {b} = {a * b}")
print(f"除法: {a} / {b} = {a / b}")
print(f"整除: {a} // {b} = {a // b}")
print(f"取余: {a} % {b} = {a % b}")
print(f"幂运算: {a} ** {b} = {a ** b}")
加法: 10 + 3 = 13
减法: 10 - 3 = 7
乘法: 10 * 3 = 30
整除: 10 // 3 = 3
取余: 10 % 3 = 1
幂运算: 10 ** 3 = 1000

比较运算符

Python 
m, n = 10, 20
print(f"{m} == {n}: {m == n}")  # False
print(f"{m} != {n}: {m != n}")  # True
print(f"{m} > {n}: {m > n}")    # False
print(f"{m} < {n}: {m < n}")    # True

逻辑运算符

Python 
p, q = True, False
print(f"p and q: {p and q}")  # False
print(f"p or q: {p or q}")    # True
print(f"not p: {not p}")      # False

条件语句

Python 使用 if、elif、else 进行条件判断。

基本 if 语句

Python 
age = 18
if age >= 18:
    print("你已经成年了")
else:
    print("你还未成年")
你已经成年了

多条件判断

Python 
score = 85
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 60:
    grade = "C"
else:
    grade = "D"

print(f"成绩 {score} 分，等级: {grade}")
成绩 85 分，等级: B

三元表达式

Python 
a, b = 10, 20
max_val = a if a > b else b
print(f"{a} 和 {b} 中较大的是: {max_val}")
10 和 20 中较大的是: 20

break 和 continue

Python 
# break: 跳出循环
for i in range(10):
    if i == 5:
        break
    print(i, end=" ")
print("\n遇到 break，循环结束")

# continue: 跳过当前迭代
for i in range(10):
    if i % 2 == 0:
        continue
    print(i, end=" ")
print("\n只打印了奇数")
0 1 2 3 4
遇到 break，循环结束
1 3 5 7 9
只打印了奇数

函数

定义函数

Python 
def greet():
    """简单的问候函数"""
    print("Hello, World!")

def greet_user(name):
    """向指定用户问候"""
    print(f"你好，{name}！")

def add(a, b):
    """返回两个数的和"""
    return a + b

greet()
greet_user("张三")
print(f"3 + 5 = {add(3, 5)}")
Hello, World!
你好，张三！
3 + 5 = 8

默认参数

Python 
def power(base, exponent=2):
    """计算幂，默认是平方"""
    return base ** exponent

print(f"3的平方: {power(3)}")
print(f"3的立方: {power(3, 3)}")
3的平方: 9
3的立方: 27

可变参数

Python 
def sum_all(*args):
    """计算所有参数的和"""
    total = 0
    for num in args:
        total += num
    return total

print(f"sum_all(1, 2, 3) = {sum_all(1, 2, 3)}")
print(f"sum_all(1, 2, 3, 4, 5) = {sum_all(1, 2, 3, 4, 5)}")
sum_all(1, 2, 3) = 6
sum_all(1, 2, 3, 4, 5) = 15

Lambda 表达式

Python 
# 匿名函数
square = lambda x: x ** 2
print(f"5的平方: {square(5)}")

# 作为参数传递
nums = [1, 2, 3, 4, 5]
squared = list(map(lambda x: x ** 2, nums))
print(f"平方后: {squared}")
5的平方: 25
平方后: [1, 4, 9, 16, 25]

列表 (List)

Python

字典 (Dictionary)

Python 
person = {"name": "张三", "age": 25, "city": "北京"}
print(f"字典: {person}")
print(f"姓名: {person['name']}")
print(f"年龄: {person.get('age')}")

# 添加/修改
person["job"] = "工程师"
print(f"添加后: {person}")

# 遍历
for key, value in person.items():
    print(f"  {key}: {value}")

集合 (Set)

Python 
s = {1, 2, 3, 2, 1}  # 自动去重
print(f"集合: {s}")  # {1, 2, 3}

# 集合运算
a = {1, 2, 3, 4, 5}
b = {4, 5, 6, 7, 8}
print(f"交集: {a & b}")   # {4, 5}
print(f"并集: {a | b}")   # {1, 2, 3, 4, 5, 6, 7, 8}
print(f"差集: {a - b}")   # {1, 2, 3}

面向对象

定义类

Python 
class Person:
    def __init__(self, name, age):
        """构造方法"""
        self.name = name
        self.age = age

    def greet(self):
        """问候方法"""
        print(f"你好，我是{self.name}，今年{self.age}岁")

# 创建对象
person1 = Person("张三", 25)
person1.greet()
你好，我是张三，今年25岁

继承

Python 
class Animal:
    def __init__(self, name):
        self.name = name
    
    def speak(self):
        print(f"{self.name} 发出声音")

class Dog(Animal):
    def speak(self):
        print(f"{self.name} 汪汪叫")

class Cat(Animal):
    def speak(self):
        print(f"{self.name} 喵喵叫")

dog = Dog("旺财")
cat = Cat("咪咪")
dog.speak()
cat.speak()
旺财 汪汪叫
咪咪 喵喵叫

文件操作

读写文件

Python 
# 写入文件
with open("test.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.write("第二行\n")

# 读取文件
with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
💡 提示 with 语句会在代码块结束后自动关闭文件，无需手动调用 f.close()。
