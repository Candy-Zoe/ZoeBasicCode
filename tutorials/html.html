HTML/CSS 基础语法教程

Web 前端简介

Web 前端开发三剑客：HTML（结构）、CSS（样式）、JavaScript（行为）。

💡 学习建议
  • HTML 定义网页结构
  • CSS 控制网页外观
  • JavaScript 实现网页交互
  • 建议按顺序学习：HTML → CSS → JavaScript

运行环境

只需要一个浏览器即可，直接双击 HTML 文件打开。

HTML 基础

基本结构

HTML 
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>网页标题</title>
</head>
<body>
    <h1>这是标题</h1>
    <p>这是段落</p>
</body>
</html>

常用标签

HTML 
<!-- 标题 -->
<h1>一级标题</h1>
<h2>二级标题</h2>

<!-- 段落 -->
<p>这是一个段落。</p>

<!-- 链接 -->
<a href="https://example.com">访问链接</a>

<!-- 图片 -->
<img src="图片.jpg" alt="图片描述">

<!-- 列表 -->
<ul>
    <li>无序列表项1</li>
    <li>无序列表项2</li>
</ul>
<ol>
    <li>有序列表项1</li>
    <li>有序列表项2</li>
</ol>

表格

HTML 
<table border="1">
    <thead>
        <tr>
            <th>姓名</th>
            <th>年龄</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>张三</td>
            <td>25</td>
        </tr>
        <tr>
            <td>李四</td>
            <td>30</td>
        </tr>
    </tbody>
</table>

表单

基本表单

HTML 
<form>
    <label>用户名: <input type="text" name="username"></label>
    <label>密码: <input type="password" name="password"></label>
    <input type="submit" value="提交">
</form>

<!-- input 类型 -->
<input type="text">      <!-- 文本 -->
<input type="password">  <!-- 密码 -->
<input type="email">     <!-- 邮箱 -->
<input type="number">    <!-- 数字 -->
<input type="date">      <!-- 日期 -->
<input type="checkbox">  <!-- 多选 -->
<input type="radio">     <!-- 单选 -->
<input type="file">       <!-- 文件 -->

CSS 基础

CSS 语法

CSS 
/* 选择器 { 属性: 值; } */
h1 {
    color: #333;
    font-size: 24px;
}

.class-name {
    background: blue;
    padding: 10px;
}

#id-name {
    border: 1px solid red;
}

选择器

选择器说明示例
元素选择器标签名h1 { }
类选择器.class.btn { }
ID选择器#id#header { }
后代选择器空格.box p { }
伪类:a:hover { }

盒模型

💡 盒模型组成
  • content - 内容区域
  • padding - 内边距
  • border - 边框
  • margin - 外边距

布局

Flexbox 布局

CSS 
.container {
    display: flex;
    justify-content: space-between;  /* 主轴对齐 */
    align-items: center;            /* 交叉轴对齐 */
}

.item {
    flex: 1;  /* 分配剩余空间 */
}

Grid 布局

CSS 
.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);  /* 3列等宽 */
    gap: 20px;  /* 间距 */
}
