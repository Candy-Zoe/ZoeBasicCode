Shell / Bash 脚本编程教程

Shell 简介

Shell 是用户与操作系统内核之间的接口，Shell 脚本是一系列命令的集合，用于自动化任务。Bash 是最常用的 Shell 环境。

💡 Shell 类型
  • Bash：GNU Bourne Again Shell，最常用
  • Zsh：功能丰富，配合 Oh My Zsh
  • sh：Bourne Shell，POSIX 标准
  • Fish：友好的交互式 Shell
  • PowerShell：Windows 下的 Shell

第一个脚本

Bash
#!/bin/bash

echo "Hello, World!"

# 运行方式：
# chmod +x hello.sh
# ./hello.sh

第一行的 #! 叫做 shebang，指定脚本的解释器。

变量与数组

变量

Bash
#!/bin/bash

# 定义变量（等号两边不能有空格！）
name="张三"
age=25

# 使用变量
echo "姓名: $name, 年龄: $age"
echo "姓名: ${name}, 年龄: ${age}"

# 只读变量
readonly PI=3.14159

# 删除变量
unset age

# 字符串操作
str="Hello World"
echo "长度: ${#str}"          # 字符串长度
echo "截取: ${str:0:5}"        # 截取子串
echo "大写: ${str^^}"          # 全部大写
echo "小写: ${str,,}"          # 全部小写

# 环境变量
echo "HOME: $HOME"
echo "PATH: $PATH"
echo "USER: $USER"
echo "PWD: $PWD"

# 特殊变量
echo "脚本名: $0"
echo "参数1: $1"
echo "参数个数: $#"
echo "所有参数: $*"
echo "进程ID: $$"
echo "上一个命令退出码: $?"

数组

Bash
#!/bin/bash

# 定义数组
fruits=("苹果" "香蕉" "橙子" "葡萄")

# 访问元素（索引从 0 开始）
echo "第一个: ${fruits[0]}"
echo "所有元素: ${fruits[@]}"
echo "数组长度: ${#fruits[@]}"

# 添加元素
fruits+=("西瓜")

# 修改元素
fruits[0]="红苹果"

# 遍历数组
for fruit in "${fruits[@]}"; do
    echo "  - $fruit"
done

# 关联数组（Bash 4+）
declare -A person
person[name]="张三"
person[age]=25
person[city]="北京"
echo "姓名: ${person[name]}"

运算符

Shell 中的运算符包括算术运算、比较运算、逻辑运算和文件测试运算符。

算术运算符

Bash
#!/bin/bash

a=10
b=3

# 算术运算（使用 $(( )) 双括号）
echo "$a + $b = $((a + b))"    # 加法：13
echo "$a - $b = $((a - b))"    # 减法：7
echo "$a * $b = $((a * b))"    # 乘法：30
echo "$a / $b = $((a / b))"    # 整数除法：3（取整）
echo "$a % $b = $((a % b))"    # 取模：1
echo "$a ** $b = $((a ** b))"  # 幂运算：1000（10的3次方）

# 复合赋值
((a += 5))   # a = a + 5 = 15
echo "a += 5 后: $a"
((a *= 2))   # a = a * 2 = 30
echo "a *= 2 后: $a"

# 自增自减
((a++))      # 后置自增
echo "a++ 后: $a"
((++a))      # 前置自增
echo "++a 后: $a"
💡 算术运算注意事项
  • $(( )) 是用于算术运算的表达式，结果会自动替换
  • 变量前不需要加 $ 符号（内部会自动解析）
  • 除法是整数除法，不保留小数
  • 如果需要小数，使用 bc 或 awk

比较运算符

Bash
#!/bin/bash

a=10
b=20

# 整数比较（[ ] 中使用 -gt、-lt 等）
if [ $a -gt $b ]; then
    echo "$a > $b"
else
    echo "$a <= $b"
fi

# 常用整数比较运算符：
# -eq  等于（Equal）           -ne  不等于（Not Equal）
# -gt  大于（Greater Than）     -lt  小于（Less Than）
# -ge  大于等于（Greater or Equal）  -le  小于等于（Less or Equal）

# 字符串比较
str1="hello"
str2="world"
str3="hello"

# = 或 ==  等于    !=  不等于
if [ "$str1" = "$str3" ]; then
    echo "str1 等于 str3"
fi

# < 小于（ASCII码比较，需转义）  > 大于
if [ "$str1" \< "$str2" ]; then
    echo "hello 在 world 前面"
fi

# -z 字符串长度为0    -n 字符串长度不为0
name=""
if [ -z "$name" ]; then
    echo "name 是空字符串"
fi

# 文件测试运算符
file="test.txt"
if [ -f "$file" ]; then
    echo "$file 是普通文件"
fi

if [ -d "/home" ]; then
    echo "/home 是目录"
fi

# 更多文件测试：
# -e 文件存在   -f 普通文件   -d 目录
# -r 可读       -w 可写       -x 可执行
# -s 文件大小大于0   -L 符号链接

逻辑运算符

Bash
#!/bin/bash

a=10
b=20

# && 逻辑与（AND）- 两个条件都为真才为真
if [ $a -gt 5 ] && [ $b -lt 30 ]; then
    echo "a > 5 且 b < 30"
fi

# || 逻辑或（OR）- 任意一个条件为真就为真
if [ $a -gt 15 ] || [ $b -lt 30 ]; then
    echo "a > 15 或 b < 30"
fi

# ! 逻辑非（NOT）- 取反
if [ ! $a -eq $b ]; then
    echo "a 不等于 b"
fi

# 组合逻辑
age=25
income=5000

if [ $age -ge 18 ] && [ $age -le 60 ] && [ $income -gt 3000 ]; then
    echo "符合贷款条件"
fi
⚠️ 常见错误
  • [ ] 与变量之间要有空格：[ $a -gt $b ] 而不是 [$a -gt $b]
  • 字符串比较时加引号：[ "$str" = "hello" ] 防止空字符串导致语法错误
  • 使用 [[ ]] 更安全：支持更多特性，如 [[ ]] && [[ ]]

流程控制

if 条件语句

if 语句用于根据条件执行不同的代码块。

Bash
#!/bin/bash

# 基础 if 语法
score=85

if [ $score -ge 90 ]; then
    echo "成绩等级：优秀"
fi

# if-else 二选一
if [ $score -ge 60 ]; then
    echo "及格了！"
else
    echo "不及格，需要努力！"
fi

# if-elif-else 多选一
if [ $score -ge 90 ]; then
    echo "优秀"
elif [ $score -ge 80 ]; then
    echo "良好"
elif [ $score -ge 60 ]; then
    echo "及格"
else
    echo "不及格"
fi

# 注意事项：[ ] 前后要有空格，变量要加引号
# 错误写法：[$score -ge 90]  或  [ "$score"-ge 90 ]
# 正确写法：[ $score -ge 90 ]  或  [ "$score" -ge 90 ]

# 字符串比较示例
name="Alice"
if [ "$name" = "Alice" ]; then
    echo "欢迎，Alice！"
elif [ "$name" = "Bob" ]; then
    echo "欢迎，Bob！"
else
    echo "访客，你好！"
fi

case 多分支语句

case 语句类似于 if-elif，用于多值匹配，比写多个 if 更清晰。

Bash
#!/bin/bash

# case 语法：匹配模式，执行对应的命令
day="周一"

case $day in
    "周一"|"周二"|"周三"|"周四"|"周五")
        echo "今天是工作日"
        ;;
    "周六"|"周日")
        echo "今天是周末"
        ;;
    *)
        echo "无效的日期"
        ;;
esac

# 模式匹配说明：
# *           匹配任意字符
# ?           匹配单个任意字符
# [abc]       匹配 a、b、c 任一字符
# [0-9]       匹配任一数字

# 实际应用：判断用户输入
echo "请输入一个选项 (a/b/c)："
read choice

case $choice in
    a|A)
        echo "你选择了选项 A"
        ;;
    b|B)
        echo "你选择了选项 B"
        ;;
    c|C)
        echo "你选择了选项 C"
        ;;
    *)
        echo "无效选择"
        ;;
esac

# 文件类型判断
file="/path/to/somefile.txt"

case $file in
    *.txt)
        echo "文本文件"
        ;;
    *.jpg|*.png|*.gif)
        echo "图片文件"
        ;;
    *.sh)
        echo "Shell 脚本"
        ;;
    *)
        echo "未知类型"
        ;;
esac
💡 if 与 case 的选择
  • if：适合判断表达式、条件组合（如 [ $a -gt 5 ] && [ $b -lt 10 ]）
  • case：适合匹配固定值、模式（通配符），代码更简洁

for 循环

for 循环用于遍历列表或执行固定次数的迭代。

Bash
#!/bin/bash

# 遍历列表
echo "遍历列表："
for i in 1 2 3 4 5; do
    echo "  第 $i 项"
done

# 遍历字符串
echo "遍历字符串："
for word in hello world; do
    echo "  单词: $word"
done

# 遍历数组
echo "遍历数组："
fruits=("苹果" "香蕉" "橙子" "葡萄")
for fruit in "${fruits[@]}"; do
    echo "  喜欢: $fruit"
done

# C 风格 for 循环（类似 Java/C）
echo "C 风格循环："
for ((i=1; i<=5; i++)); do
    echo "  i = $i"
done

# 步长循环
echo "步长为 2："
for ((i=0; i<10; i+=2)); do
    echo "  i = $i"
done

# 遍历文件
echo "当前目录的 txt 文件："
for file in *.txt; do
    echo "  发现文件: $file"
done

# 遍历目录
echo "子目录列表："
for dir in */; do
    echo "  目录: $dir"
done

while 循环

while 循环在条件为真时重复执行，适合不知道循环次数的场景。

Bash
#!/bin/bash

# 基础 while 循环
echo "while 循环示例："
count=1
while [ $count -le 5 ]; do
    echo "  count = $count"
    count=$((count + 1))  # 注意：表达式在 (()) 中，变量不加 $
done

# 读取文件行
echo "读取文件内容："
# 创建示例文件
echo -e "第一行\n第二行\n第三行" > temp_file.txt

while read -r line; do
    echo "  行内容: $line"
done < temp_file.txt
rm -f temp_file.txt

# 无限循环（配合 break 使用）
echo "无限循环示例："
i=1
while true; do
    echo "  第 $i 次"
    if [ $i -ge 3 ]; then
        echo "  退出循环"
        break
    fi
    i=$((i + 1))
done

# until 循环（条件为假时执行，与 while 相反）
echo "until 循环示例："
count=1
until [ $count -gt 5 ]; do
    echo "  count = $count"
    count=$((count + 1))
done
⚠️ 循环中的 break 和 continue
  • break：立即退出整个循环
  • continue：跳过本次循环，继续下一次
  • 多层循环时可用 break 2 退出多层
Bash
#!/bin/bash

# break 和 continue 示例
echo "break 和 continue 示例："
for i in 1 2 3 4 5; do
    if [ $i -eq 2 ]; then
        echo "  跳过 i = $i"
        continue  # 跳过本次，不执行后面的 echo
    fi
    if [ $i -eq 4 ]; then
        echo "  遇到 4，退出循环"
        break  # 退出整个循环
    fi
    echo "  处理: i = $i"
done

函数定义

函数是一段可重复使用的代码块，用于组织脚本结构和提高代码复用。

函数基础

Bash
#!/bin/bash

# 定义函数（两种方式都可以）
function say_hello {
    echo "Hello, World!"
}

greet() {
    echo "你好，世界！"
}

# 调用函数
say_hello
greet

函数参数与返回值

Bash
#!/bin/bash

# 带参数的函数
# 参数通过 $1, $2, ... $9 获取，$0 是脚本名
greet() {
    echo "你好, $1!"
    echo "今天是 $2"
}

greet "张三" "周一"  # 调用，传入两个参数
# 输出：
# 你好, 张三!
# 今天是 周一

# 计算两个数的和
add() {
    local sum=$(($1 + $2))  # local 声明局部变量
    echo $sum  # 通过 echo 返回
}

result=$(add 5 3)  # 获取返回值
echo "5 + 3 = $result"

# 返回值（return 语句）
is_even() {
    if (($1 % 2 == 0)); then
        return 0  # 返回 0 表示真（成功）
    else
        return 1  # 返回非 0 表示假（失败）
    fi
}

is_even 4
if [ $? -eq 0 ]; then
    echo "4 是偶数"
fi
💡 参数说明
  • $1-$9：第 1-9 个参数
  • ${10}：第 10 个参数（需用大括号）
  • $#：参数个数
  • $@：所有参数（作为独立字符串）
  • $*：所有参数（作为单个字符串）

函数示例

Bash
#!/bin/bash

# 局部变量 vs 全局变量
demo_var() {
    local local_var="局部变量"  # 局部变量
    global_var="全局变量"       # 全局变量
    echo "函数内 - local_var: $local_var"
    echo "函数内 - global_var: $global_var"
}

demo_var
echo "函数外 - global_var: $global_var"
# echo "函数外 - local_var: $local_var"  # 这里会输出空

# 递归函数：计算阶乘
factorial() {
    if [ $1 -le 1 ]; then
        echo 1
    else
        local prev=$(factorial $(($1 - 1)))
        echo $(($1 * prev))
    fi
}

echo "5! = $(factorial 5)"  # 输出 120

# 函数库示例：常用工具函数
log() {
    local level=$1
    shift
    echo "[$level] $*"
}

log "INFO" "程序开始运行"
log "ERROR" "文件不存在"
log "DEBUG" "变量 x = $x"

函数与数组

Bash
#!/bin/bash

# 接收数组参数
print_array() {
    local arr=("$@")  # 将参数转为数组
    echo "数组长度: ${#arr[@]}"
    for i in "${!arr[@]}"; do
        echo "  [$i] = ${arr[$i]}"
    done
}

fruits=("苹果" "香蕉" "橙子")
print_array "${fruits[@]}"

# 返回数组
get_colors() {
    local colors=("红色" "绿色" "蓝色")
    echo "${colors[@]}"
}

color_array=($(get_colors))  # 捕获返回的数组
echo "颜色: ${color_array[1]}"
✅ 函数最佳实践
  • 函数名用小写，多个单词用下划线分隔（如 check_file_exists）
  • 函数内部变量用 local 声明，避免污染全局环境
  • 复杂脚本将函数分离到单独文件，用 source 引入
  • 为函数编写注释说明参数和返回值

Bash

调试与信号

Bash
#!/bin/bash

# 调试模式
set -x   # 打印执行的每一条命令
set -e   # 遇到错误立即退出
set -u   # 使用未定义变量时报错
set -o pipefail  # 管道中任一命令失败则整体失败

# 或运行时加参数
# bash -x script.sh

# trap 捕获信号
cleanup() {
    echo "清理资源..."
    # rm -f /tmp/tempfile
}

trap cleanup EXIT        # 脚本退出时执行
trap 'echo "收到 SIGINT"' SIGINT  # Ctrl+C 时

echo "脚本运行中..."
sleep 1
echo "脚本结束"

# 常用信号：
# SIGINT (2)  - Ctrl+C
# SIGTERM (15) - 终止信号
# SIGKILL (9) - 强制杀死（不能捕获）
# EXIT (0)    - 脚本退出
✅ Shell 脚本最佳实践
  • 开头使用 #!/bin/bash 并 set -euo pipefail
  • 变量名用大写，函数名用小写加下划线
  • 字符串引用时用双引号包裹变量
  • 重要脚本加注释和帮助信息
  • 使用 shellcheck 静态检查
