Kotlin 基础教程

Kotlin 简介

Kotlin 是 JetBrains 开发的现代编程语言，运行在 JVM 上，语法简洁优雅。Google 官方推荐的 Android 开发语言，也可用于后端、Web 和原生开发。

💡 Kotlin 特点
  • 简洁：代码量比 Java 少很多
  • 空安全：从语法层面避免空指针
  • 100% Java 互操作
  • 函数式 + 面向对象
  • 扩展函数、数据类、密封类
  • 协程（Coroutine）异步编程
  • Android 官方开发语言

运算符

Kotlin 支持多种运算符，用于执行算术、比较、逻辑等操作。

算术运算符

Kotlin
fun main() {
    val a = 10
    val b = 3

    // 基本算术运算
    println("加法: a + b = ${a + b}")      // 13
    println("减法: a - b = ${a - b}")      // 7
    println("乘法: a * b = ${a * b}")      // 30
    println("除法: a / b = ${a / b}")      // 3（整数除法）
    println("取余: a % b = ${a % b}")      // 1

    // 浮点数除法
    val c = 10.0
    println("浮点除法: c / b = ${c / b}")  // 3.333...

    // 复合赋值运算符
    var x = 5
    x += 3    // x = x + 3 = 8
    println("x += 3: $x")
    x -= 2    // x = x - 2 = 6
    println("x -= 2: $x")
    x *= 2    // x = x * 2 = 12
    println("x *= 2: $x")
    x /= 3    // x = x / 3 = 4
    println("x /= 3: $x")
    x %= 3    // x = x % 3 = 1
    println("x %= 3: $x")

    // 一元运算符
    var y = 5
    println("y++: ${y++}")   // 先返回值(5)，再自增
    println("++y: ${++y}")   // 先自增(7)，再返回值
    println("y--: ${y--}")   // 先返回值(7)，再自减
    println("--y: ${--y}")   // 先自减(5)，再返回值
}
💡 整数除法注意

在 Kotlin 中，两个整数相除结果仍是整数（截断小数部分）。如果需要浮点结果，请将任一操作数转为 Double 或 Float。

比较运算符

Kotlin
fun main() {
    val a = 10
    val b = 20
    val c = 10

    // 基本比较
    println("a == c: ${a == c}")   // true（值相等）
    println("a != b: ${a != b}")   // true（值不等）
    println("a > b: ${a > b}")     // false
    println("a < b: ${a < b}")     // true
    println("a >= c: ${a >= c}")   // true
    println("a <= c: ${a <= c}")  // true

    // 字符串比较
    val str1 = "Hello"
    val str2 = "hello"
    println("\"Hello\" == \"hello\": ${str1 == str2}")   // false
    println("\"Hello\".equals(\"hello\", ignoreCase = true): ${str1.equals(str2, ignoreCase = true)}")  // true

    // Kotlin 的 == 比较的是值（类似 equals），=== 比较的是引用
    val str3 = "Hello"
    println("str1 == str3: ${str1 == str3}")  // true（值相同）
    println("str1 === str3: ${str1 === str3}") // true（可能同一对象，字符串驻留）

    val list1 = listOf(1, 2, 3)
    val list2 = listOf(1, 2, 3)
    println("list1 == list2: ${list1 == list2}")  // true（值相同）
    println("list1 === list2: ${list1 === list2}") // false（不同对象）

    // 区间检查
    val score = 85
    println("score in 60..100: ${score in 60..100}")  // true
    println("score !in 0..59: ${score !in 0..59}")    // true
}

逻辑运算符

Kotlin
fun main() {
    val a = true
    val b = false

    // 逻辑运算
    println("a && b: ${a && b}")   // false（与：两者都为 true 才为 true）
    println("a || b: ${a || b}")   // true（或：至少一个为 true 就为 true）
    println("!a: ${!a}")           // false（非：取反）

    // 短路求值
    // && 和 || 都会短路：如果第一个条件能确定结果，就不再计算第二个
    fun check1(): Boolean {
        println("check1 被调用")
        return true
    }
    fun check2(): Boolean {
        println("check2 被调用")
        return false
    }

    println("\n短路求值示例:")
    println("result = ${check1() && check2()}")  // check2 不会被调用
    println("---")
    println("result = ${check2() || check1()}")  // check1 会被调用

    // 区间与范围
    val age = 25
    println("\nage 在 18-60 之间: ${age in 18..60}")
    println("age 在 0-17 或 61-100: ${age < 18 || age > 60}")

    // 字符范围
    val ch = 'c'
    println("'c' 在 'a'..'z': ${ch in 'a'..'z'}")
}

位运算符

Kotlin
fun main() {
    val x = 0b1100   // 12 的二进制: 00001100
    val y = 0b1010   // 10 的二进制: 00001010

    println("x = $x, y = $y")
    println("x and y = ${x and y}")   // 8  (00001000)
    println("x or y = ${x or y}")     // 14 (00001110)
    println("x xor y = ${x xor y}")   // 6  (00000110)
    println("x.inv() = ${x.inv()}")   // -13 (按位取反)

    // 移位操作
    val shift = 1
    println("\n移位操作 (基于 $shift):")
    println("x shl 2 = ${x shl 2}")   // 左移 2 位: 48
    println("x shr 1 = ${x shr 1}")   // 右移 1 位: 6
    println("x ushr 2 = ${x ushr 2}") // 无符号右移 2 位: 3

    // 常用技巧
    println("\n常用技巧:")
    // 判断奇偶
    val num = 7
    println("$num 是奇数: ${num and 1 == 1}")
    println("$num 是偶数: ${num and 1 == 0}")

    // 快速乘除 2 的幂
    println("$num * 2 = ${num shl 1}")
    println("$num / 2 = ${num shr 1}")
}

条件语句

条件语句用于根据不同条件执行不同代码分支。

if-else 表达式

在 Kotlin 中，if-else 是表达式，可以返回值（类似三目运算符）。

Kotlin
fun main() {
    // 基本 if-else
    val score = 85
    if (score >= 90) {
        println("优秀")
    } else if (score >= 80) {
        println("良好")
    } else if (score >= 60) {
        println("及格")
    } else {
        println("不及格")
    }

    // if-else 作为表达式（返回值）
    val grade = if (score >= 90) {
        "优秀"
    } else if (score >= 80) {
        "良好"
    } else if (score >= 60) {
        "及格"
    } else {
        "不及格"
    }
    println("成绩等级: $grade")

    // 简化写法（单行可用）
    val result = if (score >= 60) "及格" else "不及格"
    println("简化: $result")

    // if-else 嵌套
    val num = 10
    if (num > 0) {
        if (num % 2 == 0) {
            println("$num 是正偶数")
        } else {
            println("$num 是正奇数")
        }
    } else {
        println("$num 不是正数")
    }
}
💡 提示

在 Kotlin 中，if-else 是表达式而非语句，这意味着它可以有返回值。这是 Kotlin 优于 Java 的一点。

when 表达式

when 是 Kotlin 强大的条件表达式，可以匹配各种类型的值。

Kotlin
fun main() {
    // 基本 when - 匹配值
    val day = "周一"
    val dayType = when (day) {
        "周一", "周二", "周三", "周四", "周五" -> "工作日"
        "周六", "周日" -> "周末"
        else -> "无效日期"
    }
    println("$day 是 $dayType")

    // when 作为表达式（返回值）
    val score = 85
    val result = when {
        score >= 90 -> "优秀"
        score >= 80 -> "良好"
        score >= 70 -> "中等"
        score >= 60 -> "及格"
        else -> "不及格"
    }
    println("分数 $score: $result")

    // 匹配类型
    fun describe(obj: Any): String = when (obj) {
        1 -> "数字 1"
        "Hello" -> "字符串 Hello"
        is Long -> "Long 类型，值: $obj"
        !is String -> "不是字符串"
        else -> "未知"
    }
    println(describe(1))
    println(describe("Hello"))
    println(describe(100L))
    println(describe(3.14))

    // 区间和集合检查
    val x = 15
    when (x) {
        in 1..10 -> println("$x 在 1-10 之间")
        in 11..20 -> println("$x 在 11-20 之间")
        !in 1..20 -> println("$x 不在 1-20 之间")
    }

    // when 携带多个条件
    val ch = 'a'
    when (ch) {
        'a', 'e', 'i', 'o', 'u' -> println("$ch 是元音字母")
        in 'a'..'z' -> println("$ch 是辅音字母")
        in '0'..'9' -> println("$ch 是数字")
        else -> println("$ch 是其他字符")
    }

    // 捕获 when 参数
    val tuple = Pair(1, 2)
    when {
        tuple.first > 0 && tuple.second > 0 -> println("第一象限")
        tuple.first < 0 && tuple.second > 0 -> println("第二象限")
        tuple.first < 0 && tuple.second < 0 -> println("第三象限")
        tuple.first > 0 && tuple.second < 0 -> println("第四象限")
        else -> println("在坐标轴上")
    }
}

when 的高级用法

Kotlin
// when 匹配密封类（编译器会检查是否覆盖所有情况）
sealed class Result {
    data class Success(val data: String) : Result()
    data class Error(val message: String) : Result()
    object Loading : Result()
}

fun handleResult(result: Result) = when (result) {
    is Result.Success -> println("成功: ${result.data}")
    is Result.Error -> println("错误: ${result.message}")
    Result.Loading -> println("加载中...")
    // 编译器知道这里没有其他情况，不需要 else
}

// when 枚举值
enum class Color { RED, GREEN, BLUE }

fun getColorName(color: Color) = when (color) {
    Color.RED -> "红色"
    Color.GREEN -> "绿色"
    Color.BLUE -> "蓝色"
    // 同样，编译器知道覆盖了所有情况
}

// when 代替 if-else 链
fun maxOf(a: Int, b: Int) = when {
    a > b -> a
    else -> b
}

fun main() {
    handleResult(Result.Success("数据加载成功"))
    handleResult(Result.Error("网络连接失败"))
    handleResult(Result.Loading)

    println("颜色: ${getColorName(Color.RED)}")
    println("最大值: ${maxOf(10, 20)}")
}

循环

循环用于重复执行代码块，Kotlin 提供了多种循环结构。

for 循环

for 循环是 Kotlin 最常用的循环结构，用于遍历区间、集合等。

Kotlin
fun main() {
    // 闭区间循环 1..3（包含 1 和 3）
    println("闭区间 1..3:")
    for (i in 1..3) {
        println("  i = $i")
    }

    // 半开区间 1 until 3（包含 1，不包含 3）
    println("半开区间 1 until 3:")
    for (i in 1 until 3) {
        println("  i = $i")
    }

    // 倒序 downTo
    println("倒序 3 downTo 1:")
    for (i in 3 downTo 1) {
        println("  i = $i")
    }

    // 步长 step
    println("step 2 (1, 3, 5):")
    for (i in 1..5 step 2) {
        println("  i = $i")
    }

    // 遍历字符串
    val str = "Kotlin"
    println("遍历字符串:")
    for (ch in str) {
        println("  字符: $ch")
    }

    // 遍历数组
    val arr = arrayOf("苹果", "香蕉", "橙子")
    println("遍历数组:")
    for (item in arr) {
        println("  $item")
    }

    // 遍历带索引
    println("遍历带索引:")
    for ((index, item) in arr.withIndex()) {
        println("  $index: $item")
    }

    // 遍历 Map
    val map = mapOf("语文" to 90, "数学" to 85, "英语" to 88)
    println("遍历 Map:")
    for ((key, value) in map) {
        println("  $key: $value")
    }

    // 使用 indices 遍历索引
    println("使用 indices:")
    for (i in arr.indices) {
        println("  arr[$i] = ${arr[i]}")
    }
}

while 循环

while 循环在条件为 true 时重复执行代码块。

Kotlin
fun main() {
    // while 循环
    println("while 循环:")
    var i = 1
    while (i <= 3) {
        println("  i = $i")
        i++
    }

    // do-while 循环（至少执行一次）
    println("do-while 循环:")
    var j = 1
    do {
        println("  j = $j")
        j++
    } while (j <= 3)

    // 条件在前，先判断再执行
    println("先判断后执行:")
    var count = 0
    while (count < 3) {
        println("  count = $count")
        count++
    }

    // 可能一次都不执行
    println("while 条件初始为 false:")
    while (false) {
        println("  这行不会执行")
    }
    println("  (while 循环体未执行)")

    // do-while 至少执行一次
    println("do-while 条件初始为 false:")
    do {
        println("  do-while 会执行一次")
    } while (false)
}

repeat 循环

repeat 是 Kotlin 特有的循环，用于执行固定次数的循环。

Kotlin
fun main() {
    // 基本用法：重复 3 次，索引从 0 开始
    println("repeat(3):")
    repeat(3) { index ->
        println("  第 ${index + 1} 次，index = $index")
    }

    // 指定起始索引
    println("\n从 1 开始:")
    repeat(3) { index ->
        println("  ${index + 1}")
    }

    // 倒序打印
    println("\n倒序打印:")
    repeat(3) { index ->
        val num = 3 - index
        println("  $num")
    }

    // repeat 用于初始化
    println("\n创建列表:")
    val list = mutableListOf()
    repeat(5) { i ->
        list.add(i * i)  // 添加 0, 1, 4, 9, 16
    }
    println("  $list")

    // repeat 嵌套
    println("\n打印乘法表:")
    repeat(5) { i ->
        repeat(5) { j ->
            print("${(i + 1) * (j + 1)}\t")
        }
        println()
    }
}
💡 repeat 小技巧

repeat 是 Kotlin 特有的语法，比传统的 for (i in 0..n-1) 更简洁。如果不需要索引参数，可以省略。

循环控制

break 用于跳出循环，continue 用于跳过当前迭代。

Kotlin
fun main() {
    // break - 完全跳出循环
    println("break 示例（找到第一个偶数）:")
    for (i in 1..10) {
        if (i % 2 == 0) {
            println("  找到第一个偶数: $i")
            break
        }
    }

    // continue - 跳过当前迭代
    println("\ncontinue 示例（只打印奇数）:")
    for (i in 1..7) {
        if (i % 2 == 0) {
            continue  // 跳过偶数
        }
        println("  奇数: $i")
    }

    // 嵌套循环中使用标签（break/continue 指定目标）
    println("\n嵌套循环中使用 break@loop:")
    outer@ for (i in 1..3) {
        inner@ for (j in 1..3) {
            println("  i=$i, j=$j")
            if (j == 2) {
                println("    跳过 i=$i 的剩余内循环")
                continue@inner
            }
            if (i == 2 && j == 1) {
                println("    完全跳出外循环")
                break@outer
            }
        }
    }

    // 使用 break/continue 的好习惯
    println("\n查找第一个平方大于 50 的数:")
    for (n in 1..10) {
        val square = n * n
        if (square > 50) {
            println("  找到: n=$n, square=$square")
            break
        }
    }
}

循环的返回值

Kotlin
fun main() {
    // for 循环本身没有返回值，结果是 Unit
    val loopResult = for (i in 1..3) {
        println(i)
    }
    println("for 循环返回值: $loopResult")  // kotlin.Unit

    // 如果需要返回值，可以使用其他方式
    // 方法1：使用 map
    val squares = (1..5).map { it * it }
    println("平方: $squares")

    // 方法2：使用 buildList
    val evenNums = buildList {
        for (i in 1..10) {
            if (i % 2 == 0) add(i)
        }
    }
    println("偶数: $evenNums")

    // 方法3：使用 generateSequence
    val fibonacci = generateSequence(Pair(0, 1)) {
        Pair(it.second, it.first + it.second)
    }.map { it.first }.take(10).toList()
    println("斐波那契: $fibonacci")
}

数据类

数据类是一种特殊的类，专门用于保存数据。Kotlin 会自动生成 equals()、hashCode()、toString()、copy() 等方法。

基本用法

Kotlin
// 定义数据类
data class User(val id: Int, val name: String, val email: String)

fun main() {
    // 创建数据类实例
    val user1 = User(1, "张三", "zhangsan@example.com")
    val user2 = User(2, "李四", "lisi@example.com")

    // 自动生成的 toString()
    println("user1: $user1")
    // 输出: User(id=1, name=张三, email=zhangsan@example.com)

    // 自动生成的 equals()（比较属性值）
    val user3 = User(1, "张三", "zhangsan@example.com")
    println("user1 == user3: ${user1 == user3}")  // true
    println("user1 === user3: ${user1 === user3}")  // false（不同对象）

    // 自动生成的 hashCode()
    println("user1.hashCode() == user3.hashCode(): ${user1.hashCode() == user3.hashCode()}")

    // 自动生成的 copy()（复制并修改属性）
    val user4 = user1.copy(name = "王五")
    println("copy 后: $user4")
    println("copy 整个对象: ${user1.copy()}")

    // 解构声明
    val (id, name, email) = user1
    println("解构: id=$id, name=$name, email=$email")

    // 在集合中使用
    val users = listOf(user1, user2, user3)
    println("包含 user1: ${users.contains(user1)}")
    println("查找 id=2: ${users.find { it.id == 2 }}")
}

  • 数据类不能是 abstract、open、sealed、inner
  • 如果需要无参构造函数，给所有参数提供默认值

密封类

密封类用于表示受限的类层次结构，所有子类必须在定义时已知。这非常适合用于状态管理和结果处理。

基本用法

Kotlin
// 定义密封类
sealed class Result {
    // 子类必须是嵌套类或在同一个文件中
    data class Success(val data: String) : Result()
    data class Error(val message: String) : Result()
    object Loading : Result()
}

// 处理不同情况
fun handleResult(result: Result) {
    when (result) {
        is Result.Success -> println("成功: ${result.data}")
        is Result.Error -> println("错误: ${result.message}")
        Result.Loading -> println("加载中...")
    }
}

fun main() {
    val success = Result.Success("数据加载成功")
    val error = Result.Error("网络错误")
    val loading = Result.Loading

    handleResult(success)
    handleResult(error)
    handleResult(loading)
}
💡 密封类特点
  • 密封类的子类型是有限的、固定的
  • when 表达式可以覆盖所有子类型，编译器会检查是否完整
  • 子类型可以是数据类、对象声明或普通类
  • 子类型必须在同一文件内定义

使用表达式返回值

Kotlin
sealed class Operation {
    data class Add(val value: Int) : Operation()
    data class Subtract(val value: Int) : Operation()
    data class Multiply(val value: Int) : Operation()
    object Divide : Operation()
    object SquareRoot : Operation()
}

// 使用 when 表达式返回结果
fun calculate(current: Int, op: Operation): Int = when (op) {
    is Operation.Add -> current + op.value
    is Operation.Subtract -> current - op.value
    is Operation.Multiply -> current * op.value
    Operation.Divide -> current / 2  // 简化的除法
    Operation.SquareRoot -> (current * current)
}

fun main() {
    var result = 10
    result = calculate(result, Operation.Add(5))   // 15
    println("加 5: $result")
    result = calculate(result, Operation.Multiply(2))  // 30
    println("乘 2: $result")
    result = calculate(result, Operation.SquareRoot)   // 900
    println("平方: $result")
    result = calculate(result, Operation.Subtract(100))  // 800
    println("减 100: $result")
}

空安全

空安全是 Kotlin 最著名的特性之一，从语法层面避免了空指针异常（NPE）。在 Kotlin 中，类型系统区分可空类型和非空类型。

可空类型与非空类型

Kotlin
fun main() {
    // 非空类型（不能存 null）
    val name: String = "Kotlin"
    // name = null  // 编译错误！

    // 可空类型（可以存 null）
    var nullableName: String? = "Kotlin"
    nullableName = null  // 正常

    println("name: $name")
    println("nullableName: $nullableName")
}

安全调用操作符（?.）

如果对象不为 null，则调用方法；否则返回 null。

Kotlin
fun main() {
    val str: String? = "Hello"

    // 安全调用
    println("str?.length = ${str?.length}")  // 5

    // 为 null 时返回 null
    val nullStr: String? = null
    println("nullStr?.length = ${nullStr?.length}")  // null

    // 链式调用
    val person = Person("张三", null)
    println("邮编: ${person.address?.city?.zipCode}")

    // 安全调用 + let
    str?.let {
        println("字符串长度: ${it.length}")
    }
}

data class Address(val city: City?)
data class City(val zipCode: String?)
data class Person(val name: String, val address: Address?)

Elvis 操作符（?:）

如果左侧值为 null，则返回右侧默认值。

Kotlin
fun main() {
    val name: String? = null

    // 基本用法
    val displayName = name ?: "匿名用户"
    println("显示名称: $displayName")  // 匿名用户

    // 链式使用
    val person = Person("张三", null)
    val city = person.address?.city?.name ?: "未知城市"
    println("城市: $city")

    // 与安全调用组合
    val length = person.name?.length ?: 0
    println("名字长度: $length")

    // Elvis 操作符可以链式
    val result: String? = null
    val finalResult = result ?: name ?: "默认值"
    println("最终结果: $finalResult")

    // 用于抛出异常
    val notNull = name ?: throw IllegalArgumentException("名称不能为空")
}

data class Person(val name: String?, val address: Address?)
data class Address(val city: City?)
data class City(val name: String?)

非空断言（!!）

强制转换为非空类型，如果值为 null 则抛出 NPE。请谨慎使用！

Kotlin
fun main() {
    val str: String? = "Hello"

    // 使用断言
    println("str!!.length = ${str!!.length}")  // 5

    // null 值会抛出异常
    val nullStr: String? = null
    // nullStr!!.length  // 这行会抛出 KotlinNullPointerException
}

fun processString(str: String?) {
    // 不推荐用法：使用 !! 断言非空
    // val len = str!!.length  // 如果 str 为 null，程序崩溃

    // 推荐用法：使用安全调用
    val safeLen = str?.length ?: 0
    println("安全长度: $safeLen")
}
⚠️ 警告

尽量避免使用 !! 操作符。它就像一颗定时炸弹，不知道什么时候会爆炸。如果程序崩溃了，那一定是你的问题。

安全转换（as?）

尝试转换类型，如果转换失败返回 null 而非抛出异常。

Kotlin
fun main() {

    println("转换结果: $str")  // Hello

    // 转换失败返回 null
    val num: Int? = obj as? Int
    println("数字转换: $num")  // null

    // 结合 Elvis 操作符
    val length = (obj as? String)?.length ?: 0
    println("字符串长度: $length")
}

    println("最后找到香蕉: ${fruits.findLast { it == "香蕉" }}")

    // indexOf / lastIndexOf
    println("香蕉索引: ${fruits.indexOf("香蕉")}")
    println("香蕉最后索引: ${fruits.lastIndexOf("香蕉")}")

    // contains / in
    println("包含橙子: ${fruits.contains("橙子")}")
    println("\"橙子\" in 列表: ${"橙子" in fruits}")

    // elementAt（越界抛异常）vs elementAtOrElse / elementAtOrNull
    println("索引2: ${fruits.elementAt(2)}")
    println("索引10: ${fruits.elementAtOrNull(10) ?: "越界"}")
    println("索引10: ${fruits.elementAtOrElse(10) { "默认值: $it" }}")

    // take / drop
    println("前3个: ${fruits.take(3)}")
    println("去掉前2个: ${fruits.drop(2)}")
    println("最后2个: ${fruits.takeLast(2)}")
    println("去掉最后2个: ${fruits.dropLast(2)}")
}

序列（Sequence）

对于大数据集，序列可以提高性能，因为它使用惰性计算。

Kotlin
fun main() {
    // 创建序列
    val numbers = sequenceOf(1, 2, 3, 4, 5)

    // 从列表转序列
    val list = listOf(1, 2, 3, 4, 5)
    val seq = list.asSequence()

    // generateSequence - 生成无限序列
    val fibonacci = generateSequence(Pair(0, 1)) {
        Pair(it.second, it.first + it.second)
    }.map { it.first }.take(10)

    println("斐波那契: ${fibonacci.toList()}")

    // 序列操作
    val result = sequenceOf(1, 2, 3, 4, 5)
        .map { it * it }      // 转换
        .filter { it > 10 }   // 过滤
        .take(2)              // 取前2个
        .toList()
    println("序列操作结果: $result")

    // 比较：列表每次操作都创建新集合
    // 序列只在最终操作时才计算（惰性求值）
    println("性能对比:")
    val largeList = (1..100000).toList()

    // 列表：每个操作都创建新列表
    val listTime = measureTime {
        largeList.map { it * 2 }.filter { it > 1000 }.take(10)
    }

    // 序列：只在最后才计算
    val seqTime = measureTime {
        largeList.asSequence().map { it * 2 }.filter { it > 1000 }.take(10).toList()
    }

    println("列表耗时: ${listTime}ms")
    println("序列耗时: ${seqTime}ms")
}

fun measureTime(block: () -> Unit): Long {
    val start = System.currentTimeMillis()
    block()
    return System.currentTimeMillis() - start
}

作用域函数

Kotlin 标准库提供了几个非常实用的作用域函数，是 Kotlin 的特色语法。

Kotlin
fun main() {
    // let - 函数内用 it 引用，返回最后一行
    val str: String? = "Hello"
    str?.let {
        println("let: 字符串长度 = ${it.length}")
    }

    // apply - 函数内用 this 引用，返回对象本身
    val list = mutableListOf<Int>().apply {
        add(1)
        add(2)
        add(3)
    }
    println("apply 创建的列表: $list")

    // run - 函数内用 this 引用，返回最后一行
    val result = StringBuilder().run {
        append("Hello")
        append(" ")
        append("World")
        toString()
    }
    println("run 结果: $result")

    // with - 非扩展函数，传入对象
    val list2 = listOf(1, 2, 3)
    val size = with(list2) {
        println("with: 列表 = $this")
        size
    }
    println("with 返回大小: $size")

    // also - 类似 apply，但用 it 引用
    val numbers = mutableListOf<Int>()
    numbers.also {
        it.add(1)
        it.add(2)
    }.also {
        println("also: $it")
    }

    // takeIf - 满足条件返回对象，否则 null
    val num = 42
    val result2 = num.takeIf { it > 10 }
    println("takeIf { it > 10 }: $result2")

    // takeUnless - 不满足条件返回对象
    val result3 = num.takeUnless { it > 100 }
    println("takeUnless { it > 100 }: $result3")
}
函数引用方式返回值用途
letit最后一行非空判断、链式调用
applythis对象本身初始化对象
runthis最后一行配置并计算结果
withthis最后一行对对象做多个操作
alsoit对象本身附加操作（打印等）
