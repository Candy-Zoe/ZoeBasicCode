Rust 基础教程

Rust 简介

Rust 是一门注重安全、并发和性能的系统编程语言，由 Mozilla 开发。它通过所有权系统在编译时保证内存安全，无需垃圾回收。

💡 Rust 核心特点
  • 内存安全：所有权系统，无 GC
  • 零成本抽象：高性能，媲美 C++
  • 并发安全：编译时防止数据竞争
  • 实用的错误处理：Result、Option
  • 现代工具链：cargo、rustfmt、clippy

所有权与借用

⚠️ 所有权三大规则
  1. 每个值都有一个所有者
  2. 值在任一时刻只能有一个所有者
  3. 当所有者离开作用域，值将被丢弃

所有权转移

Rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1;  // s1 的所有权转移给 s2
    // println!("{}", s1);  // 错误！s1 已失效

    // clone 深拷贝
    let s1 = String::from("hello");
    let s2 = s1.clone();

    // 基本类型实现了 Copy，不转移
    let x = 5;
    let y = x;  // x 仍然可用
}

引用与借用

Rust
fn calculate_length(s: &String) -> usize {
    s.len()
}  // s 离开作用域，但因为没有所有权，什么也不做

fn main() {
    let s1 = String::from("hello");
    let len = calculate_length(&s1);  // 借用，不转移所有权
    println!("'{}' 的长度是 {}", s1, len);

    // 可变引用
    let mut s = String::from("hello");
    change(&mut s);

    // 同一时间只能有一个可变引用
    // 或多个不可变引用
}

fn change(some_string: &mut String) {
    some_string.push_str(", world");
}

方法

Rust
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    // 方法
    fn area(&self) -> u32 {
        self.width * self.height
    }

    fn can_hold(&self, other: &Rectangle) -> bool {
        self.width > other.width && self.height > other.height
    }

    // 关联函数（类似静态方法）
    fn square(size: u32) -> Rectangle {
        Rectangle { width: size, height: size }
    }
}

Trait 与泛型

Trait

Rust
pub trait Summary {
    fn summarize(&self) -> String;

    // 默认实现
    fn summarize_author(&self) -> String {
        String::from("(Read more...)")
    }
}

struct Tweet { username: String, content: String }

impl Summary for Tweet {
    fn summarize(&self) -> String {
        format!("{}: {}", self.username, self.content)
    }
}

// trait 作为参数
fn notify(item: &impl Summary) {
    println!("突发新闻! {}", item.summarize());
}

// trait 边界
fn notify2<T: Summary>(item: &T) {
    println!("突发新闻! {}", item.summarize());
}

泛型

Rust
// 泛型函数
fn largest<T: PartialOrd>(list: &[T]) -> &T {
    let mut largest = &list[0];
    for item in list {
        if item > largest {
            largest = item;
        }
    }
    largest
}

// 泛型结构体
struct Point<T, U> {
    x: T,
    y: U,
}

// 泛型方法
impl<T, U> Point<T, U> {
    fn x(&self) -> &T {
        &self.x
    }
}

生命周期

Rust
// 函数生命周期注解
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}

// 结构体生命周期注解
struct ImportantExcerpt<'a> {
    part: &'a str,
}

fn main() {
    let novel = String::from("Call me Ishmael. Some years ago...");
    let first_sentence = novel.split('.').next().expect("没找到");
    let i = ImportantExcerpt { part: first_sentence };
}
✅ 生命周期省略规则

当函数满足以下情况时，Rust 可以自动推断生命周期，无需手动标注：

  • 输入生命周期都一样
  • 只有一个引用参数
  • 方法中 self 的生命周期赋给所有输出

错误处理

Rust
use std::fs::File;
use std::io::{self, Read};

// panic! - 不可恢复错误
// panic!("crash and burn");

// Result - 可恢复错误
fn main() {
    let f = File::open("hello.txt");
    let f = match f {
        Ok(file) => file,
        Err(error) => panic!("打开文件失败: {:?}", error),
    };
}

// ? 运算符 - 传播错误
fn read_username_from_file() -> Result<String, io::Error> {
    let mut s = String::new();
    File::open("hello.txt")?.read_to_string(&mut s)?;
    Ok(s)
}

// 自定义错误
#[derive(Debug)]
struct MyError { message: String }

impl std::fmt::Display for MyError {
    fn fmt(&self, f: &mut std::fmt::Formatter) -> std::fmt::Result {
        write!(f, "{}", self.message)
    }
}
