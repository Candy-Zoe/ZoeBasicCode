Rust 基础教程

Rust 简介

Rust 是一门注重安全、并发和性能的系统编程语言，由 Mozilla 开发。它通过所有权系统在编译时保证内存安全，无需垃圾回收。

💡 Rust 核心特点
  • 内存安全：所有权系统，无 GC
  • 零成本抽象：高性能，媲美 C++
  • 并发安全：编译时防止数据竞争
  • 实用的错误处理：Result、Option
  • 现代工具链：cargo、rustfmt、clippy

变量与数据类型

变量与可变性

Rust
fn main() {
    // 不可变变量（默认）- 推荐优先使用
    let x = 5;
    // x = 6;  // 编译错误！x 是不可变的

    // 可变变量 - 需要明确声明
    let mut y = 5;
    y = 6;  // 正确，可以修改

    // 常量 - 编译时确定，始终不可变
    const MAX_POINTS: u32 = 100_000;
    // const MAX_POINTS: u32 = get_value(); // 错误！常量不能是函数返回值

    // 变量遮蔽 - 可以用 let 重新声明同名的变量
    let spaces = "   ";       // 这是一个字符串
    let spaces = spaces.len(); // 这是一个数字，遮蔽了前面的 spaces
}
💡 变量遮蔽 vs 可变变量
  • 变量遮蔽：可以用 let 声明新变量，可以改变类型
  • 可变性：使用 mut 修改现有变量的值，类型不能变
  • 推荐优先使用变量遮蔽，因为更安全

逻辑运算符

Rust
fn main() {
    let p = true;
    let q = false;

    // 逻辑与（AND）- 两者都为 true 时结果为 true
    let and_result = p && q;       // false
    let and_result2 = p && true;  // true

    // 逻辑或（OR）- 至少有一个为 true 时结果为 true
    let or_result = p || q;        // true
    let or_result2 = false || false; // false

    // 逻辑非（NOT）- 取反
    let not_result = !p;           // false
    let not_result2 = !q;          // true

    // 短路求值
    // 表达式从左到右计算，遇到可以确定结果的值就停止
    let short_circuit = false && {
        println!("这行不会执行！"); // 不会打印
        true
    };

    println!("true && false = {}", and_result);
    println!("true || false = {}", or_result);
    println!("!true = {}", not_result);

    // 逻辑运算符优先级
    // ! > && > ||
    let demo = !false && true || false && true;
    // 等价于: ((!false) && true) || (false && true)
    // = (true && true) || (false && true)
    // = true || false
    // = true
    println!("!false && true || false && true = {}", demo);
}

位运算符

Rust
fn main() {
    let a: u8 = 0b11110010;  // 二进制: 11110010
    let b: u8 = 0b00111100;  // 二进制: 00111100

    // 按位与 - 对应位都为1时结果为1
    let bit_and = a & b;     // 00110010 = 50

    // 按位或 - 对应位至少有一个为1时结果为1
    let bit_or = a | b;      // 11111110 = 254

    // 按位异或 - 对应位不同时结果为1
    let bit_xor = a ^ b;     // 11000100 = 196

    // 按位取反 - 0变1，1变0
    let bit_not = !a;        // 00001101 = 13（假设u8溢出）

    // 左移 - 将位向左移动指定位数
    let shift_left = a << 2; // 11001000 = 200

    // 右移 - 将位向右移动指定位数
    let shift_right = a >> 2; // 00111100 = 60

    println!("a & b = {}", bit_and);
    println!("a | b = {}", bit_or);
    println!("a ^ b = {}", bit_xor);
    println!("a << 2 = {}", shift_left);
    println!("a >> 2 = {}", shift_right);

    // 常用技巧
    // 判断奇偶
    let num = 7;
    let is_odd = (num & 1) == 1;  // true（奇数）
    println!("{} 是奇数: {}", num, is_odd);

    // 2的幂次判断
    let power_of_two = 16;
    let is_power = (power_of_two & (power_of_two - 1)) == 0;
    println!("{} 是2的幂: {}", power_of_two, is_power);
}

条件语句

Rust 的条件语句用于根据表达式的真假来选择执行不同的代码路径。

if-else 表达式

Rust
fn main() {
    let number = 7;

    // 基本的 if 语句
    if number < 5 {
        println!("数字小于 5");
    } else if number < 10 {
        println!("数字在 5 到 9 之间");
    } else {
        println!("数字大于等于 10");
    }

    // if 是表达式，可以赋值
    let condition = true;
    let value = if condition { 1 } else { 2 };
    println!("value = {}", value);

    // 多分支 if-else-if
    let score = 85;
    let grade = if score >= 90 {
        "A"
    } else if score >= 80 {
        "B"
    } else if score >= 70 {
        "C"
    } else if score >= 60 {
        "D"
    } else {
        "F"
    };
    println!("分数 {} 的等级是: {}", score, grade);

    // 注意：if 和 else 的返回值类型必须兼容
    let number = 3;
    // let result = if number > 0 { "positive" } else { -1 }; // 错误！类型不匹配
    let result = if number > 0 { "positive" } else if number < 0 { "negative" } else { "zero" };
    println!("{} 是 {}", number, result);
}
⚠️ if-else 分支类型

所有分支的返回值类型必须相同！例如，不能一个分支返回 i32，另一个分支返回 &str。

if let 语法

Rust
fn main() {
    // if let 用于匹配单一模式，比 match 更简洁

    // 匹配 Option
    let some_value: Option = Some(42);

    // 使用 if let 简化
    if let Some(value) = some_value {
        println!("值为: {}", value);
    } else {
        println!("没有值");
    }

    // 配合 else 使用
    if let Some(value) = some_value {
        println!("获取到值: {}", value);
    }

    // 匹配枚举
    enum Message {
        Quit,
        Move { x: i32, y: i32 },
        Write(String),
        ChangeColor(u8, u8, u8),
    }

    let msg = Message::Move { x: 10, y: 20 };

    if let Message::Move { x, y } = msg {
        println!("移动到坐标: ({}, {})", x, y);
    }

    // while let 循环
    let mut stack = vec![1, 2, 3];
    while let Some(top) = stack.pop() {
        println!("弹出: {}", top);
    }

    // let else 语法（Rust 1.65+）
    let some_value: Option = Some(42);
    let value = else { 100 } if let Some(v) = some_value { v };
    println!("value = {}", value);
}
💡 if let vs match
  • 当只需要匹配一个模式时，用 if let 更简洁
  • 当需要匹配多个模式时，用 match 更清晰
  • if let 可以看作 match 的简化语法

match 条件分支

Rust
fn main() {
    // match 是 Rust 强大的模式匹配工具

    let number = 13;

    match number {
        1 => println!("数字是 1"),
        2 | 3 => println!("数字是 2 或 3"),          // 匹配多个值
        4..=6 => println!("数字在 4 到 6 之间"),     // 范围匹配
        7..=10 if number % 2 == 0 => {              // 带条件的匹配
            println!("数字是 7-10 之间的偶数");
        }
        _ => println!("其他数字"),                    // 通配符
    }

    // match 作为表达式返回值
    let result = match number {
        1 => "一",
        2 => "二",
        3 => "三",
        n if n < 10 => "个位数",
        n if n < 100 => "两位数",
        _ => "大数字",
    };
    println!("{} 是 {}", number, result);

    // 匹配元组
    let point = (2, 5);
    match point {
        (0, 0) => println!("原点"),
        (x, 0) => println!("在 x 轴上，x = {}", x),
        (0, y) => println!("在 y 轴上，y = {}", y),
        (x, y) => println!("在 ({}, {})", x, y),
    }
}

循环语句

Rust 提供了三种循环方式：loop（无限循环）、while（条件循环）和 for（遍历循环）。

loop 无限循环

Rust
fn main() {
    // loop 会无限循环，直到遇到 break
    let mut count = 0;

    let result = loop {
        count += 1;
        if count == 10 {
            // break 可以返回值
            break count * 2;
        }
    };
    println!("loop 结果: {}", result);  // 20

    // 嵌套循环使用标签
    let mut outer = 0;
    'outer_loop: loop {
        outer += 1;
        let mut inner = 0;
        loop {
            inner += 1;
            if inner == 3 && outer == 2 {
                break 'outer_loop;  // 跳出外层循环
            }
            if inner > 5 {
                break;  // 只跳出内层循环
            }
        }
    }
    println!("外部循环次数: {}", outer);

    // continue 跳过本次循环
    let mut i = 0;
    loop {
        i += 1;
        if i % 2 == 0 {
            continue;  // 跳过偶数
        }
        if i > 10 {
            break;
        }
        print!("{} ", i);  // 打印奇数: 1 3 5 7 9
    }
    println!();
}
⚠️ loop 标签的使用

在嵌套循环中，可以使用标签（如 'outer_loop）来明确指定要 break 或 continue 的是哪一层循环。

while 条件循环

Rust
fn main() {
    // while 循环在条件为 true 时继续执行

    // 基本用法
    let mut number = 3;
    while number != 0 {
        println!("倒计时: {}!", number);
        number -= 1;

}

for 遍历循环

Rust
fn main() {
    // for 是 Rust 中最常用的循环方式

    // 遍历范围
    for i in 1..=5 {           // 1, 2, 3, 4, 5（包含5）
        println!("i = {}", i);
    }

    // 遍历数组
    let arr = [10, 20, 30];
    for element in arr {
        println!("element = {}", element);
    }

    // 使用 iter() 遍历数组（不获取所有权）
    let arr = [1, 2, 3];
    for element in &arr {
        println!("值: {}", element);
    }
    println!("数组仍然可用: {:?}", arr);

    // 使用 enumerate 获取索引
    let names = ["Alice", "Bob", "Charlie"];
    for (index, name) in names.iter().enumerate() {
        println!("{}. {}", index + 1, name);
    }

    // rev() 反向遍历
    for i in (1..=3).rev() {
        print!("{} ", i);  // 3 2 1
    }
    println!();

    // 遍历 Vec
    let fruits = vec!["苹果", "香蕉", "橙子"];
    for fruit in &fruits {
        println!("喜欢: {}", fruit);
    }

    // zip 合并遍历
    let names = ["Alice", "Bob"];
    let scores = [90, 85];
    for (name, score) in names.iter().zip(scores.iter()) {
        println!("{}: {}分", name, score);
    }
}
✅ 推荐使用 for 循环
  • for 循环在 Rust 中是最安全、最高效的循环方式
  • 编译器会对 for 循环进行优化
  • 避免使用索引遍历数组，减少边界检查错误

循环的返回值与标签

Rust
fn main() {
    // 循环可以作为表达式返回值
    let mut counter = 0;
    let result = loop {
        counter += 1;
        if counter == 10 {
            break counter;  // 返回 counter 的值
        }
    };
    println!("result = {}", result);

    // 多层嵌套循环的标签
    let mut mat = [
        [1, 2, 3],
        [4, 5, 6],
        [7, 8, 9],
    ];
    'outer: for i in 0..3 {
        for j in 0..3 {
            if mat[i][j] == 5 {
                println!("找到5，位置: ({}, {})", i, j);
                break 'outer;  // 直接跳出外层循环
            }
        }
    }

    // continue 的标签使用
    let mut sum = 0;
    'outer_sum: for i in 1..=3 {
        for j in 1..=3 {
            if i == j {
                continue;  // 跳过 i == j 的情况
            }
            sum += i * j;
        }
    }
    println!("sum = {}", sum);
    // i=1: 跳过 j=1, 加 1*2 + 1*3 = 5
    // i=2: 跳过 j=2, 加 2*1 + 2*3 = 8
    // i=3: 跳过 j=3, 加 3*1 + 3*2 = 9
    // sum = 5 + 8 + 9 = 22
}

所有权与借用

⚠️ 所有权三大规则
  1. 每个值都有一个所有者（Owner）
  2. 值在任一时刻只能有一个所有者
  3. 当所有者离开作用域，值将被丢弃（Drop）

所有权转移

Rust
fn main() {
    // 所有权转移示例
    let s1 = String::from("hello");  // s1 拥有字符串的所有权
    let s2 = s1;                     // 所有权从 s1 转移到 s2
    // println!("{}", s1);            // 编译错误！s1 已经无效

    // 基本类型实现了 Copy trait，直接复制值
    let x = 5;
    let y = x;                       // x 和 y 都是有效的
    println!("x = {}, y = {}", x, y);

    // clone 深拷贝
    let s1 = String::from("hello");
    let s2 = s1.clone();             // 显式深拷贝
    println!("s1 = {}, s2 = {}", s1, s2);  // 两个都有效

    // 函数中的所有权转移
    let s = String::from("hello");
    take_ownership(s);               // 所有权转移给函数
    // println!("{}", s);            // 编译错误！s 已经无效

    // 基本类型作为参数会复制
    let x = 5;
    makes_copy(x);
    println!("x 仍然有效: {}", x);   // 正确！i32 实现了 Copy

    // 返回值转移所有权
    let s1 = String::from("hello");
    let s2 = take_and_return(s1);   // s1 转移到函数，又返回给 s2
    println!("s2: {}", s2);
}

fn take_ownership(s: String) {
    println!("获得所有权: {}", s);
}  // s 离开作用域，字符串被丢弃

fn makes_copy(x: i32) {
    println!("复制了值: {}", x);
}  // x 离开作用域，因为是 Copy 类型，什么也不发生

fn take_and_return(s: String) -> String {
    s  // 返回值转移所有权给调用者
}

引用与借用

Rust
fn main() {
    // 借用：不取得所有权，只"借用"值的引用
    let s1 = String::from("hello");
    let len = calculate_length(&s1);  // & 表示引用
    println!("'{}' 的长度是 {}", s1, len);  // s1 仍然有效

    // 可变引用
    let mut s = String::from("hello");
    change(&mut s);
    println!("修改后的字符串: {}", s);

    // 可变引用的规则
    let mut s = String::from("hello");

    // 同一时间只能有一个可变引用
    let r1 = &mut s;
    // let r2 = &mut s;  // 编译错误！不能同时有两个可变引用
    println!("r1: {}", r1);
    // r1 在这里不再使用，所以可以创建新的可变引用
    let r2 = &mut s;  // 正确！r1 已经不再使用
    println!("r2: {}", r2);

    // 不可变引用可以在有不可变引用时创建
    let s = String::from("hello");
    let r1 = &s;      // 第一个不可变引用
    let r2 = &s;      // 第二个不可变引用（可以同时有多个）
    // let r3 = &mut s;  // 编译错误！有不可变引用时不能有可变引用
    println!("r1: {}, r2: {}", r1, r2);
}

fn calculate_length(s: &String) -> usize {
    s.len()
}  // s 是引用，离开作用域不会丢弃值

fn change(some_string: &mut String) {
    some_string.push_str(", world");
}

  • 引用必须总是有效的（悬垂引用编译时防止）
  • 使用引用作为参数称为"借用"

        self.part
    }

✅ 生命周期省略规则

use std::fs::File;

自定义错误类型

Rust
use std::fmt;
use std::num::ParseIntError;

#[derive(Debug)]
struct MyError {
    message: String,
}

// 实现 Display trait
impl fmt::Display for MyError {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "错误: {}", self.message)
    }
}

// 实现 Error trait
impl std::error::Error for MyError {}

// From 实现错误转换
impl From for MyError {
    fn from(err: ParseIntError) -> Self {
        MyError {
            message: format!("数字解析错误: {}", err),
        }
    }
}

fn parse_and_double(s: &str) -> Result {
    let num: i32 = s.trim().parse()?;  // 使用 ? 自动转换错误类型
    Ok(num * 2)
}

fn main() {
    match parse_and_double("42") {
        Ok(n) => println!("结果: {}", n),
        Err(e) => println!("错误: {}", e),
    }

    match parse_and_double("abc") {
        Ok(n) => println!("结果: {}", n),
        Err(e) => println!("错误: {}", e),
    }

    // 使用 ? 运算符链式调用
    fn process() -> Result {
        let num = parse_and_double("10")?;
        let num = Ok(num + 1)?;
        Ok(num)
    }

    println!("process: {:?}", process());
}
