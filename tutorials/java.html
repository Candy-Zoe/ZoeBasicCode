Java 基础语法教程

Java 简介

Java 是一种面向对象的编程语言，具有跨平台、安全性高、生态丰富等特点，广泛应用于企业级开发。

💡 Java 特点
  • 平台无关性 - "Write Once, Run Anywhere"
  • 纯面向对象
  • 自动内存管理（GC）
  • 强类型检查
  • 丰富的标准库

第一个程序

Java 
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
⚠️ 编译运行 javac HelloWorld.java && java HelloWorld

运算符

运算符就是用来做数学运算和逻辑判断的符号，就像我们平时用的 +（加）、-（减）、=（等于）一样。

算术运算符

算术运算符就是数学里常见的加减乘除，但有几个需要注意的点：

Java 
int a = 10;
int b = 3;

// 基本运算
System.out.println("加法: " + a + " + " + b + " = " + (a + b));  // 10 + 3 = 13
System.out.println("减法: " + a + " - " + b + " = " + (a - b));  // 10 - 3 = 7
System.out.println("乘法: " + a + " * " + b + " = " + (a * b));  // 10 × 3 = 30
System.out.println("除法: " + a + " / " + b + " = " + (a / b));  // 10 ÷ 3 = 3（整数除法取整）
System.out.println("取余: " + a + " % " + b + " = " + (a % b));  // 10 ÷ 3 = 1（余数）

// 自增自减
int c = 5;
System.out.println("c++ = " + c++);  // 先输出再自增，输出5
System.out.println("++c = " + ++c);  // 先自增再输出，输出7
System.out.println("c-- = " + c--);  // 先输出再自减，输出7
System.out.println("--c = " + --c);  // 先自减再输出，输出5
加法: 10 + 3 = 13
减法: 10 - 3 = 7
乘法: 10 * 3 = 30
除法: 10 / 3 = 3（整数除法取整）
取余: 10 % 3 = 1（余数）
💡 什么时候用 % 和 /？

想象一下分糖果的场景：

  • /（整除）：10颗糖分给3个人，告诉每个人能分到几颗整糖
  • %（取余）：还剩几颗糖不能整分
⚠️ 注意

Java 中整数除法会向下取整，结果还是整数。如果需要小数结果，分子或分母要变成小数：

10 / 3.0 结果是 3.333...

比较运算符

比较运算符用来比较两个值的大小，结果只有 true（真）或 false（假）：

Java 
int m = 10;
int n = 20;

System.out.println(m + " == " + n + ": " + (m == n));  // false（等于）
System.out.println(m + " != " + n + ": " + (m != n));  // true（不等于）
System.out.println(m + " > " + n + ": " + (m > n));    // false（大于）
System.out.println(m + " < " + n + ": " + (m < n));    // true（小于）
System.out.println(m + " >= " + n + ": " + (m >= n));  // false（大于等于）
System.out.println(m + " <= " + n + ": " + (m <= n));  // true（小于等于）
⚠️ 特别注意

== 是"等于"（比较），= 是"赋值"（存入）。别搞混了！

逻辑运算符

逻辑运算符用来组合多个条件，就像说"并且"、"或者"、"不是"：

Java 
boolean p = true;
boolean q = false;

System.out.println("p && q: " + (p && q));  // false（并且：两个都要真）
System.out.println("p || q: " + (p || q));  // true（或者：至少一个为真）
System.out.println("!p: " + (!p));          // false（不是：取反）

// 实际应用示例：判断年龄是否符合条件
int age = 20;
boolean isStudent = true;
// 20岁以上并且是学生
boolean canDiscount = (age > 18) && isStudent;
System.out.println("可以打折: " + canDiscount);
💡 逻辑运算记忆口诀
  • &&（与）：and 就是"和"，要两个都对才返回 true
  • ||（或）：or 就是"或"，至少一个对就返回 true
  • !（非）：not 就是"非"，取反（对的变错，错的变对）

赋值运算符

Java 
int x = 10;

x += 5;   // 相当于 x = x + 5，结果 x = 15
x -= 3;   // 相当于 x = x - 3，结果 x = 12
x *= 2;   // 相当于 x = x * 2，结果 x = 24
x /= 4;   // 相当于 x = x / 4，结果 x = 6
x %= 5;   // 相当于 x = x % 5，结果 x = 1

System.out.println("最终结果: " + x);

条件语句

条件语句就像我们日常生活中的决策：如果...就...，否则如果...就...，否则就...

Java 使用 if（如果）、else if（否则如果）、else（否则）来进行条件判断。还有 switch 适合处理多值分支。

基本 if 语句

最简单的场景：如果条件满足，就做一件事，否则做另一件事。

Java 
int age = 18;
if (age >= 18) {
    System.out.println("你已经成年了");
} else {
    System.out.println("你还未成年");
}
你已经成年了
💡 语法小提示

注意代码的大括号 {}！Java 用大括号来区分代码块，每个括号内的代码就是一个整体。

多条件判断

生活中经常有多个条件，比如考试成绩判断：

Java 
int score = 85;
char grade;

if (score >= 90) {
    grade = 'A';       // 90分以上是A
} else if (score >= 80) {
    grade = 'B';       // 80-89分是B
} else if (score >= 60) {
    grade = 'C';       // 60-79分是C
} else {
    grade = 'D';       // 60分以下是D
}

System.out.println("成绩 " + score + " 分，等级: " + grade);
成绩 85 分，等级: B
💡 多个条件的判断顺序

计算机会从上到下检查条件，一旦找到满足的条件就执行对应的代码，后面的条件就不会再检查了。

所以要把更具体的条件放前面，更宽泛的条件放后面。

switch-case 语句

当需要根据一个变量的值选择多个分支时，switch 比 if-else 更清晰：

Java 
int day = 3;
String dayName;

switch (day) {
    case 1:
        dayName = "星期一";
        break;      // 重要！每个 case 后面要加 break
    case 2:
        dayName = "星期二";
        break;
    case 3:
        dayName = "星期三";
        break;
    case 4:
        dayName = "星期四";
        break;
    case 5:
        dayName = "星期五";
        break;
    case 6:
        dayName = "星期六";
        break;
    case 7:
        dayName = "星期日";
        break;
    default:
        dayName = "无效的日期";
}

System.out.println("今天是 " + dayName);
今天是 星期三
⚠️ 别忘了 break！

如果 case 后面没有 break，程序会"贯穿"到下一个 case，继续执行后面的代码，直到遇到 break 或 switch 结束。这可能是你想要的，也可能不是！

switch 表达式（Java 14+）

新版 Java 提供了更简洁的 switch 语法：

Java 
// Java 14+ 支持箭头语法
int day = 2;
String dayName = switch (day) {
    case 1 -> "星期一";
    case 2 -> "星期二";
    case 3 -> "星期三";
    case 4 -> "星期四";
    case 5 -> "星期五";
    case 6, 7 -> "周末";     // 多个值可以合并
    default -> "无效日期";
};

System.out.println("今天是 " + dayName);

三元表达式

如果只想根据条件返回一个值，可以用更简洁的方式：

Java 
// 格式：条件 ? 值1 : 值2
int a = 10;
int b = 20;
int max = (a > b) ? a : b;  // 如果 a>b 成立，返回 a，否则返回 b

System.out.println(a + " 和 " + b + " 中较大的是: " + max);
10 和 20 中较大的是: 20

循环语句

循环就是让计算机重复做某件事。想象一下要打印 100 次"你好"，不用循环就要写 100 遍，有了循环就只需要几行代码！

for 循环

for 循环就像按顺序执行，适合知道循环次数的场景：

Java 
// 基本的 for 循环
// 格式：for(初始化; 条件; 更新)
for (int i = 0; i < 5; i++) {
    System.out.println("第 " + i + " 次循环");
}

// 计算 1 到 100 的和
int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum += i;
}
System.out.println("1+2+...+100 = " + sum);
第 0 次循环
第 1 次循环
第 2 次循环
第 3 次循环
第 4 次循环
1+2+...+100 = 5050
💡 for 循环的三个部分
  • 初始化：int i = 0，只执行一次
  • 条件：i < 5，每次循环前检查
  • 更新：i++，每次循环后执行

while 循环

while 循环就像满足条件就一直做：只要条件为真，就一直重复执行。

Java 
int count = 1;
while (count <= 5) {       // 只要 count <= 5，就一直循环
    System.out.println("count = " + count);
    count++;               // 重要！每次循环后递增，否则会无限循环！
}
count = 1
count = 2
count = 3
count = 4
count = 5
⚠️ 警告：无限循环！

使用 while 循环时，一定要确保循环条件最终会变为 false，否则程序会一直运行下去，不会停止！

就像热水器，如果忘记关，就会一直烧水，直到...

do-while 循环

do-while 和 while 的区别是：先执行一次，再判断条件。适合必须执行至少一次的场景：

Java 
int num = 1;
do {
    System.out.println("先执行一次再说，num = " + num);
    num++;
} while (num < 1);    // 即使条件不满足，也会执行一次

System.out.println("循环结束");
先执行一次再说，num = 1
循环结束

foreach 循环（增强 for 循环）

foreach 专门用来遍历数组或集合，不需要关心索引：

Java 
String[] fruits = {"苹果", "香蕉", "橙子", "葡萄"};

// foreach 语法：for (元素类型 变量名 : 数组或集合)
for (String fruit : fruits) {
    System.out.println("水果: " + fruit);
}
水果: 苹果
水果: 香蕉
水果: 橙子
水果: 葡萄
💡 什么时候用 foreach？
  • foreach：适合只需要读取元素，不需要索引的场景
  • 普通 for：适合需要用索引，或者从后往前遍历的场景

break 和 continue

有时候我们需要提前退出循环或跳过某次循环：

Java 
// break: 提前退出循环（整个循环结束）
System.out.println("break 示例:");
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;   // 当 i=5 时，退出整个循环
    }
    System.out.print(i + " ");
}
System.out.println("\n遇到 break，循环结束");

// continue: 跳过当前迭代（进入下一次循环）
System.out.println("\ncontinue 示例:");
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) {    // 如果是偶数
        continue;       // 跳过这次循环，继续下一次
    }
    System.out.print(i + " ");
}
System.out.println("\n只打印了奇数");
break 示例:
0 1 2 3 4
遇到 break，循环结束

continue 示例:
1 3 5 7 9
只打印了奇数
💡 break vs continue
  • break：提前下班，直接结束整个循环
  • continue：跳过这次，但继续下一次循环

嵌套循环

循环里面还可以再放循环，就像打印乘法表：

Java 
// 打印 99 乘法表
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print(j + "*" + i + "=" + (i*j) + "\t");
    }
    System.out.println();   // 换行
}
1*1=1
1*2=2 2*2=4
1*3=3 2*3=6 3*3=9
...
1*9=9 2*9=18 3*9=27 ... 9*9=81

函数

在 Java 中，函数被称为方法（Method）。方法就是一段可以重复使用的代码，用来完成某个特定的功能。

💡 为什么需要方法？

想象一下：你要写 100 遍"计算并打印结果"，还是写一个方法然后调用 100 次？

方法让代码不重复、更简洁、易维护。

定义方法

Java 
public class Main {

    // 无返回值、无参数的方法
    public static void greet() {
        System.out.println("Hello, World!");
    }

    // 无返回值、有参数的方法
    public static void greetUser(String name) {
        System.out.println("你好，" + name + "！");
    }

    // 有返回值、有参数的方法
    public static int add(int a, int b) {
        return a + b;   // return 返回结果
    }

    public static void main(String[] args) {
        greet();
        greetUser("张三");
        int result = add(3, 5);
        System.out.println("3 + 5 = " + result);
    }
}
Hello, World!
你好，张三！
3 + 5 = 8
💡 方法的组成
  • public static：访问修饰符和静态标志
  • void 或返回类型：void 表示没有返回值
  • 方法名：见名知意
  • (参数)：方法接受的输入

带默认参数的方法（重载）

Java 不支持直接给参数默认值，但可以通过方法重载实现类似效果：

Java 
public class Main {

    // 计算平方（重载1）
    public static int power(int base) {
        return base * base;
    }

    // 计算指定次方（重载2）
    public static int power(int base, int exponent) {
        int result = 1;
        for (int i = 0; i < exponent; i++) {
            result *= base;
        }
        return result;
    }

    public static void main(String[] args) {
        System.out.println("3的平方: " + power(3));         // 使用1个参数
        System.out.println("3的立方: " + power(3, 3));     // 使用2个参数
    }
}
3的平方: 9
3的立方: 27
💡 什么是方法重载？

重载就是同一个方法名，但参数个数或类型不同。编译器会根据你传入的参数自动选择对应的方法。

就像一个"老板"，你叫他做事，他根据你给的任务决定怎么做。

可变参数

有时候不确定会有多少个参数，用 类型... 参数名 可以接收任意数量：

Java 
public class Main {

    // 可变参数方法
    public static int sumAll(int... numbers) {
        int total = 0;
        for (int num : numbers) {    // 可变参数当作数组使用
            total += num;
        }
        return total;
    }

    public static void main(String[] args) {
        System.out.println("sumAll(1, 2, 3) = " + sumAll(1, 2, 3));
        System.out.println("sumAll(1, 2, 3, 4, 5) = " + sumAll(1, 2, 3, 4, 5));
    }
}
sumAll(1, 2, 3) = 6
sumAll(1, 2, 3, 4, 5) = 15

递归方法

递归就是方法调用自己，适合处理可以分解为相似子问题的问题：

Java 
public class Main {

    // 计算阶乘：5! = 5 * 4 * 3 * 2 * 1
    public static int factorial(int n) {
        if (n <= 1) {       // 递归终止条件
            return 1;
        }
        return n * factorial(n - 1);   // 调用自己
    }

    // 计算斐波那契数列
    public static int fibonacci(int n) {
        if (n <= 1) {
            return n;
        }
        return fibonacci(n - 1) + fibonacci(n - 2);
    }

    public static void main(String[] args) {
        System.out.println("5! = " + factorial(5));     // 120
        System.out.println("第6个斐波那契数: " + fibonacci(6));  // 8
    }
}
⚠️ 递归要注意

递归必须有终止条件，否则会无限递归导致栈溢出错误。

递归虽好，但要注意性能问题，能用循环解决的尽量用循环。

数组

数组就像一个固定大小的容器，用来存储多个相同类型的元素。数组的大小在创建时就确定，之后不能改变。

💡 数组的特点
  • 数组长度固定，创建时确定
  • 所有元素类型相同
  • 元素在内存中连续存储
  • 可以通过索引快速访问（从0开始）

声明和创建数组

Java 
// 方法1：先声明，后创建
int[] scores = new int[5];      // 创建能存5个整数的数组，默认值0

// 方法2：直接初始化
int[] numbers = {10, 20, 30, 40, 50};

// 方法3：声明并创建
String[] names = new String[]{"张三", "李四", "王五"};

// 访问数组元素（索引从0开始）
System.out.println("第一个成绩: " + scores[0]);
System.out.println("第二个数字: " + numbers[1]);

// 修改数组元素
scores[0] = 95;
System.out.println("修改后第一个成绩: " + scores[0]);

// 获取数组长度
System.out.println("numbers 长度: " + numbers.length);
第一个成绩: 0
第二个数字: 20
修改后第一个成绩: 95
numbers 长度: 5
⚠️ 索引从 0 开始！

在 Java 中，数组的第一个元素索引是 0，不是 1。

就像楼层：第 1 层其实是 0 楼（ground floor）。

遍历数组

有多种方式遍历数组：

Java 
int[] nums = {10, 20, 30, 40, 50};

// 方式1：普通 for 循环（可以获取索引）
System.out.println("普通 for 循环:");
for (int i = 0; i < nums.length; i++) {
    System.out.println("  索引 " + i + ": " + nums[i]);
}

// 方式2：foreach 增强循环（更简洁）
System.out.println("\nforeach 循环:");
for (int num : nums) {
    System.out.println("  元素: " + num);
}
普通 for 循环:
  索引 0: 10
  索引 1: 20
  索引 2: 30
  索引 3: 40
  索引 4: 50

foreach 循环:
  元素: 10
  元素: 20
  元素: 30
  元素: 40
  元素: 50

常见数组操作

Java 
import java.util.Arrays;   // 需要导入 Arrays 类

int[] arr = {3, 1, 4, 1, 5, 9, 2, 6};

// 排序
Arrays.sort(arr);
System.out.println("排序后: " + Arrays.toString(arr));

// 查找元素（返回索引，未找到返回负数）
int index = Arrays.binarySearch(arr, 5);
System.out.println("元素5的索引: " + index);

// 填充数组
int[] arr2 = new int[5];
Arrays.fill(arr2, 10);
System.out.println("填充后: " + Arrays.toString(arr2));

// 复制数组
int[] arr3 = Arrays.copyOf(arr, arr.length * 2);  // 扩大一倍
System.out.println("复制并扩容: " + Arrays.toString(arr3));
排序后: [1, 1, 2, 3, 4, 5, 6, 9]
元素5的索引: 5
填充后: [10, 10, 10, 10, 10]
复制并扩容: [1, 1, 2, 3, 4, 5, 6, 9, 0, 0, 0, 0, 0, 0, 0, 0]

二维数组

二维数组就像表格，有行有列：

Java 
// 创建 3 行 4 列的二维数组

字符串

字符串（String）是 Java 中最常用的类型之一，用来表示文本。Java 中的字符串是不可变的，这意味着一旦创建，内容就不能改变。

💡 什么是不可变？

就像刻在石头上字，你不能修改它，只能重新刻一个新的。这听起来是缺点，但其实有很多好处：

  • 线程安全（多线程可以同时读取）
  • 安全性更高（不会被意外修改）
  • 可以共享使用，节省内存

字符串比较

Java 
String s1 = "hello";
String s2 = "hello";
String s3 = new String("hello");

// == 比较的是引用（内存地址），不是内容！
System.out.println("s1 == s2: " + (s1 == s2));    // true（字符串池，共享内存）
System.out.println("s1 == s3: " + (s1 == s3));    // false（new 创建了新对象）

// equals 比较的是内容（推荐使用！）
System.out.println("s1.equals(s2): " + s1.equals(s2));  // true
System.out.println("s1.equals(s3): " + s1.equals(s3));  // true

// 忽略大小写比较
System.out.println("Hello 和 hello 相同: " + "Hello".equalsIgnoreCase("hello"));  // true
⚠️ 字符串比较要使用 equals()

很多初学者会用 == 比较字符串，这通常是错误的！

== 比较的是内存地址（引用），equals() 比较的是内容。
