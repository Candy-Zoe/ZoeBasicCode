TypeScript 基础教程

TypeScript 简介

TypeScript 是微软开发的 JavaScript 超集，添加了静态类型系统，可以编译为纯 JavaScript。

💡 TypeScript 特点
  • 静态类型检查，提前发现错误
  • 支持 ES6+ 新特性
  • 更好的 IDE 代码提示
  • 适合大型项目开发
  • 完全兼容 JavaScript

安装与运行

Bash
# 全局安装
npm install -g typescript

# 编译
tsc hello.ts

# 使用 ts-node 直接运行
npm install -g ts-node
ts-node hello.ts

类型系统

基本类型

TypeScript
// 布尔值
let isDone: boolean = false;

// 数字
let decimal: number = 6;
let hex: number = 0xf00d;

// 字符串
let color: string = "blue";
let name: string = `Bob`;
let sentence: string = `Hello, ${name}`;

// 数组
let list1: number[] = [1, 2, 3];
let list2: Array<number> = [1, 2, 3];

// 元组
let x: [string, number] = ["hello", 10];

// 枚举
enum Color {Red, Green, Blue}
let c: Color = Color.Green;

// Any
let notSure: any = 4;
notSure = "maybe a string";

// Void
function warnUser(): void {
    console.log("警告");
}

// Null 和 Undefined
let u: undefined = undefined;
let n: null = null;

类型断言

TypeScript
// 方式一：尖括号
let someValue: any = "this is a string";
let strLength1: number = (<string>someValue).length;

// 方式二：as 语法（JSX 推荐）
let strLength2: number = (someValue as string).length;

接口 Interface

基本接口

TypeScript
interface Person {
    firstName: string;
    lastName: string;
    age?: number;           // 可选属性
    readonly id: number;    // 只读属性
}

function greeter(person: Person): string {
    return `Hello, ${person.firstName} ${person.lastName}`;
}

let user: Person = { firstName: "Jane", lastName: "User", id: 1 };
console.log(greeter(user));

类与继承

TypeScript
class Animal {
    name: string;

    constructor(name: string) {
        this.name = name;
    }

    move(distance: number = 0): void {
        console.log(`${this.name} 移动了 ${distance} 米`);
    }
}

class Dog extends Animal {
    breed: string;

    constructor(name: string, breed: string) {
        super(name);
        this.breed = breed;
    }

    bark(): void {
        console.log(`${this.name} 汪汪叫`);
    }

    move(distance: number = 0): void {
        console.log(`${this.name} 跑了 ${distance} 米`);
        super.move(distance);
    }
}

let dog = new Dog("旺财", "金毛");
dog.bark();
dog.move(20);

访问修饰符

📝 三种访问修饰符
  • public：公开的，默认值，任何地方可访问
  • private：私有的，只能在类内部访问
  • protected：受保护的，类内部和子类可访问

泛型

泛型函数

TypeScript
function identity<T>(arg: T): T {
    return arg;
}

let output = identity<string>("myString");
let output2 = identity("myString");  // 类型推断

泛型类

TypeScript
class GenericNumber<T> {
    zeroValue: T;
    add: (x: T, y: T) => T;

    constructor(zero: T, addFn: (x: T, y: T) => T) {
        this.zeroValue = zero;
        this.add = addFn;
    }
}

let myGenericNumber = new GenericNumber<number>(0, (x, y) => x + y);
console.log(myGenericNumber.add(5, 3));  // 8

泛型约束

TypeScript
interface Lengthwise {
    length: number;
}

function loggingIdentity<T extends Lengthwise>(arg: T): T {
    console.log(arg.length);
    return arg;
}

loggingIdentity("hello");  // 5
loggingIdentity([1, 2, 3]);  // 3

高级类型

联合类型和交叉类型

TypeScript
// 联合类型
function padLeft(value: string, padding: string | number): string {
    if (typeof padding === "number") {
        return Array(padding + 1).join(" ") + value;
    }
    return padding + value;
}

// 交叉类型
interface PersonInfo { name: string; age: number; }
interface Employee { company: string; salary: number; }
type EmployeeInfo = PersonInfo & Employee;

类型守卫

TypeScript
// typeof 类型守卫
function formatValue(value: string | number): string {
    if (typeof value === "number") {
        return value.toFixed(2);
    }
    return value.toUpperCase();
}

// instanceof 类型守卫
class Bird { fly() {} }
class Fish { swim() {} }

function move(pet: Bird | Fish) {
    if (pet instanceof Bird) {
        pet.fly();
    } else {
        pet.swim();
    }
}

// 自定义类型守卫
function isString(x: any): x is string {
    return typeof x === "string";
}

映射类型

TypeScript
interface Person {
    name: string;
    age: number;
}

// 所有属性只读
type ReadonlyPerson = Readonly<Person>;

// 所有属性可选

type PersonName = Pick<Person, "name">;

// 排除部分属性
type PersonWithoutAge = Omit<Person, "age">;

装饰器

TypeScript
// 类装饰器
function sealed(constructor: Function) {
    Object.seal(constructor);
    Object.seal(constructor.prototype);
}

@sealed
class Greeter {
    greeting: string;
    constructor(message: string) {
        this.greeting = message;
    }
    greet() { return "Hello, " + this.greeting; }
}

// 方法装饰器
function enumerable(value: boolean) {
    return function (target: any, propertyKey: string, descriptor: PropertyDescriptor) {
        descriptor.enumerable = value;
    };
}

class MyClass {
    @enumerable(false)
    greet() {}
}
