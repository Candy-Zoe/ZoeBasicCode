# C++ 基础语法学习

## 编译运行方式

### Windows (MinGW / Visual Studio)
```bash
g++ 文件名.cpp -o 输出文件名
输出文件名.exe
```

### Linux / macOS
```bash
g++ 文件名.cpp -o 输出文件名
./输出文件名
```

### 推荐使用 C++11 或更高版本
```bash
g++ -std=c++17 文件名.cpp -o 输出文件名
```

## 目录结构

### 01_基础语法

## 推荐学习顺序
